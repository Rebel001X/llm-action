# DPO 与 GRPO

> 一句话定位：DPO 把"训奖励模型 + 跑 PPO"的两段式 RLHF，**用一个解析推导直接折叠成一条二元分类损失**；GRPO 则保留 RL 在线采样，但**用组内采样的相对排名替代价值网络(critic)**。两者都在"砍掉 RLHF 里最重最不稳的那块"。📍 导航：[[00-知识地图]]

## 0. 一句话锚点

- **RLHF (PPO)**：先训一个奖励模型 $r_\phi$，再用 PPO 让策略最大化奖励、同时被 KL 拽住别跑远。**4 个模型同时在显存里**：策略、参考、奖励、价值。
- **DPO**：发现"KL 约束下的最优策略"有**闭式解**，于是把奖励 $r$ 用策略本身表达出来，代回偏好概率，**奖励模型和 RL 全部消失**，只剩一条像逻辑回归一样的损失。**只要 2 个模型**：策略 + 参考。
- **GRPO**：不想要价值网络估 baseline，就对同一个 prompt 采 $G$ 个回答，**用这组回答奖励的均值当 baseline、标准差做归一**。**3 个模型**：策略、参考、奖励（无价值网络）。

## 1. 地基 / 前置（不假设你记得任何公式）

### 1.1 RLHF 标准三段式
```
①  SFT：监督微调，得到 π_ref（也叫 π_SFT），后续都拿它当"锚"
②  RM ：收集人类偏好对 (x, y_w, y_l)，y_w 比 y_l 好，训奖励模型 r_φ(x,y)
③  RL ：用 PPO 让策略 π_θ 最大化 r_φ，同时 KL(π_θ || π_ref) 别太大
```
DPO 干掉的是 ② 和 ③，GRPO 改造的是 ③。

### 1.2 偏好怎么变成概率：Bradley-Terry 模型
人只会说"A 比 B 好"，不会打分。BT 模型假设：存在隐藏分数 $r(x,y)$，则"$y_w$ 胜过 $y_l$"的概率是
$$P(y_w \succ y_l \mid x) = \frac{\exp r(x,y_w)}{\exp r(x,y_w)+\exp r(x,y_l)} = \sigma\big(r(x,y_w)-r(x,y_l)\big)$$
其中 $\sigma(z)=\frac{1}{1+e^{-z}}$ 是 sigmoid。**关键直觉**：胜负概率只取决于**两者奖励之差**，奖励的绝对零点不影响结果。这一点后面会让"配分函数 $Z(x)$ 消失"成为可能。

训练 RM 就是最大化这个概率的对数似然：$\mathcal{L}_{RM}=-\mathbb{E}\big[\log\sigma(r_\phi(x,y_w)-r_\phi(x,y_l))\big]$。**记住这个形状**——DPO 最终长得和它一模一样，只是把 $r_\phi$ 换成了"用策略表达的隐式奖励"。

### 1.3 sigmoid / log-sigmoid 速查（手算要用）
| $z$ | $\sigma(z)$ | $-\log\sigma(z)$ |
|---|---|---|
| -2 | 0.119 | 2.13 |
| -1 | 0.269 | 1.31 |
| 0  | 0.500 | 0.693 |
| +1 | 0.731 | 0.313 |
| +2 | 0.881 | 0.127 |
$\sigma'(z)=\sigma(z)(1-\sigma(z))$，且 $\frac{d}{dz}[-\log\sigma(z)] = -(1-\sigma(z)) = \sigma(z)-1$（恒为负，所以增大 $z$ 一定减小损失）。

## 2. RLHF 的目标函数：为什么它难

RLHF 第 ③ 步的优化目标（对每个 prompt $x$）：
$$\max_{\pi_\theta}\; \mathbb{E}_{y\sim\pi_\theta(\cdot|x)}\big[r_\phi(x,y)\big] \;-\; \beta\, \mathrm{KL}\big(\pi_\theta(\cdot|x)\,\|\,\pi_{ref}(\cdot|x)\big)$$

逐项读：
- 第一项 $\mathbb{E}[r_\phi]$：让策略多生成高奖励的回答。
- 第二项 $-\beta\,\mathrm{KL}$：罚策略偏离参考模型太远。$\beta$ 越大，越像参考模型（越保守）。

**为什么难（这也是 DPO/GRPO 的动机）**：
```
难点1  奖励 r 是离散文本的函数，y 是采样出来的 → 不可微 → 必须用策略梯度(PPO)
难点2  PPO 要估"优势 A"，得再训一个价值网络 critic（第4个模型）
难点3  4模型同驻显存 + 在线采样 + 重要性比 clip → 工程极其难调、易崩
难点4  奖励模型本身可能被"钻空子"(reward hacking)
```

**"4 模型同驻"有多贵（显存手算）**：以一个 7B 模型为例，纯权重（fp16，2 字节/参数）约 $7\times10^9\times2=14$ GB。PPO 要同时放**策略 + 参考 + 奖励 + 价值**四份：
```
策略 π_θ  14GB(权重) + 优化器/梯度(AdamW 约权重×4) ≈ 70GB  ← 要训, 最贵
参考 π_ref 14GB(仅前向, 冻结)
奖励 r_φ  14GB(仅前向, 冻结)
价值 V    14GB(权重) + 优化器/梯度 ≈ 70GB              ← 也要训
                                  合计 ≈ 168GB +激活
```
DPO 只剩**策略(要训, ~70GB) + 参考(冻结, 14GB) ≈ 84GB**，省掉了奖励与价值两份、其中价值还是要训的那种昂贵份。**这就是"DPO 把单卡能跑的规模整整放大一档"的来源**（数值为量级估算，实际随序列长/批大小/优化器实现而变）。

## 3. 核心推导（一）：KL 约束最优策略的闭式解

我们**不数值求解**第 2 节那个 max，而是问：在没有参数限制（策略可以是任意分布）的情况下，最优策略 $\pi^*$ 的**解析形式**是什么？

把目标改写成最小化（除以 $\beta$、取负）：
$$\min_{\pi}\; \mathbb{E}_{y\sim\pi}\Big[\log\frac{\pi(y|x)}{\pi_{ref}(y|x)} - \tfrac{1}{\beta}r(x,y)\Big]$$
凑成一个 KL 散度。定义
$$Z(x)=\sum_y \pi_{ref}(y|x)\exp\!\Big(\tfrac{1}{\beta}r(x,y)\Big)\quad(\textbf{配分函数，只跟 }x\textbf{ 有关})$$
则上式可写成
$$\min_\pi \;\mathrm{KL}\!\Big(\pi(y|x)\;\Big\|\;\underbrace{\tfrac{1}{Z(x)}\pi_{ref}(y|x)\exp(\tfrac1\beta r(x,y))}_{\text{记作 }\pi^*(y|x)}\Big) - \log Z(x)$$
$\log Z(x)$ 与 $\pi$ 无关，是常数。KL 散度在两分布相等时取最小值 0，所以**最优解就是括号里那个分布**：
$$\boxed{\;\pi^*(y|x)=\frac{1}{Z(x)}\,\pi_{ref}(y|x)\,\exp\!\Big(\frac{1}{\beta}r(x,y)\Big)\;}$$

```
直觉图：最优策略 = 参考策略 被奖励"重加权"
   π_ref(y|x) ──×── exp(r/β) ──÷── Z(x)  =  π*(y|x)
   原来的概率      奖励高的放大    归一化      最优概率
   r 越大、β 越小 → 放大越狠（越激进偏向高奖励）
```
这是整篇推导的**支点**：它给出了"奖励 → 最优策略"的映射。DPO 的天才之处是把它**反过来用**。

## 4. 核心推导（二）：反解奖励 → 代入 BT → DPO 损失

第 3 节的式子对 $r$ 求解（两边取 log 再移项）：
$$r(x,y)=\beta\log\frac{\pi^*(y|x)}{\pi_{ref}(y|x)} + \beta\log Z(x)$$

**关键一步**：把这个奖励表达式代回 Bradley-Terry（1.2 节）。BT 只关心**奖励之差** $r(x,y_w)-r(x,y_l)$，而 $\beta\log Z(x)$ 同时出现在 $y_w$ 和 $y_l$ 上、**与 $y$ 无关 → 相减时直接抵消**！这就是"免奖励模型"的数学根源：
$$r(x,y_w)-r(x,y_l)=\beta\log\frac{\pi^*(y_w|x)}{\pi_{ref}(y_w|x)}-\beta\log\frac{\pi^*(y_l|x)}{\pi_{ref}(y_l|x)}$$

把"真实最优策略 $\pi^*$"换成"我们要训练的 $\pi_\theta$"，代入 BT 的负对数似然，得到 **DPO 损失**：
$$\boxed{\;\mathcal{L}_{DPO}=-\,\mathbb{E}_{(x,y_w,y_l)}\Big[\log\sigma\Big(\beta\log\tfrac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}-\beta\log\tfrac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\Big)\Big]\;}$$

**为什么这叫"把 RLHF 变成直接偏好分类损失"**：对比 1.2 节训 RM 的损失，形状完全一致——都是 $-\log\sigma(\text{胜者分} - \text{败者分})$，即一个**二元交叉熵 / 逻辑回归**。区别只是"分数"从外部奖励模型 $r_\phi$，换成了**策略自己定义的隐式奖励** $\hat r_\theta(x,y)=\beta\log\frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}$。**奖励模型和 PPO 都消失了**，因为奖励已被策略本身"吸收"。

```
RLHF 两段:   偏好数据 → 训RM r_φ → 跑PPO(策略+参考+奖励+价值)
                 │                         ↑ 4模型, 在线采样, 难调
DPO 一段:    偏好数据 ──直接──> 一条 BCE 损失(策略+参考)
                 │                         ↑ 2模型, 离线, 像监督学习
            等价性来自: π* 闭式解 + BT 只看奖励差 + logZ(x) 抵消
```

### 4.1 用极小例子看 $Z(x)$ 为什么必须抵消（手算）
配分函数 $Z(x)=\sum_y \pi_{ref}(y|x)\exp(r(x,y)/\beta)$ 是对**整个词表所有可能续写 $y$ 求和**，天文数字、根本算不出来——这正是奖励模型路线绕不开的麻烦。设想一个玩具：词表只有 $\{a,b\}$，$\beta=1$，$\pi_{ref}(a)=\pi_{ref}(b)=0.5$，奖励 $r(a)=2,\;r(b)=0$。
$$Z=0.5e^{2}+0.5e^{0}=0.5(7.389)+0.5(1)=4.19$$
那么 $r(a)-r(b)=2-0$。而用反解式 $r=\log\frac{\pi^*}{\pi_{ref}}+\log Z$：两个 $\log Z=\log 4.19=1.43$ 完全一样，相减 $1.43-1.43=0$。**结论**：无论 $Z$ 是 4.19 还是 4 万亿，只要在差里出现两次就抵消。DPO 因此**永远不需要计算 $Z(x)$**——这是它能把不可解的归一化甩掉、纯靠两个 $\log\pi$ 之差训练的根本原因。

### 4.2 DPO 也悄悄满足了那个 KL
有人担心 DPO 没有显式 KL 项，会不会跑飞？其实约束**编码进了损失结构**：隐式奖励是 $\beta\log\frac{\pi_\theta}{\pi_{ref}}$，若 $\pi_\theta$ 远离 $\pi_{ref}$，这个对数比会爆炸式增大，$\beta$ 又把它缩放后送入 sigmoid 使梯度饱和 → 自然不鼓励无限偏离。所以 DPO 的 KL 约束不是外加的惩罚项，而是**长在奖励定义里**。

## 5. DPO 损失逐项拆解 + β 温度

记 $h = \beta\big[(\log\pi_\theta(y_w)-\log\pi_{ref}(y_w)) - (\log\pi_\theta(y_l)-\log\pi_{ref}(y_l))\big]$，损失 $=-\log\sigma(h)$。

- $\log\pi_\theta(y_w)-\log\pi_{ref}(y_w)$：**胜者相对参考变好了多少**。
- $\log\pi_\theta(y_l)-\log\pi_{ref}(y_l)$：**败者相对参考变好了多少**。
- 两者相减：我们希望"胜者涨得比败者多" → $h>0$ → 损失小。

**梯度**（解释 DPO 在做什么）：
$$\nabla_\theta\mathcal{L}=-\beta\,\underbrace{\sigma(\hat r_l-\hat r_w)}_{\text{权重}}\big[\nabla\log\pi_\theta(y_w)-\nabla\log\pi_\theta(y_l)\big]$$
权重 $\sigma(\hat r_l-\hat r_w)$ 是"**模型当前把次序判错的程度**"：模型越觉得败者比胜者好（判错越离谱），权重越接近 1，更新越大；已经判对的样本权重趋近 0，几乎不更新。**这是自带的难例聚焦**，避免在已学会的样本上过拟合。

### β 温度的物理含义
$\beta$ 是第 2 节 KL 惩罚的系数，在 DPO 里它**缩放隐式奖励 / 控制偏离参考的强度**：
| β | 行为 | 风险 |
|---|---|---|
| 大 (如 0.5) | 强 KL 约束，策略紧贴参考，更新温和 | 学不动偏好，提升有限 |
| 小 (如 0.01) | 弱约束，激进追偏好 | 偏离参考太远、退化/重复、过拟合 |
| 常用 | **0.1 ~ 0.5**（以官方/任务为准） | — |

直觉：$\beta$ 把"对数概率比"放大 $\beta$ 倍再喂给 sigmoid。$\beta$ 越大，同样的概率比变化会产生越大的 $h$，sigmoid 越快饱和 → 梯度越小 → 越保守。

## 6. 数值手算：一条样本从头算到尾

设 $\beta=0.1$，一条偏好样本 $(x,y_w,y_l)$。模型给出的**序列对数概率**（已对 token 求和）：

| 量 | $\log\pi_\theta$ | $\log\pi_{ref}$ | 差 $=\log\frac{\pi_\theta}{\pi_{ref}}$ |
|---|---|---|---|
| 胜者 $y_w$ | -8.0 | -10.0 | **+2.0** |
| 败者 $y_l$ | -9.0 | -10.0 | **+1.0** |

**Step1 隐式奖励**：$\hat r_w=\beta\cdot 2.0=0.2$，$\hat r_l=\beta\cdot 1.0=0.1$。
**Step2 奖励差** $h=\hat r_w-\hat r_l=0.2-0.1=0.1$。
**Step3 损失** $\mathcal{L}=-\log\sigma(0.1)$。$\sigma(0.1)=\frac{1}{1+e^{-0.1}}=\frac{1}{1+0.9048}=0.525$，故 $\mathcal{L}=-\log 0.525=0.644$。
**Step4 梯度方向**：权重 $=\sigma(\hat r_l-\hat r_w)=\sigma(-0.1)=0.475$。因为 $h>0$（已小幅判对），权重略小于 0.5，更新会**继续抬高 $\log\pi_\theta(y_w)$、压低 $\log\pi_\theta(y_l)$**，使 $h$ 进一步变大、损失继续下降。

**反例（判错时）**：若胜者差 = +1.0、败者差 = +2.0，则 $h=0.1\times(1-2)=-0.1$，$\mathcal{L}=-\log\sigma(-0.1)=-\log 0.475=0.744$（更大），权重 $=\sigma(+0.1)=0.525$（更大）→ 模型被更强地推回正确次序。**符号一切都对**：判对损失小、更新小；判错损失大、更新大。

```
ASCII：DPO 把 y_w 概率往上推、y_l 往下压，同时被 π_ref 拽住
   log π(y_w) ↑↑          目标: 拉开 w 与 l 的"相对参考增量"差
   ───────────────  π_ref (锚, 冻结)
   log π(y_l) ↓
```

## 7. GRPO：组内归一优势，免 critic

GRPO（Group Relative Policy Optimization，DeepSeek 提出，见 [[llm-algo/deepseek/DeepSeek-R1]]）**仍是在线 RL**（要采样、要奖励信号），但解决 PPO 的"必须训价值网络当 baseline"这一痛点。

### 7.1 PPO 为什么要价值网络
PPO 优势 $A_t = r_t + \gamma V(s_{t+1}) - V(s_t)$，那个 $V$（价值/critic）就是**第 4 个模型**：和策略同等大小，显存翻倍、还难训。它的作用只是给奖励减一个 baseline 来降方差。

### 7.2 GRPO 的替代：用一组样本自己当 baseline
对同一个 prompt $x$，采 $G$ 个回答 $\{y_1,...,y_G\}$（一组 group），各自打分得 $\{r_1,...,r_G\}$。**组内归一**作为优势：
$$\hat A_i=\frac{r_i-\mathrm{mean}(r_1..r_G)}{\mathrm{std}(r_1..r_G)+\epsilon}$$
- 减均值 = 这组的 baseline（替代 $V$）；
- 除标准差 = 自动归一，奖励尺度无关、稳定。

整组里**比平均好的回答 $\hat A_i>0$（鼓励），差的 $\hat A_i<0$（抑制）**。同一组所有 token 共享这个序列级 $\hat A_i$。目标（含 PPO 式 clip 重要性比与 KL 正则）：
$$\mathcal{J}_{GRPO}=\mathbb{E}\Big[\tfrac{1}{G}\sum_i \min\big(\rho_i\hat A_i,\;\mathrm{clip}(\rho_i,1\!-\!\epsilon,1\!+\!\epsilon)\hat A_i\big)\Big]-\beta\,\mathrm{KL}(\pi_\theta\|\pi_{ref}),\quad \rho_i=\tfrac{\pi_\theta(y_i|x)}{\pi_{\theta_{old}}(y_i|x)}$$

### 7.3 GRPO 优势手算
一组 $G=4$ 的奖励（如：答对得 1、答错得 0）：$r=[1,0,1,0]$。
均值 $=0.5$，方差 $=\frac14[(0.5)^2\times4]=0.25$，标准差 $=0.5$。
$$\hat A=\frac{[1,0,1,0]-0.5}{0.5}=[+1,\,-1,\,+1,\,-1]$$
两个对的回答被同等放大、两个错的被同等压低，**无需任何价值网络**，baseline 直接来自这 4 个样本。注意一个退化情形：若一组**全对**（$r=[1,1,1,1]$），均值=1、标准差=0，则 $\hat A$ 全为 0（除零前加 $\epsilon$），这组样本不产生梯度——符合直觉：全对则无从比较、学不到东西，因此采样温度不能太低、$G$ 不能太小，否则组内无差异、训练停滞。
```
prompt x ──采样──> y1(r=1) y2(r=0) y3(r=1) y4(r=0)
                     │       │       │       │
        组内均值0.5/标准差0.5 归一 → A=[+1,-1,+1,-1]
                     ↑ 这一步代替了 PPO 的 critic V(s)
```

### 7.4 token 级怎么用这个 $\hat A_i$
GRPO 是序列级奖励：整条 $y_i$ 只有一个标量奖励，于是这条回答里**每个 token 共享同一个序列级优势 $\hat A_i$**。某条回答 $\hat A_i=+1$，它的所有 token 的对数概率都被往上推；$\hat A_i=-1$ 的回答所有 token 被往下压。重要性比 $\rho$ 与 clip 是逐 token 算的（防一步更新太猛），但优势全程是那个组内归一标量。**对比 PPO**：PPO 用 GAE 给每个 token 算不同的优势（需要 critic 提供 $V$）；GRPO 牺牲这种 token 级精细度，换来"零价值网络"的简洁——对答案整体对错才有意义的推理任务（数学/代码），这种取舍非常划算。

### 7.5 DPO 家族变体（面试加分）
| 变体 | 改了什么 | 解决的问题 |
|---|---|---|
| IPO | 把 $\log\sigma$ 换成平方损失、加正则 | DPO 在干净数据上易过拟合、把概率比推到无穷 |
| cDPO | 给标签加噪声平滑 | 偏好标注有错时更鲁棒 |
| KTO | 用**单条**样本(好/坏二值)而非成对 | 难以拿到成对偏好、只有单点反馈时可用 |
| ORPO | 把偏好项直接并入 SFT、**免参考模型** | 连 $\pi_{ref}$ 都不想加载，进一步省显存 |

| 维度 | RLHF-PPO | DPO | GRPO |
|---|---|---|---|
| 范式 | 在线 RL | **离线/监督式** | 在线 RL |
| 是否训奖励模型 | 是（显式 $r_\phi$） | **否**（隐式奖励） | 是（或规则奖励） |
| 是否需价值网络 critic | **是** | 否 | **否（组内 baseline）** |
| 同驻模型数 | 4（策略/参考/奖励/价值） | **2（策略/参考）** | 3（策略/参考/奖励） |
| 显存/工程难度 | 最高 | 最低 | 中 |
| 是否在线采样 | 是 | 否（固定偏好对） | 是 |
| KL 约束 | 显式 KL 项 | 隐含在 β 对数比 | 显式 KL 项 |
| 数据 | 偏好对 | **偏好对** | prompt + 奖励(可验证/RM) |
| 探索能力 | 强 | 弱（受限于数据分布） | 强 |
| 典型场景 | 通用对齐 | 轻量对齐、资源受限 | **推理/数学/代码(R1)** |

**一句话记忆**：DPO 砍掉"奖励模型 + RL"（省 2 个模型，但离线、不探索）；GRPO 砍掉"价值网络"（省 1 个模型，仍在线、能探索，适合可验证奖励的推理任务）。

## 9. 常见问题 / 高频追问

| 高频问题 | 踩点答案 | 追问 & 陷阱 |
|---|---|---|
| DPO 为什么能不要奖励模型？ | KL 约束最优策略有闭式解 $\pi^*\propto\pi_{ref}e^{r/\beta}$，反解出 $r=\beta\log\frac{\pi}{\pi_{ref}}+\beta\log Z$，代回只看奖励差的 BT，$\log Z(x)$ 抵消 → 奖励被策略隐式表达 | 追问：$Z(x)$ 为何能消？答：它只依赖 $x$ 不依赖 $y$，胜负只看奖励差，相减即没 |
| DPO 损失和训 RM 的损失什么关系？ | 形状完全相同，都是 $-\log\sigma(\text{胜}-\text{败})$ 的 BCE；只是分数从 $r_\phi$ 换成隐式奖励 $\beta\log\frac{\pi_\theta}{\pi_{ref}}$ | 陷阱：别说"DPO 没有奖励"，是**隐式**奖励 |
| β 调大调小影响？ | 大→紧贴参考、保守、可能学不动；小→激进追偏好、易退化过拟合；常用 0.1~0.5 | 追问：β 与 PPO 的 KL 系数是同一个，控偏离参考强度 |
| DPO 的缺点？ | 离线、不采样 → 受限于偏好数据分布，无法探索数据外的更优解；对 $\pi_{ref}$ 和数据质量敏感；可能降低 $y_w$ 绝对概率（只保证相对差） | 追问：为何会一起降低？因损失只约束**差**，可同降只要 w 降得少 |
| GRPO 怎么免 critic？ | 同 prompt 采 $G$ 个回答，用组内奖励 $\frac{r_i-\text{mean}}{\text{std}}$ 当优势，均值即 baseline，省掉价值网络 | 追问：方差从哪来？答：组内多样采样，故需 $G$ 够大(常 8~64) |
| R1 为何用 GRPO 不用 DPO？ | 推理任务奖励**可验证**（答案对错、单测通过），适合在线采样 + 规则奖励 + 探索；DPO 离线无探索拿不到这种增益 | 陷阱：DPO 适合"有现成偏好对"，GRPO 适合"有可判分环境" |
| PPO/DPO/GRPO 显存排序？ | PPO(4)>GRPO(3)>DPO(2)；DPO 最省因为没有奖励/价值网络 | 追问：DPO 的参考模型可冻结、甚至预存 logp，进一步省 |
| DPO 训练会崩吗？ | 会：β 太小或数据噪声大时，$y_w,y_l$ 概率一起塌、输出退化/复读；常加 SFT 正则或用 IPO/cDPO 变体 | 提一句变体：IPO 改损失防过拟合、KTO 用单样本不需成对 |

## 一页纸总结（背诵版）
- DPO 三连：① KL 约束最优策略闭式解 $\pi^*\propto\pi_{ref}e^{r/\beta}$ → ② 反解 $r=\beta\log\frac{\pi}{\pi_{ref}}+\beta\log Z$ → ③ 代回只看奖励差的 BT，$\log Z$ 抵消，得 BCE 损失。
- 一句话区分：**DPO 砍奖励模型+RL（离线、省2模型、不探索）；GRPO 砍价值网络（在线、省1模型、组内均值当 baseline、适合可验证奖励的推理）。**
- 隐式奖励 $\hat r_\theta=\beta\log\frac{\pi_\theta}{\pi_{ref}}$；β 越大越保守。损失梯度权重 $=\sigma(\hat r_l-\hat r_w)$，自带难例聚焦。
- 显存量级：PPO 4 模型 ≈168GB ＞ GRPO 3 模型 ＞ DPO 2 模型 ≈84GB（7B 估算）。
