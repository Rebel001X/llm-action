## 0. 一句话锚点

> **On-Policy（在线策略）**：用谁、学谁——采样动作的策略和被优化的策略是**同一个**。
> **Off-Policy（离线策略）**：用一个**行为策略**去采样，却去优化**另一个目标策略**，因此可以复用历史/他人的数据。

一句口诀：

```
On-Policy  = 自己下厨学做菜（边做边学，做的就是要学的那道）
Off-Policy = 看别人的食谱学做菜（数据来自别人，学的是自己的最优做法）
```

## 1. 地基：行为策略与目标策略

强化学习（Reinforcement Learning, RL）里，智能体（Agent）在环境中按某个**策略**选动作，拿到**奖励**，目标是最大化长期累积回报。形式化为五元组：

$$\langle \mathcal{S}, \mathcal{A}, P, R, \gamma \rangle$$

- $\mathcal{S}$：状态空间；$\mathcal{A}$：动作空间。
- $P(s'\mid s,a)$：转移概率；$R(s,a)$：奖励；$\gamma\in[0,1)$：折扣因子。

关键是区分**两个策略**——这正是 On/Off-Policy 的分水岭：

| 名称 | 符号 | 作用 |
|---|---|---|
| 行为策略 Behavior Policy | $\mu(a\mid s)$ | 真正去**采样/产生数据**的策略 |
| 目标策略 Target Policy | $\pi(a\mid s)$ | 我们真正想**优化/最终使用**的策略 |

```
            选动作、攒数据                被优化、最终上线
  环境  ◄────────────────  行为策略 μ        目标策略 π
   │                          │                  ▲
   └──── reward / next state ─┘                  │
                          数据 (s,a,r,s')  ───────┘ 用来更新

   On-Policy:  μ == π   （同一个策略，左右两列合二为一）
   Off-Policy: μ != π   （两列分离，π 用 μ 产出的数据学习）
```

> **为什么这区分如此重要？** 因为它决定了「数据能不能复用」。On-Policy 一旦更新策略，旧数据立刻「过期」；Off-Policy 把数据存进经验池反复榨干，样本效率高一个量级——但代价是要处理「数据分布和目标策略不一致」的偏差。

## 2. On-Policy（在线策略）：边玩边学

**定义**：学习过程中，策略（Policy）和行为（Behavior）是一致的。即智能体总是根据**当前学习到的策略**来选择动作。

**特点**：
- 直接从当前策略中采样数据。
- 学习过程和行为策略是同步的。
- 常见的 On-Policy 算法包括 **SARSA** 和 **REINFORCE** 等。

**优点**：由于学习过程和行为策略一致，可以更直接地对策略进行优化。
**缺点**：可能需要更多的探索来学习一个好的策略，因为智能体总是根据当前策略选择动作（探索不足易陷局部最优）。

机制图：

```
  ┌──────────────────────────────────────────┐
  │  采样一批 (s,a,r,s',a')  用 π_t 自己产生   │
  └───────────────┬──────────────────────────┘
                  ▼
        用这批数据更新 π_t → π_{t+1}
                  ▼
        旧数据立即作废（必须重采）  ← On-Policy 的代价
```

SARSA 的更新式（注意「下一动作 $a'$ 也来自当前策略」，因此名字是 S-A-R-S-A）：

$$Q(s,a) \leftarrow Q(s,a) + \alpha\big[\,r + \gamma\, Q(s',a') - Q(s,a)\,\big]$$

数值手算（$\alpha=0.1,\ \gamma=0.9$，当前 $Q(s,a)=2.0$，下一步按当前策略选了 $a'$ 且 $Q(s',a')=5.0$，奖励 $r=1$）：

$$Q \leftarrow 2.0 + 0.1\times[\,1 + 0.9\times5.0 - 2.0\,] = 2.0 + 0.1\times3.5 = 2.35$$

> 关键：$a'$ 是**实际会执行**的那个动作（含探索 $\varepsilon$-greedy 的随机性），所以 SARSA 学到的是「带探索风险的」更保守策略。

## 3. Off-Policy（离线策略）：别人的经验也能学

**定义**：学习过程中，策略（Policy）和行为（Behavior）可以不一致。即智能体可以按一个**行为策略**（Behavior Policy）选动作，却学习一个不同的**目标策略**（Target Policy）。

**特点**：
- 可以利用历史数据或模拟环境来学习，不需要实时与环境交互。
- 学习过程和行为策略是异步的。
- 常见的 Off-Policy 算法包括 **Q-Learning**、**Deep Q-Networks（DQN）** 和 **Actor-Critic** 方法等。

**优点**：可以更有效地利用数据，因为可以重复使用历史数据，并且可以更灵活地探索环境。
**缺点**：需要处理策略不一致带来的偏差问题，需要使用一些技术（如**重要性采样**）来纠正这种偏差。

机制图：

```
   行为策略 μ ──采样──► 经验池 Replay Buffer ──采样小批──► 更新目标策略 π
       ▲                  (s,a,r,s') 反复复用                 │
       └──── 偶尔同步/可完全不同 ◄───────────────────────────┘
```

Q-Learning 的更新式（注意是 $\max_{a'}$，即假设下一步走**目标策略下的最优动作**，与实际采样动作脱钩）：

$$Q(s,a) \leftarrow Q(s,a) + \alpha\big[\,r + \gamma\, \max_{a'} Q(s',a') - Q(s,a)\,\big]$$

同样数据（$Q(s',\cdot)$ 的最大值为 $5.0$）：

$$Q \leftarrow 2.0 + 0.1\times[\,1 + 0.9\times5.0 - 2.0\,] = 2.35$$

> SARSA 与 Q-Learning 的唯一区别就在那一项：SARSA 用 $Q(s',a')$（**实际走的**），Q-Learning 用 $\max_{a'}Q(s',a')$（**最优的**）。前者 On-Policy，后者 Off-Policy——一字之差，范式之别。

**两者会学出不同策略吗？会。** 经典「悬崖行走（Cliff Walking）」直觉：

```
   起点 S ......悬崖（掉下去 -100）...... 终点 G
         │                                  │
   Q-Learning 学最优路径 → 贴着悬崖走（理论最短，但探索时常掉下去）
   SARSA      学含探索的路径 → 绕远离悬崖（更安全，回报曲线更平稳）
```

> 为什么？SARSA 的更新里 $a'$ 含 $\varepsilon$-greedy 的随机探索，它「知道自己偶尔会乱走」，于是主动远离悬崖；Q-Learning 用 $\max$，假装下一步永远最优，于是贴边走。这就是「学你真会做的」与「学你最该做的」的现实差异。

## 4. 重要性采样：Off-Policy 的纠偏引擎

数据来自行为策略 $\mu$，但要估计目标策略 $\pi$ 下的期望，分布对不上，必须乘一个**重要性采样权重**（Importance Sampling）：

$$\mathbb{E}_{a\sim\pi}[f(a)] = \mathbb{E}_{a\sim\mu}\!\left[\frac{\pi(a\mid s)}{\mu(a\mid s)}\, f(a)\right]$$

```
   想要 π 下的均值，手里只有 μ 采的样
        │
        ▼   乘权重 ρ = π(a|s) / μ(a|s)
   ρ>1：π 比 μ 更爱这个动作 → 放大它的贡献
   ρ<1：π 比 μ 更不爱       → 缩小它的贡献
```

数值示例：某动作 $\pi(a\mid s)=0.6,\ \mu(a\mid s)=0.3$，权重 $\rho=0.6/0.3=2.0$，说明这条样本在目标策略下「应该出现两倍频率」，所以它的回报贡献被放大 2 倍。

> **坑预警**：当 $\mu$ 几乎不选某动作（$\mu\to0$）而 $\pi$ 想选时，$\rho\to\infty$，方差爆炸。这就是大模型 PPO 里要做 **ratio clipping**（把 $\rho$ 裁到 $[1-\epsilon, 1+\epsilon]$）的根本原因。

## 5. 数据流对照：一张图看懂

```
  On-Policy                         Off-Policy
  ─────────                         ──────────
  π_t ──采样──► data                μ ──采样──► Replay Buffer
   │             │                                  │
   │   更新       │                    小批采样 + 重要性采样
   ▼             ▼                                  ▼
  π_{t+1}   旧 data 作废 ✗            优化 π（可多轮复用同一批）✓

  样本效率: 低                        样本效率: 高
  稳定性  : 高（分布一致）            稳定性  : 需纠偏，否则发散
  探索    : 受当前策略限制            探索    : 行为策略可独立探索
```

## 6. 映射到大模型对齐（PPO / GRPO / DPO）

把上面的语言翻译到 LLM 对齐场景：「状态」≈ prompt + 已生成 token，「动作」≈ 下一个 token，「策略」≈ 语言模型本身。

| 算法 | 范式 | 数据来源 | 关键点 |
|---|---|---|---|
| **PPO**（RLHF 主力） | 近似 On-Policy | 当前 actor 现采样生成 | 用 clip 的重要性比值允许「微 Off-Policy」复用几个 epoch，平衡效率与稳定 |
| **GRPO** | On-Policy | 同一 prompt 采多条回答做组内对比 | 去掉 value 网络，用组内相对优势 |
| **DPO** | Off-Policy（离线） | **固定的偏好数据集**（人类标好的 chosen/rejected） | 完全不在线采样，把 RL 目标解析为分类损失，最省事 |

> 一句话连接：DPO 之所以能「不跑 RL」，正是因为它彻底走 Off-Policy——用别人（标注员）产生的偏好数据，直接闭式优化目标策略；而 PPO 必须让模型自己「下厨」（在线采样），所以更贵但更贴当前策略分布。这正是 §0 那句「自己下厨 vs 看食谱」在大模型里的具体落地。

## 实操：On-Policy 与 Off-Policy 的经典对照

在实际应用中，On-Policy 和 Off-Policy 算法的区别可以通过以下例子来说明：

**On-Policy 算法的例子：SARSA（State-Action-Reward-State-Action）**
在 SARSA 算法中，智能体（比如一个机器人）学习基于**当前正在执行**的动作和策略。假设我们正在教机器人导航一个迷宫，SARSA 算法会让机器人根据当前的策略（**包括探索步骤**）来学习价值函数。这就像是通过亲自尝试不同的食谱来学习烹饪。SARSA 会根据「当前动作、收到的奖励、下一个状态-动作对」来更新价值函数。

**Off-Policy 算法的例子：Q-Learning**
Q-Learning 是一个经典的 Off-Policy 方法。智能体可以观察其他智能体（比如其他机器人）成功的移动，并学习每个状态下的**最佳移动**，不管它自己在这个情况下会做什么。这就像是阅读食谱并学习烹饪方法，而不需要亲自下厨。Q-Learning 允许智能体从外部经验中提取有价值的策略，促进了一个多功能、高效的学习范式。

通过这些例子可以看到：On-Policy 方法直接从当前策略中学习，而 Off-Policy 方法则可以利用与当前策略不同的策略生成的数据来进行学习。这意味着 Off-Policy 方法可以更有效地利用数据（重复使用历史数据、更灵活地探索环境）；而 On-Policy 方法更直接地对当前策略进行优化，但可能需要更多探索来学到好策略。

简而言之，On-Policy 方法在学习时直接使用当前策略进行探索和学习，而 Off-Policy 方法则可以利用历史数据或模拟数据，学习一个与当前行为策略不同的目标策略。这使得 Off-Policy 方法在数据利用上更加高效，但也带来了额外的算法复杂性。

并排速记：

```
            行为策略 μ      目标策略 π      下一步用谁
  SARSA       π             π             实际动作 a'   → On-Policy
  Q-Learning  μ(可探索)      π(贪婪)        max_a' Q     → Off-Policy
```

## 常见问题/坑

| 问题/坑 | 说明 | 对策 |
|---|---|---|
| 把「在线/离线」误读成「实时/非实时」 | On/Off-Policy 区别在「采样策略是否等于优化策略」，不是「是否实时交互」 | 看的是 $\mu$ 与 $\pi$ 是否相等 |
| Off-Policy 直接拿旧数据训练就发散 | 分布不匹配，期望估计有偏 | 加重要性采样 $\rho=\pi/\mu$ 纠偏 |
| 重要性权重 $\rho$ 方差爆炸 | $\mu\to0$ 时 $\rho\to\infty$ | 做 clipping（PPO 的 ratio clip）或 weighted IS |
| 以为 PPO 是纯 On-Policy | PPO 用 clip 的比值复用几个 epoch，是「近似 On-Policy / 微 Off-Policy」 | 控制更新轮数与 KL，别让 $\pi$ 离采样分布太远 |
| On-Policy 探索不足陷局部最优 | 总按当前策略选动作 | 加 $\varepsilon$-greedy / 熵正则鼓励探索 |
| DPO 数据集陈旧导致「分布漂移」 | 离线数据是固定快照，与最新策略偏离大 | 周期性重采新偏好数据，或上在线 DPO 变体 |
