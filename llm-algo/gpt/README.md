## 0. 一句话锚点

> **GPT-1 = 用海量无标注文本「猜下一个词」预训练出一个 Transformer Decoder，再用少量有标注数据微调，就能横扫多个 NLP 任务。**

它要回答的根本问题是：**自然语言理解任务的标注数据很贵很少，但无标注文本几乎无限多——能不能先用无标注文本学到通用语言表示，再用一点点标注数据把它「点醒」成具体任务？**

GPT-1 的答案是「能」，而且效果惊人：在 12 个数据集里有 9 个刷新了 SOTA。

```
        无标注文本(便宜·海量)              有标注数据(昂贵·稀少)
        ┌──────────────────┐              ┌──────────────────┐
        │  BooksCorpus     │              │  情感分类/蕴含/   │
        │  ~7000 本书      │   ───────▶   │  问答/相似度...   │
        └────────┬─────────┘   迁移        └────────┬─────────┘
                 │                                   │
          [阶段一: 生成式预训练]              [阶段二: 判别式微调]
          自监督, 学"语言长什么样"           监督, 学"这个任务怎么做"
```

## 1. 地基 / 前置

### 1.1 什么是「语言模型」(Language Model, LM)

语言模型就是给一段文本算「**这段话有多自然/出现概率多大**」的模型。对一个词序列 $U = (u_1, u_2, \dots, u_n)$，它建模联合概率：

$$P(U) = \prod_{i=1}^{n} P(u_i \mid u_1, \dots, u_{i-1})$$

也就是把「整句话的概率」拆成「**每个词在它前文条件下出现的概率**」连乘。这种「**只看前文、从左到右预测下一个词**」的方式叫 **自回归 (autoregressive)**，是 GPT 全家族的灵魂。

```
句子:   "我  爱  自然  语言  处理"
预测:    ?   ?    ?     ?      ?
         ↑   ↑    ↑     ↑      ↑
        给BOS 给"我" 给"我爱" 给"我爱自然" 给"我爱自然语言"
        每一步: 只用左边已知词, 预测右边下一个词
```

### 1.2 自监督 (self-supervised)：标签从哪来

预训练阶段没有人工标签，但「下一个词」本身就是天然标签——把文本往右挪一位就是答案。这种「**从数据自己构造监督信号**」叫自监督，让我们能用无限的无标注文本训练。

### 1.3 Transformer Decoder：GPT 用的积木

GPT-1 用的是 Transformer 的 **Decoder 部分**，关键是 **带掩码的自注意力 (Masked Self-Attention)**：第 $i$ 个位置只能「看见」位置 $\le i$ 的词，看不见未来。这正好匹配自回归——预测下一个词时绝不能偷看答案。

```
普通注意力(BERT用): 每个词能看到左右全部 → 双向
                    [我][爱][NLP]  每个词 ←→ 所有词

掩码注意力(GPT用):  每个词只能看到自己及左边 → 单向
                    [我]      ← 只看 我
                    [我][爱]   ← 看 我,爱
                    [我][爱][NLP] ← 看 我,爱,NLP
```

一句话区别：**Encoder 双向（适合「理解」），Decoder 单向（适合「生成」）**。GPT 选 Decoder，是因为「猜下一个词」这件事天生需要单向。

## 2. 范式总览：两阶段是核心创新

GPT-1 真正的贡献不是某个新算子，而是**一套范式**：

```
┌─────────────────────────────────────────────────────────────┐
│  阶段一  Unsupervised Pre-training (无监督/自监督预训练)       │
│  数据: 海量无标注文本 (BooksCorpus)                            │
│  目标: 标准语言模型 —— 最大化 "猜对下一个词" 的概率            │
│  产出: 一个会"说话"的通用 Transformer Decoder                 │
└───────────────────────────┬─────────────────────────────────┘
                            │  迁移同一套参数 (不重新初始化!)
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  阶段二  Supervised Fine-tuning (有监督微调)                   │
│  数据: 具体任务的少量标注数据                                  │
│  目标: 任务损失 + (可选)语言模型辅助损失                       │
│  产出: 针对该任务的专用模型                                    │
└─────────────────────────────────────────────────────────────┘
```

精髓：**两个阶段共享同一个网络主干**。微调时几乎不加新结构（只加一个线性输出头），所以预训练学到的知识能最大程度保留下来——这叫「**最小化任务相关的架构改动**」。

## 3. 阶段一：生成式预训练 (Generative Pre-Training)

### 3.1 目标函数

给定无标注语料的 token 序列 $\mathcal{U} = \{u_1, \dots, u_n\}$，最大化如下对数似然：

$$L_1(\mathcal{U}) = \sum_{i} \log P(u_i \mid u_{i-k}, \dots, u_{i-1};\ \Theta)$$

- $k$：上下文窗口大小（往左看几个词）。
- $\Theta$：模型参数。
- 直观理解：**把文本里每个词，都当成「给定它前面 $k$ 个词，要被预测出来」的目标**，让模型对真实出现的词给出尽量高的概率。

### 3.2 前向计算（一层层走）

设输入 token 的上下文向量 $U = (u_{-k}, \dots, u_{-1})$：

$$h_0 = U W_e + W_p$$
$$h_l = \text{transformer\_block}(h_{l-1}),\quad l = 1, \dots, L$$
$$P(u) = \text{softmax}(h_L W_e^{\top})$$

- $W_e$：**token 嵌入矩阵**（把词 id 变成向量），最后输出层复用它的转置（权重绑定 weight tying）。
- $W_p$：**位置嵌入**（GPT-1 用的是可学习的位置嵌入，不是 sin/cos）。
- 中间 $L=12$ 个 transformer block（带掩码注意力 + 前馈网络）。

```
  token id ──[W_e 查表]──▶ ┐
                          ├──(相加)──▶ h_0 ──[block×12]──▶ h_L ──[W_e^T+softmax]──▶ 下一词概率
  位置 id ──[W_p 查表]──▶ ┘
```

### 3.3 为什么用单向（左到右）语言模型？

因为目标就是「**预测下一个词**」。如果允许看右边，就等于把答案告诉了模型，训练目标坍塌成 trivial。单向是自回归生成的必然要求——也正是它日后让 GPT 路线天然擅长「生成」的根源。

## 4. 阶段二：判别式微调 (Discriminative Fine-tuning)

### 4.1 怎么把语言模型变成分类器

有标注数据集 $\mathcal{C}$：每条样本是输入 token 序列 $x^1, \dots, x^m$ 加一个标签 $y$。做法：

1. 把序列喂进预训练好的 Decoder，取**最后一个 token** 在最后一层的隐状态 $h_L^m$（它「看过」整句，是整句的浓缩表示）。
2. 接一个**新加的线性层** $W_y$，输出类别分布：

$$P(y \mid x^1, \dots, x^m) = \text{softmax}(h_L^m\, W_y)$$

3. 微调损失（最大化预测对标签的概率）：

$$L_2(\mathcal{C}) = \sum_{(x,y)} \log P(y \mid x^1, \dots, x^m)$$

```
  输入序列 ─▶ [预训练 Decoder (12层, 权重复用)] ─▶ 最后token隐状态 h_L^m ─▶ [新线性头 W_y] ─▶ 类别
                  ↑ 唯一从零初始化的就是 W_y, 整个主干都是预训练来的
```

### 4.2 辅助语言模型损失（一个小但关键的 trick）

GPT-1 发现：微调时**额外保留一点语言模型目标 $L_1$** 当辅助损失，能 (a) 改善泛化、(b) 加速收敛。于是总损失是：

$$L_3(\mathcal{C}) = L_2(\mathcal{C}) + \lambda \cdot L_1(\mathcal{C})$$

$\lambda$ 是权重（论文里约 0.5，以官方为准）。直觉：让模型在学任务的同时别忘了「怎么好好说话」，相当于一个正则项。

## 5. 输入变换：不改架构适配 4 类任务

难点：分类只有一段输入，但「文本蕴含」「相似度」「问答」有多段输入。GPT-1 的巧妙之处是——**不为每个任务设计新结构，而是把不同任务的输入「改写」成一段连续序列**，加上特殊分隔符 (delimiter)，统一喂给同一个 Decoder。这叫 **traversal-style / task-specific input transformations**。

```
分类 (Classification):
   [Start] 文本 [Extract] ──▶ Transformer ──▶ Linear ──▶ 类别

文本蕴含 (Entailment):
   [Start] 前提 [Delim] 假设 [Extract] ──▶ Transformer ──▶ Linear

相似度 (Similarity)  (两种顺序都算, 因为相似度对称):
   [Start] 句A [Delim] 句B [Extract] ─┐
   [Start] 句B [Delim] 句A [Extract] ─┴(隐状态相加)─▶ Linear

多选问答 (Multiple Choice / QA):
   [Start] 文档+问题 [Delim] 选项1 [Extract] ─▶ Transformer ─▶ Linear ─▶ 分数1
   [Start] 文档+问题 [Delim] 选项2 [Extract] ─▶ Transformer ─▶ Linear ─▶ 分数2
   ...                                                          ─▶ softmax 选最高
```

要点：`[Start]`、`[Delim]`、`[Extract]` 是新增的特殊 token，靠微调学到它们的嵌入。**架构纹丝不动，变的只是输入排布**——这正是「minimal architecture change」哲学的体现。

## 6. 模型架构与规模（约/以官方为准）

| 项目 | GPT-1 取值（约） |
|------|------------------|
| 结构 | Transformer **Decoder-only** |
| 层数 $L$ | 12 |
| 隐藏维度 $d_{model}$ | 768 |
| 注意力头数 | 12（每头 64 维）|
| 前馈层维度 | 3072（= 4 × 768）|
| 位置编码 | 可学习位置嵌入（learned），最大长度 512 |
| 激活函数 | GELU |
| 参数量 | 约 1.17 亿（117M）|
| 分词 | BPE（字节对编码），词表约 40000 |

```
单个 Transformer Block 内部 (GPT-1, Pre-LN 之前的 Post-LN 风格):
   输入 ──▶ Masked Multi-Head Self-Attention ──▶ +残差 ──▶ LayerNorm
        ──▶ Position-wise Feed-Forward (768→3072→768, GELU) ──▶ +残差 ──▶ LayerNorm ──▶ 输出
   ×12 层堆叠
```

> 对照后代：GPT-2 把层数/维度放大并改用 Pre-LN，GPT-3 进一步暴力放大到 1750 亿参数。架构骨架几乎一脉相承，详见 [[llm-algo/gpt2/模型架构]]。

## 7. 训练细节（约/以官方为准）

| 项目 | 设置（约） |
|------|-----------|
| 预训练语料 | **BooksCorpus**，约 7000 本未出版书，长连续文本（有利于学长程依赖）|
| 上下文长度 | 512 tokens |
| 优化器 | Adam，峰值学习率约 2.5e-4，带 warmup 线性升 + 余弦退火 |
| Batch | 约 64 个连续序列 × 512 token |
| 训练时长 | 约 100 个 epoch |
| 正则 | Dropout 0.1、权重衰减、attention dropout |

为什么选 BooksCorpus 而非短文本（如打乱的句子）？因为书里有**长段连续叙事**，能逼模型学到跨越很多词的长程依赖，这对生成式预训练特别重要。

## 8. 路线对比：GPT vs ELMo vs BERT

这是理解 2018 年 NLP 大格局的关键三角。

```
                  方向性          迁移方式            主干结构
   ELMo (2018初)  双向(浅拼接)    特征式(feature)     双向 LSTM
   GPT-1(2018中)  单向(左→右)     微调式(fine-tune)   Transformer Decoder
   BERT (2018末)  双向(深度)      微调式(fine-tune)   Transformer Encoder
```

### 8.1 两个正交的维度

- **方向性**：单向（GPT，只看左文）vs 双向（BERT/ELMo，左右都看）。
- **迁移方式**：特征式（ELMo：把预训练表示当固定特征，喂给另搭的任务模型）vs 微调式（GPT/BERT：整个网络参数继续训练）。

### 8.2 详细对照表

| 维度 | ELMo | **GPT-1** | BERT |
|------|------|-----------|------|
| 时间 | 2018.02 | 2018.06 | 2018.10 |
| 主干 | 双向 LSTM | **Transformer Decoder** | Transformer Encoder |
| 上下文 | 双向（两个独立单向 LSTM 拼接，浅）| **单向（左→右）** | 双向（同一网络内深度融合）|
| 预训练目标 | 双向 LM | **标准 LM（猜下一词）** | MLM（完形填空）+ NSP |
| 下游迁移 | 特征式（freeze）| **微调（整模型）** | 微调（整模型）|
| 天生擅长 | 表示抽取 | **文本生成** | 文本理解 |

### 8.3 为什么 BERT 在「理解」任务上常更强，但 GPT 路线最终走得更远？

- **理解任务**（情感、蕴含、问答里判断对错）需要同时看左右文，BERT 的双向是天然优势，所以当年 GLUE 榜单 BERT 普遍领先。
- 但 GPT 的**单向自回归**让它天然能「生成」——一个词一个词往外吐。当模型规模爆炸式增大（GPT-2/3），「**生成 + 上下文学习 (in-context learning)**」展现出 BERT 这类「填空式」模型难以企及的通用性。今天的对话大模型几乎全是 Decoder-only 自回归路线，源头正是 GPT-1。

> 一句话：**BERT 赢了 2018-2019 的榜单，GPT 路线赢了 2020 之后的时代。** 详见 [[llm-algo/bert]]。

## 9. 贡献与历史地位

1. **确立「预训练 + 微调」范式**：证明无标注文本里学到的通用表示，能用微调高效迁移到多种下游任务，而无需为每个任务从零设计模型。
2. **奠定 Decoder-only 自回归路线**：选择单向 LM + Transformer Decoder，成为 GPT-2/3/4、LLaMA、Qwen 等几乎所有现代生成式大模型的统一骨架。
3. **task-agnostic 架构 + 输入变换**：用统一结构 + 输入改写覆盖分类/蕴含/相似度/问答，少改架构、多靠数据，理念延续至今的「指令统一接口」。
4. **辅助 LM 损失**：微调时保留语言建模目标提升泛化，是早期「多任务正则」思想。
5. **实证规模红利的雏形**：12 任务 9 项 SOTA，并观察到「层数越多、预训练越充分，下游越好」，为后来的 Scaling Law 埋下伏笔。

## 数值例子 / 对照

### 例 1：自回归概率手算

句子 "I love NLP"（已分词为 3 个 token，外加句首符号），语言模型给出的句子概率：

$$P(\text{"I love NLP"}) = P(\text{I}\mid \text{[BOS]}) \cdot P(\text{love}\mid \text{[BOS] I}) \cdot P(\text{NLP}\mid \text{[BOS] I love})$$

假设模型预测：
- $P(\text{I}\mid \text{[BOS]}) = 0.10$
- $P(\text{love}\mid \text{[BOS] I}) = 0.05$
- $P(\text{NLP}\mid \text{[BOS] I love}) = 0.20$

则 $P = 0.10 \times 0.05 \times 0.20 = 0.001$。

训练时用**负对数似然**当损失（数值更稳）：

$$-\log P = -(\log 0.10 + \log 0.05 + \log 0.20) \approx -(-2.30 - 3.00 - 1.61) = 6.91$$

模型训练就是不断调参，让真实出现的词概率变大、$-\log P$ 变小。

### 例 2：参数量从哪来（粗估，约）

以 $d=768$、$L=12$、FFN 倍数 4 为例，单层主要权重：
- 注意力 $Q,K,V,O$ 四个矩阵：$4 \times 768 \times 768 \approx 2.36\text{M}$
- 前馈两个矩阵：$2 \times 768 \times 3072 \approx 4.72\text{M}$
- 单层合计约 7.1M，$\times 12$ 层 $\approx 85\text{M}$。

再加上 token 嵌入（词表约 4 万 $\times 768 \approx 30\text{M}$）和位置嵌入等，总量约 **1.17 亿**，与官方公布的 117M 量级吻合（精确值以官方为准）。

## 常见问题

| 问题 | 回答 |
|------|------|
| GPT 用的是 Transformer 的哪一半？ | **Decoder 部分**（带掩码自注意力），不用 Encoder。|
| 为什么 GPT 是单向、BERT 是双向？ | GPT 目标是「猜下一词」（自回归），看右边=偷看答案；BERT 目标是「完形填空」（MLM），需要左右文一起看。|
| 「生成式预训练」和「判别式微调」分别指什么？ | 预训练是生成式（建模 $P(\text{下一词})$，自监督）；微调是判别式（建模 $P(y\mid x)$，有监督分类）。|
| 微调时改了网络结构吗？ | 几乎没有，只在顶部加一个线性分类头 $W_y$，主干完全复用预训练参数。|
| 不同任务输入长度/段数不同怎么办？ | 用 task-specific 输入变换：加 `[Start]/[Delim]/[Extract]` 特殊符号，把多段拼成一段连续序列。|
| GPT-1 用什么位置编码？ | **可学习的位置嵌入**（learned positional embedding），不是 sin/cos 固定编码。|
| 辅助 LM 损失有什么用？ | 微调时保留语言建模目标当正则，提升泛化、加速收敛。|
| GPT-1 参数量多大？ | 约 1.17 亿（117M），12 层（以官方为准）。|
| 为什么用 BooksCorpus？ | 书有长连续文本，利于学长程依赖，比打乱的短句更适合生成式预训练。|
