## 0. 一句话锚点

GLM-130B = **GLM 目标**（统一自回归与空白填充）+ **双语**（中文优先的开源千亿）+ **工程稳定性**（DeepNorm + 嵌入缩放扛住 spike）+ **可部署**（INT4 单机 4 卡）。

一句话记忆：**「一个目标统一生成与理解，一套工程让千亿训得动、量化跑得起。」**

## 1. 地基：三种预训练目标，GLM 解决什么

要理解 GLM-130B，先理解它名字里的 **GLM (General Language Model)** 到底是哪种「目标函数」。预训练模型按「怎么遮、怎么预测」分三大流派：

```
 流派        代表        机制                         强项        弱项
 ───────────────────────────────────────────────────────────────────
 自回归 AR   GPT         从左到右逐字预测下一个        生成强       不能双向看上下文
 自编码 AE   BERT        随机遮词 [MASK] 双向还原      理解强       不能自然生成长文
 编码-解码   T5/BART     遮一段→另一头重建            两者兼顾     参数翻倍、结构重
 ───────────────────────────────────────────────────────────────────
 GLM         GLM-130B    "自回归空白填充":             生成+理解    需要特殊位置编码
                         遮掉连续片段, 在原位置
                         用自回归方式逐字补回
```

**核心矛盾**：GPT 会生成但看不到右侧上下文；BERT 双向但不会生成。GLM 的设计哲学是——**用一个目标同时拿到双向理解和自回归生成**，不靠两套模型。

> 为什么这很重要？千亿模型训一次就耗几百卡几十天，没人想为「理解」和「生成」各训一个。GLM 让一个 130B 模型既能做 NLU 又能做 NLG。

## 2. GLM 训练目标：自回归空白填充（Autoregressive Blank Infilling）

这是 GLM 的灵魂。流程分三步：**挖空 → 打乱片段 → 自回归补回**。

### 2.1 直观流程图

```
原句:  x1 x2 x3 x4 x5 x6
       │
       ├─ Step1 采样若干"连续片段"挖空 (泊松λ≈3, 总遮 15%)
       │     遮掉 [x3] 和 [x5 x6]
       ▼
Part A(损坏文本, 双向可见):
       x1 x2 [M] x4 [M]          ← [M] 是 [MASK] 占位
       │
       ├─ Step2 被遮片段随机打乱顺序, 排到 Part B
       ▼
Part B(待填空白, 自回归生成):
       [S] x5 x6 │ [S] x3        ← [S]=起始符, 逐字生成
                 │
       每个空白内部"从左到右"预测, 但能看到整个 Part A(双向)
```

- **Part A**：损坏后的文本，内部 **双向注意力**（像 BERT，能左右看）。
- **Part B**：被挖走的片段，**自回归生成**（像 GPT，逐字、只看已生成的 + 整个 Part A）。

一句话：**Part A 给你双向理解，Part B 给你自回归生成，合在一个目标里。**

### 2.2 注意力掩码（关键）

GLM 用一张「拼接的」注意力掩码，让两半行为不同：

```
        被注意的 →   A区(x1 x2 [M] x4 [M])   B区([S]x5x6  [S]x3)
 查询↓
 A区   x1 x2 ... ┃   ■ ■ ■ ■ ■ (全可见,双向)  ░ ░ ░  ░ ░ (看不到B)
 ─────────────────────────────────────────────────────────────
 B区   [S]x5x6   ┃   ■ ■ ■ ■ ■ (能看整个A)    ▲下三角(因果,只看左)
       [S]x3     ┃   ■ ■ ■ ■ ■                ▲下三角
```

- `■` = 可注意，`░` = 屏蔽，`▲` = 因果（下三角）。
- B 区能看 A 区全部（双向 context），但 B 区内部是因果（保证生成合法）。

### 2.3 二维位置编码（2D Positional Encoding）

普通模型一个 token 一个位置 id。GLM 给每个 token **两个**位置：

```
token:      x1 x2 [M] x4 [M] │ [S] x5 x6 │ [S] x3
位置1(全局): 1  2   3   4   5 │   3   3  3 │   5   5   ← 片段在原文的位置
位置2(局部): 0  0   0   0   0 │   0   1  2 │   0   1   ← 片段内部偏移
```

- **位置1**：这个被遮片段在原句里站在哪（让模型知道空白的全局锚点）。
- **位置2**：该 token 在被遮片段**内部**的第几个（自回归生成时的局部序号）。

> 为什么要 2D？因为 Part B 生成时，模型必须知道「我在填哪个空、填到第几个字」，又不能泄露空白长度。2D 位置正好编码这两点。

### 2.4 两种 MASK：[MASK] 与 [gMASK]

| 标记 | 遮的内容 | 用途 | 对应任务 |
|------|----------|------|----------|
| `[MASK]` | 句中**短**连续片段（NLU 风格） | 完形/理解 | BERT 式 |
| `[gMASK]` | 句**末长**片段（直到结尾） | 长文生成 | GPT 式 |

GLM-130B 混合用两者：**`[MASK]` 占多数训理解，少量 `[gMASK]` 训长文生成**。推理时给 `[gMASK]` 就能像 GPT 一样续写。这就是「一个目标统一两件事」的工程落地。

## 3. 数据：双语 + 95%/5% 两段式目标

GLM-130B 在 **超过 4000 亿个双语 token**（约 2000 亿英文 + 2000 亿中文，数字约，以官方为准）上预训练。它是当时少有的 **中文优先开源千亿**——同期 BLOOM 是多语种偏英、OPT/GPT-3 偏英。

预训练目标由两部分组成：

```
┌────────────────────────────────────────────────────────────┐
│ 95%  自监督自回归空白填充 (GLM 目标)                          │
│      ├ 公开大规模语料 (Pile 等英文 + Wudao 等中文)            │
│      └ 学语言本身: 双向理解 + 自回归生成                       │
├────────────────────────────────────────────────────────────┤
│  5%  多任务指令预训练 (MIP, Multi-task Instruction Pretrain) │
│      ├ T0++ 与 DeepStruct 中 ~70 个数据集的抽样子集           │
│      └ 格式: 指令式多任务、多提示的 seq2seq 生成              │
└────────────────────────────────────────────────────────────┘
```

- **为什么混 5% 指令数据？** 让模型在预训练阶段就「见过任务格式」，从而具备**零样本学习**能力，并支持**英文→中文的零样本跨语言迁移**（在英文任务上学的能力迁到中文）。
- **为什么是 5% 而非更多？** 太多会让模型过拟合任务模板、损失通用语言建模能力；5% 是「点到为止」的甜点。

> 这一思路（预训练即混入少量指令数据）后来在很多模型里被验证有效，是 GLM-130B 的前瞻设计之一。

## 4. 架构与归一化：后归一化 + DeepNorm + 缩放

千亿模型最难的不是「设计」而是「训得稳」。GLM-130B 的稳定性核心是归一化方案的选择。先讲清 Pre-LN vs Post-LN。

### 4.1 Pre-LN vs Post-LN 是什么

Transformer 每个子层（注意力 / FFN）外面包一层 LayerNorm，放的位置有两派：

```
Post-LN (原始 Transformer):           Pre-LN (GPT-3 等多数大模型):
  x ──┬──────────────┐                 x ──┬──── LN ── Sublayer ──┐
      │           Sublayer                 │                      ▼
      └──── + ◄──────┘                      └──────── + ◄──────────┘
            │                                         │
           LN  ← 归一化在残差相加"之后"               x_out (LN 在相加"之前")
            │
          x_out
```

- **Pre-LN**：训练稳、好收敛，**但**深层模型表达能力略弱（梯度被"过度归一"）。
- **Post-LN**：表达能力强、效果上限高，**但**深层极易梯度爆炸/loss 发散，难训。

GLM-130B 想要 Post-LN 的效果，又要避开它的不稳定——答案是 **DeepNorm**。

### 4.2 DeepNorm：可控的 Post-LN

DeepNorm 在 Post-LN 残差里给「输入支路」乘一个放大系数 $\alpha$，给「初始化」乘一个缩小系数 $\beta$：

$$x_{out} = \text{LayerNorm}\big(\alpha \cdot x + \text{Sublayer}(x)\big)$$

对 $N$ 层 Encoder-only/解码结构，取（约值，以官方为准）：

$$\alpha = (2N)^{1/2}, \qquad \beta = (2N)^{-1/2}$$

```
直觉:
   α 放大残差主干 ──► 让深层信息"直通", 防止 Post-LN 把信号洗没
   β 缩小子层初值 ──► 让训练初期子层"轻推一把", 不一上来就炸
   合起来: 既保留 Post-LN 上限, 又拿到接近 Pre-LN 的稳定性
```

GLM-130B 96 层用 DeepNorm-style Post-LN，是它能稳定训完的关键之一。

## 5. 训练稳定性：千亿训练的血泪经验

这是 GLM-130B 论文里最有价值的工程贡献——**怎么不让千亿训练崩**。

### 5.1 问题：Loss Spike（损失尖刺）

```
loss
  │      ╱╲  ← spike! 突然飙升, 可能直接 NaN 整轮报废
  │   ╲ ╱  ╲╱╲___
  │    ╲___      ╲____  正常应该平滑下降
  │                   ╲_____
  └──────────────────────────► step
```

千亿模型上，某一步梯度异常会让 loss 突然爆炸，轻则停滞、重则 NaN 全废，几十卡几天白跑。

### 5.2 解法一：嵌入层梯度缩放（Embedding Gradient Shrink, EGS）

诊断发现：**不稳定常源于嵌入层（embedding）的梯度异常大**。解法是把嵌入层梯度乘一个收缩系数 $\alpha$（如 0.1）：

```
forward:  emb_out = emb(x)                    ← 前向不变
backward: grad_emb = α · grad_emb  (α≈0.1)    ← 只缩小嵌入的梯度

实现技巧(stop-gradient trick):
  word_emb = emb * α + (emb * (1-α)).detach()
  ─► 前向值不变, 反向只有 α 那份带梯度 ⇒ 梯度被缩到 α 倍
```

效果：嵌入梯度被「踩刹车」，spike 频率大幅下降，几乎不影响最终效果。**这是 GLM-130B 稳定性最关键的一招。**

### 5.3 解法二：混合精度选择（FP16 → 谨慎用 BF16/动态）

- 大模型用 FP16 时，数值范围窄容易溢出；GLM-130B 在注意力 softmax 等敏感处做了数值缩放与上溢处理。
- 经验：**敏感算子升精度、用更稳的归一化、配合 loss-scale 动态调整**。

### 5.4 其他经验汇总

```
┌─ 稳定性工具箱 ────────────────────────────────────┐
│ DeepNorm 后归一化     → 深层不发散                  │
│ 嵌入梯度缩放(α≈0.1)   → 杀 loss spike(最关键)       │
│ 梯度裁剪 clip         → 限制单步更新幅度            │
│ 跳过坏 batch / 回滚    → spike 时回退 checkpoint     │
│ 敏感算子升精度        → 避免 FP16 溢出              │
└──────────────────────────────────────────────────┘
```

> 一句话总结这一节：**千亿训练的成败 70% 在工程稳定性，而稳定性的命门在嵌入层梯度。**

## 6. INT4 量化部署：为什么 GLM 能几乎无损

GLM-130B 的另一大亮点：**INT4 量化几乎不掉点**，让原本需要 8×A100 的模型跑在 **4×RTX 3090(24G) 或 8×RTX 2080Ti(11G)** 上。

### 6.1 量化是什么（最底层）

把权重从 FP16（16 bit）压到 INT4（4 bit），**显存直接降到 1/4**：

```
FP16 权重:  16 bit/参数   130B × 2 字节 ≈ 260 GB
INT8 权重:   8 bit/参数   130B × 1 字节 ≈ 130 GB
INT4 权重:   4 bit/参数   130B × 0.5字节 ≈  65 GB  ← 4 卡 24G 装得下!
```

量化公式（对称量化，按通道）：

$$w_{int} = \text{round}\left(\frac{w}{s}\right), \quad s = \frac{\max(|w|)}{2^{b-1}-1}$$

反量化：$\hat{w} = w_{int} \cdot s$。$b=4$ 时只有 16 个量化档位。

### 6.2 为什么 GLM-130B INT4 几乎无损（关键洞察）

```
普通模型 INT4 掉点严重 ── 因为权重分布里有少数"离群值(outlier)"
                          被 4bit 粗粒度量化压扁 → 精度崩

GLM-130B 的发现:
  ① 权重量化(weight-only)而非激活量化 → 避开激活 outlier 难题
  ② GLM 结构权重分布相对"良性", 离群值少且集中
  ③ 仅权重 INT4 + 激活保持 FP16 计算 → 精度损失可忽略
  ──► 这是 GLM-130B 能 INT4 而很多模型只能 INT8 的核心原因
```

### 6.3 部署对照

| 精度 | 约显存 | 最低硬件(约) | 精度损失 |
|------|--------|--------------|----------|
| FP16 | ~260 GB | 8×A100 40G | 基线 |
| INT8 | ~130 GB | 4×A100 40G | 几乎无 |
| **INT4** | **~65 GB** | **4×3090 / 8×2080Ti** | **几乎无（亮点）** |

> 意义：把千亿模型从「只有大厂能跑」拉到「实验室/小团队能跑」，这是 GLM-130B 普惠性的实锤。

## 8. 数值例子 / 横向对照

### 8.1 INT4 显存手算

> 问：GLM-130B INT4 权重要多少显存？4 张 3090(24G) 够吗？

```
权重显存 = 参数量 × 每参字节
        = 130×10⁹ × 0.5 字节        (INT4 = 4bit = 0.5 字节)
        = 65 ×10⁹ 字节
        ≈ 65 GB

4 × RTX 3090 = 4 × 24 GB = 96 GB 显存池
65 GB(权重) + KV cache/激活 余量 < 96 GB  ✓ 装得下
```

再算 FP16 对比：$130\times10^9 \times 2 = 260$ GB，需 8×A100(40G)=320G 才够 → **INT4 把硬件门槛从 8×A100 降到 4×3090，成本下降一个数量级。**

### 8.2 GLM 目标 token 利用率

15% 遮蔽、片段平均长 3，则一句 100 token：

```
被遮 token ≈ 15 个 → 分成约 15/3 = 5 个片段
Part A: 100 - 15 + 5(MASK占位) = 90 token (双向)
Part B: 15 + 5(起始符) = 20 token (自回归)
─► 同一句既产生"理解信号"(A)又产生"生成信号"(B), 一份数据两用
```

### 8.3 横向对比表

| 模型 | 参数 | 语言 | 目标 | 归一化 | 量化亮点 | 开源 |
|------|------|------|------|--------|----------|------|
| **GLM-130B** | 130B | 中英双语 | **GLM 空白填充** | **DeepNorm Post-LN** | **INT4 无损** | ✔ |
| GPT-3 | 175B | 英文为主 | 自回归 AR | Pre-LN | — | ✘ |
| OPT-175B | 175B | 英文 | 自回归 AR | Pre-LN | INT8 | ✔ |
| [[llm-algo/bloom]] | 176B | 46 语种(偏英) | 自回归 AR | Pre-LN + embed-LN | INT8 | ✔ |
| T5 | 11B | 英文 | span 重建(enc-dec) | Pre-LN | — | ✔ |

**记忆点**：GLM-130B 在三件事上独树一帜——**双语优先、GLM 统一目标、INT4 可部署**。

## 9. 意义与影响

```
GLM-130B(2022)
   │
   ├─ 证明"千亿稳定训练"可复现 ── 公开 spike/嵌入缩放等血泪经验
   ├─ 证明"中文优先开源千亿"可行 ── 填补中文大模型空白
   ├─ 证明"INT4 千亿可部署" ── 把门槛拉到单机多卡
   │
   ▼
ChatGLM-6B / ChatGLM2 / ChatGLM3 (见 [[llm-algo/chatglm/README]])
   ── GLM 目标 + 对齐微调, 走向消费级、产品化
```

- **学术意义**：系统性公开了千亿训练的工程细节（loss spike、嵌入梯度缩放、DeepNorm），是后来者的「避坑指南」。
- **生态意义**：开放权重 + INT4 部署，让国内外大量团队第一次能上手千亿模型。
- **产品意义**：直接孵化了 ChatGLM 系列，成为国产开源对话模型的源头之一。

## 常见问题

| 问题 | 答 |
|------|----|
| GLM 和 GPT 最大区别？ | GPT 纯自回归（单向）；GLM 用空白填充，Part A 双向 + Part B 自回归，一个目标兼顾理解与生成。 |
| `[MASK]` 和 `[gMASK]` 区别？ | `[MASK]` 遮句中短片段（理解），`[gMASK]` 遮句末长片段（长文生成）。 |
| 为什么用 Post-LN 不用更稳的 Pre-LN？ | Post-LN 效果上限高，配 DeepNorm 的 α/β 缩放后既稳又强。 |
| loss spike 怎么治？ | 最关键是**嵌入层梯度缩放**（α≈0.1）；辅以梯度裁剪、回滚 checkpoint、敏感算子升精度。 |
| 为什么 GLM 能 INT4 而很多模型只能 INT8？ | 只做权重量化（避激活 outlier）+ GLM 权重分布良性、离群值少 → INT4 几乎无损。 |
| 2D 位置编码作用？ | 位置1=片段在原文全局位置；位置2=片段内部偏移；让自回归生成知道"填哪个空、填到第几字"。 |
| 5% 指令数据有什么用？ | 预训练即见任务格式 → 零样本学习 + 英→中跨语言零样本迁移。 |
| 它和 ChatGLM 什么关系？ | GLM-130B 是基座/鼻祖；ChatGLM 系列在其目标基础上加对齐微调，做成对话产品。 |
