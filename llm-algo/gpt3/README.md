## 0. 一句话锚点

**GPT-2 → GPT-3 之间，模型架构基本没变，变的只是"变大了 100 倍"。而仅仅是变大，就让模型学会了一件 GPT-2 做不好的事：你在 prompt 里给它几个示范，它当场就能照做新任务，完全不用再训练。** 这件事叫 **in-context learning**，它的强度随规模"涌现"，是 GPT-3 论文标题《Language Models are Few-Shot Learners》的全部含义。

## 1. 地基 / 前置

读懂 GPT-3 只需要三个原子概念，先逐一拆到底。

**(1) 自回归语言模型(Autoregressive LM)**
模型做的唯一一件事：给定前面所有词，预测下一个词的概率分布。形式化为

$$P(x_1, x_2, \dots, x_n) = \prod_{t=1}^{n} P(x_t \mid x_1, \dots, x_{t-1})$$

训练目标是最大化真实文本的对数似然(等价于最小化交叉熵 / 困惑度 perplexity)。**没有"任务标签"，只有"猜下一个词"。** 这正是后面 in-context learning 能成立的根基——任何任务都能被改写成"续写文本"。

**(2) token(词元)**
文本先被 BPE 分词器切成子词单元(token)，每个 token 映射成一个整数 id，再查嵌入表变成向量。GPT-3 词表约 50257。"175B 参数""300B token"里的 token 就是它。

**(3) Transformer Decoder(仅解码器)**
GPT 系列只用 Transformer 的**解码器堆叠**，核心是**带因果掩码(causal mask)的自注意力**：第 $t$ 个位置只能看到 $\le t$ 的位置，保证"预测下一个词"不偷看未来。

```
          输入 tokens
             │
   [Token Embedding] + [Position Embedding]   ← 把 id 变向量、加位置信息
             │
   ┌─────────▼──────────┐  ×  N 层 (GPT-3 175B: N=96)
   │  Masked Multi-Head  │     │
   │   Self-Attention    │     │  每层结构与 GPT-2 完全一致
   │        + 残差/LN     │     │
   │  Feed-Forward (MLP)  │     │
   │        + 残差/LN     │     │
   └─────────┬──────────┘     ▼
             │
   [LayerNorm] → [Linear → 词表] → softmax → 下一个 token 概率
```

> 想看每一层内部(注意力怎么算、LN 放哪)请跳 [[llm-algo/gpt2/模型架构]]，GPT-3 与之**逐字相同**，本文不再重复。

## 2. 与 GPT-2 的差异：几乎只有"规模"

这是理解 GPT-3 最重要的一句话：**它不是一个新架构，而是一个被放大的 GPT-2。**

```
              GPT-2 (最大)        GPT-3 (最大)        倍数
参数量         1.5 B              175 B              ~117×
层数 N         48                 96                 2×
隐藏维度 d     1600               12288              7.68×
注意力头数     25                 96                 ~4×
上下文长度     1024               2048               2×
训练 token     ~10 B 量级         300 B              ~30×
架构           Transformer 解码器  同左(几乎逐字)      —
```

**唯一值得一提的架构微调**：GPT-3 在注意力中交替使用 **dense(稠密)与 locally banded sparse(局部带状稀疏)注意力模式**(借鉴 Sparse Transformer)，以缓解长序列注意力的开销。除此之外——激活函数(GELU)、Pre-LN、残差结构、BPE 分词——**全部沿用 GPT-2**。

一句话记忆：

```
GPT-2 ──「同一张图纸，按比例放大 ~100×」──▶ GPT-3
        (层更深、更宽、头更多、数据更多)
```

正因为"只是放大"，GPT-3 的全部惊喜都来自**规模本身**，而不是某个聪明的新模块。这把"规模"推到了研究舞台中央。

## 3. 175B 规模拆解

OpenAI 一口气训练了 **8 个尺寸**(从 1.25 亿到 1750 亿)，专门用来观察"能力随规模如何变化"。

```
模型名          参数量     层数 N   隐藏维 d   头数 h   每头维度
GPT-3 Small     125 M      12       768       12       64
GPT-3 Medium    350 M      24       1024      16       64
GPT-3 Large     760 M      24       1536      16       96
GPT-3 XL        1.3 B      24       2048      24       128
GPT-3 2.7B      2.7 B      32       2560      32       80
GPT-3 6.7B      6.7 B      32       4096      32       128
GPT-3 13B       13 B       40       5140      40       128
GPT-3 175B ★    175 B      96       12288     96       128
 (即 "GPT-3" / "davinci")
```

注意一个规律：**每头维度基本固定在 64~128，靠"加更多头 + 加更多层 + 加宽"一起把参数堆上去。**

**参数量怎么来的(手算近似)**
Transformer 每层参数主要由两块构成：

- 注意力(QKVO 四个投影矩阵)：$4 d^2$
- 前馈 MLP(通常 $4d$ 宽)：$2 \times d \times 4d = 8 d^2$

每层约 $12 d^2$，$N$ 层共 $12 N d^2$。对 175B：

$$12 \times 96 \times 12288^2 \approx 12 \times 96 \times 1.51\times10^8 \approx 1.74 \times 10^{11} \approx 174\text{B}$$

再加上嵌入表 $50257 \times 12288 \approx 0.6\text{B}$，与官方 175B 吻合。**这说明参数几乎全在 Transformer 主体，嵌入只占零头。**

## 4. In-context Learning：GPT-3 的灵魂

这是 GPT-3 真正的创新点。传统范式是"预训练 + 在下游任务上微调(fine-tune，更新权重)"。GPT-3 提出：**别微调了，直接把任务说明和几个示范写进 prompt，模型在一次前向推理中就"现学现做"。** 权重一个都不动。

按"给几个示范"分三档：

```
┌──────────── Zero-shot(零样本) ────────────┐
│  把英文翻成法文：                              │
│  cheese =>                ← 只给任务描述         │
└────────────────────────────────────────────┘

┌──────────── One-shot(单样本) ─────────────┐
│  把英文翻成法文：                              │
│  sea otter => loutre de mer   ← 给 1 个示范     │
│  cheese =>                                    │
└────────────────────────────────────────────┘

┌──────────── Few-shot(少样本，K 个示范) ────┐
│  把英文翻成法文：                              │
│  sea otter => loutre de mer                  │
│  peppermint => menthe poivrée                │
│  plush giraffe => girafe peluche   ← K 个示范   │
│  cheese =>                ← 模型续写出答案       │
└────────────────────────────────────────────┘
```

**为什么这能 work？** 因为自回归模型本质是"续写最可能的文本"。当 prompt 里已经出现"英文 => 法文"的几个范例，那么"接着 cheese => 后面最该出现的文本"就是它的法文 `fromage`。任务没有被"学进权重"，而是被**临时编码进了上下文(激活)**。所以也叫 **in-context learning** 或 **prompt-based learning**。

```
传统 fine-tune:   数据 → 反向传播 → 改权重 → 部署(每个任务一份权重)
in-context:       数据(示范)写进 prompt → 一次前向 → 出答案(同一份权重通吃)
                  └── 不更新任何参数 ──┘
```

**关键观测(论文核心图)**：示范数 $K$ 越多、模型越大，few-shot 准确率越高；而且 **few-shot 与 zero-shot 的差距随模型变大而拉开**——小模型给再多示范也学不会，大模型才"看几眼就懂"。这把我们带向下一节：涌现。

## 5. 涌现(Emergence)：能力随规模"跳变"

**涌现 = 某种能力在小模型上几乎为 0，到了某个规模阈值后突然出现并快速变好**，曲线不是平滑直线而像"相变"。

```
准确率
  ▲
1 │                              ╭───── 大模型:few-shot 远超 zero-shot
  │                          ╭──╯
  │                      ╭──╯       ← 阈值附近"拐点"(涌现)
  │                 ╭───╯
  │          ╭─────╯
0 │─────────╯  ← 小模型:给示范也没用,接近随机
  └────────────────────────────────────▶  参数规模(对数)
   0.1B    1B    10B    100B
```

GPT-3 的算术、SAT 类比、生成几可乱真的新闻段落、根据描述写代码雏形等能力，都呈现这种"到了 10B~100B 量级才像样"的特征。**涌现是"为什么非要做大"的最有力论据**：很多能力小模型上根本看不到苗头，不是"差一点"，而是"压根没有"。

> 注意：后续研究(2022 起)对"涌现是真相变还是评测指标不连续造成的假象"有争论。但**在 GPT-3 这篇工作里，规模带来 few-shot 能力质变，是当时最震撼也最被认可的发现。**

## 6. Scaling Laws：可预测的提升

GPT-3 建立在 OpenAI 2020 年的 **Scaling Laws** 之上：在算力充足时，**测试损失 $L$ 随参数量 $N$、数据量 $D$、计算量 $C$ 呈幂律(power-law)平滑下降**，跨好几个数量级都成立：

$$L(N) \approx \left(\frac{N_c}{N}\right)^{\alpha_N}, \qquad \alpha_N \approx 0.076$$

```
log(损失 L)
  ▲
  │ ●
  │   ●          幂律 = 在 log-log 坐标上是一条直线
  │      ●
  │         ●●
  │             ●●●
  │                  ●●●●  ← 损失随规模"可预测地"下降
  └────────────────────────▶  log(参数量 N)
```

这条规律的产业意义极大：**可以在小模型上拟合曲线，外推预测"花更多钱做更大模型大概能到多好"，把"做大模型"从赌博变成工程。** GPT-3 175B 正是顺着这条曲线选出的规模点。(注：2022 年 DeepMind 的 Chinchilla 进一步指出 GPT-3 "参数过大、数据偏少"，最优应让 $N$ 与 $D$ 同比例增长——但那是后话，GPT-3 当时偏向"把参数堆满"。)

## 7. 训练数据与算力

```
数据来源(过滤后, 按采样权重)         约占比
─────────────────────────────────────────
Common Crawl(清洗去重后)            ~60%
WebText2(高质量网页)                ~22%
Books1 / Books2(图书)               ~16%
Wikipedia(英文维基)                  ~3%
─────────────────────────────────────────
训练用 token 总量 ≈ 300 B(billion)
```

- **算力**：训练 175B 约消耗 **3640 PF-days(petaflop/s-days)** 量级的计算(以官方为准)——即"每秒千万亿次浮点运算持续约 3640 天"的等效算力，需上千张 GPU 训练数周。
- **数据处理**：对 Common Crawl 做了质量分类器过滤 + 模糊去重，并刻意**降低与评测集重叠**以防作弊(数据污染)。

## 8. 局限与影响

**局限(论文自陈 + 后续共识)**

- 长文本会**重复、自相矛盾、丢失连贯性**；缺乏真正的"理解"与世界模型。
- **无法可靠做精确多步推理**(大数算术、复杂逻辑常错)。
- 会**复读训练数据的偏见**(性别/种族/宗教)，可能生成有害内容。
- 训练**极其昂贵**，更新知识只能靠重训；推理成本也高。
- few-shot 对**提示写法(prompt)很敏感**，催生了"提示工程"。

**影响(深远)**

```
GPT-3 ─┬─▶ 确立"大模型 + in-context learning"新范式,微调不再是唯一路径
       ├─▶ 直接催生 OpenAI API / Codex(代码)/ 后续 InstructGPT
       ├─▶ InstructGPT 在 GPT-3 上加 RLHF(人类反馈强化学习) ──▶ 通往 ChatGPT
       ├─▶ 把"Scaling Laws / 涌现"推成行业信仰,引爆千亿参数军备竞赛
       └─▶ 让"提示工程""few-shot 评测"成为标准实践
```

一句话总结影响：**GPT-3 证明"够大就够通用"，把 NLP 从"一个任务一个模型"带进了"一个大模型 + 提示"的时代，是 ChatGPT 之前最关键的一块基石。**

## 数值例子 / 对照

**例 1：175B 模型纯权重显存**
FP16 下每参数 2 字节：

$$175 \times 10^9 \times 2\,\text{B} = 350 \times 10^9\,\text{B} = 350\,\text{GB}$$

单卡(如 80GB A100)放不下 → 必须**张量并行 + 流水线并行**切到多卡。训练时还要存梯度($\times1$)、Adam 优化器一阶/二阶动量($\times2$)等，**总显存往往是纯权重的 4~8 倍(约 1.4~2.8 TB 量级)**，所以训练需要成百上千张卡。

**例 2：一次前向的算力(FLOPs)**
经验公式：自回归模型处理一个 token 的前向计算约 $2N$ FLOPs($N$ 为参数量)。

$$2 \times 175\times10^9 = 3.5\times10^{11}\ \text{FLOPs / token}$$

生成 100 个 token 约 $3.5\times10^{13}$ FLOPs ≈ 35 TFLOPs。**这解释了为什么 175B 推理又慢又贵。**

**例 3：fine-tune vs few-shot 对照**

| 维度 | 传统 fine-tune | GPT-3 few-shot(in-context) |
|------|---------------|----------------------------|
| 是否改权重 | 是(反向传播) | 否(只前向) |
| 每个新任务 | 需各自一份权重 + 标注数据集 | 共用同一权重，几个示范即可 |
| 上手成本 | 高(训练流水线) | 低(写 prompt) |
| 对小模型 | 有效 | 几乎无效(能力未涌现) |
| 对大模型 | 有效但贵 | 有效，且随规模越来越强 |

## 常见问题(FAQ)

| 问题 | 回答 |
|------|------|
| GPT-3 相对 GPT-2 最大变化是什么？ | **规模**(参数 ~117×、数据 ~30×、层/宽/头同步放大)，架构几乎不变。 |
| in-context learning 会更新权重吗？ | **不会**。任务靠 prompt 里的示范临时编码进上下文，一次前向就出答案。 |
| few-shot / one-shot / zero-shot 区别？ | 分别是 prompt 里给 **K 个 / 1 个 / 0 个**示范，其余完全一样。 |
| "涌现"是什么意思？ | 某能力在小模型≈0、超过某规模阈值后突然出现并快速变好的非线性现象。 |
| Scaling Laws 有什么用？ | 损失随规模幂律下降、可外推，让"做更大模型能好多少"变得可预测。 |
| GPT-3 是 ChatGPT 吗？ | 不是。ChatGPT 谱系是 GPT-3 → 加 RLHF 的 InstructGPT → 对话化产品。 |
| 为什么 175B 这么难部署？ | 纯 FP16 权重就 350GB，超单卡显存，必须多卡并行；推理算力 ~2N FLOPs/token，又慢又贵。 |
| GPT-3 的参数最优吗？ | 按后来的 Chinchilla 结论：参数偏大、数据偏少，并非算力最优；但这不影响它的历史地位。 |
