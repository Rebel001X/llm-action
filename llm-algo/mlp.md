## 0. 一句话锚点

> **FFN（Feed-Forward Network）就是 Transformer 里对每个位置（token）独立施加的一个两层 MLP**：把 $d$ 维向量**升到** $4d$ 维做一次非线性变换，再**压回** $d$ 维。它**不跨 token 混合信息**（那是注意力的活），只负责"在每个位置上做特征加工"。

记住这张总图，后面所有内容都挂在它上面：

```
        一个 Transformer Block
   ┌──────────────────────────────────┐
   │  x ──► [ 多头注意力 ] ──► +x (残差) │   ← token 之间交换信息
   │            │                       │
   │            ▼                       │
   │  h ──► [   F F N   ] ──► +h (残差) │   ← 每个 token 各自加工（本文主角）
   └──────────────────────────────────┘
```

## 1. 地基：从一个神经元讲起

### 1.1 神经元 = 加权求和 + 偏置

一个神经元做的事就是把输入向量 $x=(x_1,\dots,x_n)$ 做**加权求和**再加一个偏置：

$$z = w_1x_1 + w_2x_2 + \dots + w_nx_n + b = \mathbf{w}^\top x + b$$

一**层**有很多神经元，把它们的权重堆成矩阵 $W$，就得到**线性层（全连接层）**：

$$z = Wx + b,\quad W\in\mathbb{R}^{m\times n},\ x\in\mathbb{R}^{n},\ z\in\mathbb{R}^{m}$$

```
x (n维)        W (m×n)            z (m维)
┌─┐         ┌───────────┐        ┌─┐
│x1│        │ w11 ... w1n│        │z1│
│x2│  ───►  │ w21 ... w2n│  ───►  │z2│   每个 zi = 该行点乘 x + bi
│..│        │  ...       │        │..│
│xn│        │ wm1 ... wmn│        │zm│
└─┘         └───────────┘        └─┘
```

### 1.2 为什么必须有激活函数（非线性）

如果只是把多层线性层叠起来：$W_2(W_1x)=（W_2W_1)x=W'x$，**两层等价于一层**，再深也没用。
**激活函数 $\sigma$ 引入非线性**，让 $\sigma(W_1x)$ 之后 $W_2$ 不能被吸收，网络才有表达能力去拟合复杂曲面。这就是 FFN 中间那一下"激活"存在的根本理由。

### 1.3 "逐位置"是什么意思

输入序列形状是 `[batch, seq_len, d]`。FFN 把 **同一套权重** $W_1,W_2$ 作用在**每一个** token 向量上，彼此独立、不通信。所以它本质是一个对 $d$ 维向量的函数 $\text{FFN}:\mathbb{R}^d\to\mathbb{R}^d$，被广播到所有位置。

## 2. 标准 FFN：两层升降维（4× 扩张）

经典 Transformer（Vaswani 2017）的 FFN：

$$\text{FFN}(x) = W_2\,\sigma(W_1 x + b_1) + b_2$$

- $W_1\in\mathbb{R}^{d_{ff}\times d}$：**升维**，$d \to d_{ff}$，通常 $d_{ff}=4d$
- $\sigma$：激活函数（ReLU/GELU/...）
- $W_2\in\mathbb{R}^{d\times d_{ff}}$：**降维**，$d_{ff}\to d$，压回原维度好接残差

```
   d 维          升维 W1         d_ff = 4d 维        激活        降维 W2        d 维
  ┌────┐       ┌────────┐      ┌──────────────┐   ┌──────┐   ┌────────┐    ┌────┐
  │ x  │ ────► │  4d×d   │ ───► │   z (宽)      │──►│ σ(z) │──►│ d×4d   │──► │ y  │
  └────┘       └────────┘      └──────────────┘   └──────┘   └────────┘    └────┘
   窄            扩张4倍           "工作空间"        非线性       收回           窄
```

**为什么要先升维再降维？** 中间那层宽（$4d$）相当于给网络一个**更大的"草稿纸"**：在高维空间里，激活函数可以把不同特征分配到不同维度上、把线性不可分的东西变得可分；做完非线性加工后再投影回 $d$ 维主干。宽度 4× 是经验上"算力/效果"较优的折中——太窄表达力不够，太宽收益递减且变慢。

## 3. 激活函数：ReLU / GELU / SiLU

### 3.1 ReLU —— 最简单的"开关"

$$\text{ReLU}(x)=\max(0,x)$$

正数原样通过，负数一律置 0。优点：算得快、不饱和（正区间梯度恒为 1，缓解梯度消失）。缺点：负区间梯度恒为 0，神经元可能"死亡"；且在 0 点不平滑。

```
ReLU       GELU            SiLU(=x·sigmoid(x))
  │  /        │   ╱            │    ╱
  │ /         │  ╱             │   ╱
──┼────    ───┼─╱──        ──╲─┼──╱──   ← 负区间有一小段"凹下去"
  │/          │╱  平滑          ╲│╱       不是硬截断
```

### 3.2 GELU —— 用概率"软门控"

$$\text{GELU}(x)=x\cdot\Phi(x)$$

$\Phi$ 是标准正态分布的累积分布函数（CDF），可理解为"以多大概率保留这个输入"。它**平滑可微**，在 0 附近不是硬拐角，负区间也允许一点点信号通过。BERT、GPT-2 等用它。常用近似：

$$\text{GELU}(x)\approx 0.5x\Big(1+\tanh\big[\sqrt{2/\pi}(x+0.044715x^3)\big]\Big)$$

### 3.3 SiLU / Swish —— GELU 的近亲

$$\text{SiLU}(x)=x\cdot\sigma(x),\quad \sigma(x)=\frac{1}{1+e^{-x}}$$

形状几乎和 GELU 一样：平滑、非单调（负区间先降后升）。它是 SwiGLU 里那个"门"的激活，下一节登场。

**直觉统一**：GELU/SiLU 都长成 $x\cdot(\text{某个 0~1 的门})$ 的样子——**输入乘以一个由自己决定的开合度**，这就是"门控"思想的雏形。

## 4. GLU 与 SwiGLU：门控为什么更好

### 4.1 GLU = 一路"内容" × 一路"门"

普通 FFN 只有一条路：`x → 升维 → 激活 → 降维`。
**GLU（Gated Linear Unit）** 把升维拆成**两条并行的投影**：一条当"内容"，另一条过激活当"门"，**逐元素相乘**：

$$\text{GLU}(x) = (W_{\text{value}}x)\ \odot\ \sigma(W_{\text{gate}}x)$$

$\odot$ 是逐元素（Hadamard）乘。门的每个分量是 0~1 附近的数，**逐维地决定"内容"放行多少**——这比"对整条向量做同一个激活"更精细、更像一个可学习的注意力开关。

### 4.2 SwiGLU = 门用 SiLU

把门的激活换成 SiLU（Swish），就是 LLaMA、PaLM、Qwen 等主流大模型用的 **SwiGLU**：

$$\text{SwiGLU}(x) = \big(W_3 x\big)\ \odot\ \text{SiLU}\big(W_1 x\big),\qquad \text{FFN}_{\text{SwiGLU}}(x)=W_2\,\text{SwiGLU}(x)$$

注意它有**三个权重矩阵** $W_1,W_2,W_3$（标准 FFN 只有两个 $W_1,W_2$）。

```
            ┌──► W1 ──► SiLU ──┐  (门 gate，0~1ish)
   x ──────►│                  ⊙ ──► W2 ──► y
   (d维)    └──► W3 ──────────┘  (内容 value，原样)
                 升到 d_ff        逐元素乘后再降回 d
```

### 4.3 为什么门控更好（直观 + 工程）

1. **逐维选择性**：普通激活对所有维"一刀切"，门控让网络**自适应地**对每一维放大/抑制，表达力更强。
2. **乘法交互**：$\odot$ 提供了输入特征间的**乘性（二阶）交互**，纯 $W\sigma(Wx)$ 是加性的，乘性能更高效地表示某些函数。
3. **梯度更友好**：SiLU 平滑、负区间有梯度，配合门控训练更稳，经验上在相同算力下困惑度更低（来源以各模型原论文/官方实现为准）。
4. **保持总算量不变的设计技巧**：多了一个矩阵 $W_3$，为了让参数/FLOPs 与 $4d$ 的标准 FFN 持平，通常把 $d_{ff}$ **缩到约 $\tfrac{2}{3}\times 4d=\tfrac{8}{3}d$**（再向上取到硬件友好的倍数）。下一节算给你看。

## 5. 参数量占比：FFN 吃掉了大头

把一层 Transformer 的参数粗算一下（忽略偏置/LayerNorm 这些小项）。设隐藏维 $d$。

**注意力部分**：Q、K、V、O 四个 $d\times d$ 矩阵 → $4d^2$。

**标准 FFN（$d_{ff}=4d$）**：$W_1$ 是 $4d\times d$、$W_2$ 是 $d\times 4d$ → $4d^2+4d^2=8d^2$。

$$\frac{\text{FFN}}{\text{FFN}+\text{Attn}}=\frac{8d^2}{8d^2+4d^2}=\frac{8}{12}=\boxed{66.7\%}$$

> **结论：FFN 约占每层参数的 2/3**，是大模型里最"重"的子模块——这也是 MoE（把 FFN 换成多个专家、按需激活）能省算力的根本原因，见 [[llm-algo/moe/README]]。

**SwiGLU 版**：三个矩阵，单看是 $3 \times d\cdot d_{ff}$。若想与标准 FFN 的 $8d^2$ 持平：

$$3\,d\,d_{ff}=8d^2 \ \Rightarrow\ d_{ff}=\tfrac{8}{3}d\approx 2.667d$$

所以 LLaMA 把"4d"改成"约 8/3 d"再取整，正是为了在引入第三个矩阵后**保持参数量不变**。

## 6. 完整数值示例 / 手算（含 SwiGLU 逐数）

为了把每个数都算出来，取一个**玩具尺寸**：$d=4$。

### 6.1 标准 FFN 走一遍（$d_{ff}=8$，即 2× 这里为简化）

输入 $x=[1,\ 2,\ -1,\ 0]$。取升维矩阵 $W_1$（$8\times4$）的**第 1 行** $=[0.5,\ 0.5,\ 0,\ 1]$：

$$z_1 = 0.5\cdot1+0.5\cdot2+0\cdot(-1)+1\cdot0 = 0.5+1.0 = 1.5$$

设第 2 行算出 $z_2=-0.8$。过 **ReLU**：

$$\text{ReLU}(1.5)=1.5,\qquad \text{ReLU}(-0.8)=0$$

可见负的那一维被"关掉"了。其余各维同理，得到 8 维隐藏向量 $h$，再用 $W_2$（$4\times8$）压回 4 维、加残差。**要点**：升维提供 8 个"特征探测器"，ReLU 只保留被正向激活的那些。

### 6.2 SwiGLU 逐数手算（核心）

继续用 $x=[1,2,-1,0]$，$d=4$，门/内容都升到 $d_{ff}=8$（演示只算前两维）。

**第一步：门路 $W_1 x$，再过 SiLU。** 取 $W_1$ 前两行：

- 行1 $=[1,0,0,0]\Rightarrow g_1 = 1\cdot1=1.0$
- 行2 $=[0,0,1,0]\Rightarrow g_2 = 1\cdot(-1)=-1.0$

SiLU$(a)=a\cdot\sigma(a)$，$\sigma(a)=\frac{1}{1+e^{-a}}$：

$$\sigma(1.0)=\frac{1}{1+e^{-1}}=\frac{1}{1+0.3679}=0.7311 \Rightarrow \text{SiLU}(1.0)=1.0\times0.7311=0.7311$$

$$\sigma(-1.0)=\frac{1}{1+e^{1}}=\frac{1}{1+2.7183}=0.2689 \Rightarrow \text{SiLU}(-1.0)=-1.0\times0.2689=-0.2689$$

所以门向量前两维 $\text{gate}=[\,0.7311,\ -0.2689\,]$。**注意 SiLU 让负输入产生一个小负门，而不是像 ReLU 那样硬置 0**——保留了一点信息。

**第二步：内容路 $W_3 x$（线性，不激活）。** 取 $W_3$ 前两行：

- 行1 $=[1,1,0,0]\Rightarrow v_1 = 1+2 = 3.0$
- 行2 $=[0,1,0,1]\Rightarrow v_2 = 2+0 = 2.0$

内容向量前两维 $\text{value}=[\,3.0,\ 2.0\,]$。

**第三步：逐元素相乘 $\text{value}\odot\text{gate}$。**

$$u_1 = 3.0 \times 0.7311 = 2.1933$$
$$u_2 = 2.0 \times (-0.2689) = -0.5378$$

得 $u=[\,2.1933,\ -0.5378,\ \dots\,]$（共 8 维）。**门把第 1 维放大、把第 2 维反向缩小**——这就是"逐维门控"的实际效果，普通 FFN 做不到这种各维不同的乘性调节。

**第四步：降维 $W_2 u$ 回到 4 维。** 取 $W_2$ 第 1 行 $=[1, 1, 0,0,0,0,0,0]$（只看前两维贡献）：

$$y_1 = 1\times2.1933 + 1\times(-0.5378) = 1.6555$$

加上残差 $x_1=1$：输出该位置第 1 维 $\approx 1+1.6555=2.6555$。整条 token 向量同法得到。

**一句话复盘**：`门(SiLU) × 内容(线性) → 降维 → 残差`。门的每个分量独立地决定对应内容分量"放行多少"，这正是 SwiGLU 比"单激活"更强的来源。

### 6.3 顺带：参数量/FLOPs 数值感

取真实尺寸 $d=4096$（如 7B 级别）：

- 标准 FFN 参数 $=8d^2=8\times4096^2\approx 1.34\times10^8$（**1.34 亿/层**）。
- 注意力参数 $=4d^2\approx 0.67\times10^8$。FFN 确实约是注意力的 **2 倍**，占比 2/3，和第 5 节公式吻合。
- 单 token 前向 FLOPs 约 $2\times$参数量 $\approx 2.7\times10^8$（乘加各算一次）。

## 复杂度 / 对照表

| 变体 | 公式 | 矩阵数 | 典型 $d_{ff}$ | 每层参数(忽略偏置) | 代表模型 |
|---|---|---|---|---|---|
| 标准 FFN(ReLU) | $W_2\text{ReLU}(W_1x)$ | 2 | $4d$ | $8d^2$ | 原始 Transformer |
| GELU FFN | $W_2\text{GELU}(W_1x)$ | 2 | $4d$ | $8d^2$ | BERT / GPT-2 |
| GLU 系 | $W_2[(W_3x)\odot\sigma(W_1x)]$ | 3 | $\approx\tfrac{8}{3}d$ | $\approx 8d^2$ | — |
| **SwiGLU** | $W_2[(W_3x)\odot\text{SiLU}(W_1x)]$ | 3 | $\approx\tfrac{8}{3}d$ | $\approx 8d^2$ | LLaMA / PaLM / Qwen |

> 三矩阵但 $d_{ff}$ 缩到 $8/3\,d$，让 SwiGLU 与标准 FFN **参数/算力基本持平**，却效果更好。

## 常见问题

| 疑问 | 真相 |
|---|---|
| FFN 会让 token 互相交流吗？ | 不会。它逐位置独立，跨 token 混合是注意力的职责 |
| 为什么中间非要 4 倍宽？ | 经验最优折中；更宽的"工作空间"利于非线性加工，4× 是算力/效果甜点 |
| ReLU 和 GELU 差别大吗？ | GELU 平滑、负区间留余地，训练更稳；ReLU 更快但有"死神经元" |
| SwiGLU 为什么有三个矩阵还不更贵？ | 把 $d_{ff}$ 从 $4d$ 缩到 $\approx 8/3\,d$，三矩阵总量回到 $8d^2$ |
| 门控到底强在哪？ | 逐维、乘性的自适应开关，比"全向量同一激活"表达力更强 |
| 偏置 $b$ 重要吗？ | 现代大模型 FFN 常**去掉偏置**（配合 RMSNorm），简化且几乎不掉点 |
| FFN 占多少参数？ | 每层约 **2/3**，是大模型最大单元，也是 MoE 优化的对象 |
