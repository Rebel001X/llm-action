## 0. 一句话锚点

LLaMA = 原始 Transformer 的 **Decoder-only** 形态，但把四个组件全部升级：

```
LayerNorm  → RMSNorm          (更省、更稳)
Post-norm  → Pre-norm         (深层好训)
绝对位置编码 → RoPE            (相对位置 + 可外推)
FFN(ReLU)  → SwiGLU           (门控，效果更好)
MHA        → GQA (2、3代)     (KV Cache 显存砍数倍)
```

记住一句话：**"该减的减（RMSNorm/GQA 省算省显存），该换的换（RoPE/SwiGLU 提效果），位置都靠前（Pre-norm）。"**

## 1. 地基：原始 Transformer Decoder 是什么样

不假设你记得，先把"被替换掉的旧件"摆出来，后面才知道 LLaMA 改了什么。

一个标准 Transformer Decoder Block（GPT 风格）做这些事：

1. **LayerNorm**：把一行向量 $x\in\mathbb{R}^d$ 标准化。公式
   $$\text{LN}(x)=\gamma\odot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta,\quad \mu=\tfrac1d\sum x_i,\ \sigma^2=\tfrac1d\sum(x_i-\mu)^2$$
   需要算 **均值 $\mu$ 和方差 $\sigma^2$**，还有两组可学习参数 $\gamma,\beta$。
2. **位置编码**：原始论文用正弦 $\text{PE}(pos,2i)=\sin(pos/10000^{2i/d})$，**加到** embedding 上，是绝对位置。
3. **多头注意力 MHA**：Q、K、V 各 $h$ 个头，每个头都有自己独立的 K、V。
4. **FFN**：$\text{FFN}(x)=\max(0, xW_1)W_2$，两层 + ReLU，中间维度通常 $4d$。
5. **残差 + Post-norm**：旧式是 $x \leftarrow \text{LN}(x+\text{Sublayer}(x))$，归一化在残差**之后**。

LLaMA 把第 1、2、3、4、5 条**全改了**。下面逐条拆。

## 2. 整体数据流（全景 ASCII 图）

```
                 token ids  [B, T]
                     │
            ┌────────▼─────────┐
            │  Embedding 查表    │  d_model 维，无位置加法(位置交给RoPE)
            └────────┬─────────┘
                     │  x:[B,T,d]
   ┌─────────────────▼──────────────────┐
   │   Decoder Block × N  (重复 N 层)     │
   │                                     │
   │   ┌── x ──────────────────────┐     │
   │   │                           │     │
   │   ▼ RMSNorm                残差 │     │
   │   Attention(GQA + RoPE)        │     │   ← 注意：Norm 在子层"前"(Pre-norm)
   │   │                           │     │
   │   └──────► + ◄────────────────┘     │
   │            │                        │
   │   ┌── x ───┴───────────────┐        │
   │   │                        │ 残差    │
   │   ▼ RMSNorm                │        │
   │   SwiGLU FFN               │        │
   │   │                        │        │
   │   └──────► + ◄─────────────┘        │
   └─────────────────┬───────────────────┘
                     │  (N 层后)
            ┌────────▼─────────┐
            │  最后一层 RMSNorm  │
            └────────┬─────────┘
                     │
            ┌────────▼─────────┐
            │ LM Head (线性)    │  → logits [B,T,vocab]
            └──────────────────┘
```

对应代码骨架（呼应文件原有的两个类）：

```python
class LlamaDecoderLayer(nn.Module):
    def forward(self, x, ...):
        # Pre-norm：先归一化再进子层，子层输出加回残差
        x = x + self.self_attn(self.input_layernorm(x), ...)   # RMSNorm + GQA + RoPE
        x = x + self.mlp(self.post_attention_layernorm(x))     # RMSNorm + SwiGLU
        return x

## LlamaAttention(nn.Module)
#   - q_proj / k_proj / v_proj：注意 K、V 头数 = num_key_value_heads(GQA 关键)
#   - 对 q、k 施加 RoPE 旋转
#   - repeat_kv：把 KV 头复制到与 Q 头同数，再做 scaled-dot-product attention
#   - o_proj 输出投影

## LlamaMLP(nn.Module)
#   - gate_proj、up_proj、down_proj 三个线性层
#   - down_proj( silu(gate_proj(x)) * up_proj(x) )   ← SwiGLU
```

## 3. RMSNorm + Pre-norm：为什么这样归一化

### 3.1 RMSNorm 是什么

RMSNorm（Root Mean Square Norm）**砍掉了 LayerNorm 里的"减均值"和偏置 $\beta$**，只保留缩放：

$$\text{RMSNorm}(x)=\frac{x}{\sqrt{\frac1d\sum_{i=1}^{d}x_i^2+\epsilon}}\odot g$$

其中 $g\in\mathbb{R}^d$ 是唯一的可学习增益。对比 LayerNorm：

```
LayerNorm:  要算 μ(均值)、σ²(方差)、γ、β        → 2 次统计量 + 2 组参数
RMSNorm :   只算 RMS = √(mean(x²))、g          → 1 次统计量 + 1 组参数
```

**为什么能去掉均值？** 经验发现 LayerNorm 起作用的主要是**re-scaling（缩放不变性）**而非 re-centering（平移不变性）。去掉减均值后：少一遍求和、少一组参数、数值更简单，效果几乎不掉，**速度更快**。这就是"该减的减"。

### 3.2 逐数手算 RMSNorm（$d=4$）

设 $x=[2,\,-2,\,1,\,-1]$，$\epsilon\approx0$，$g=[1,1,1,1]$：

```
平方:      4, 4, 1, 1
mean(x²) = (4+4+1+1)/4 = 10/4 = 2.5
RMS      = √2.5 ≈ 1.5811
输出      = x / 1.5811
         = [1.265, -1.265, 0.632, -0.632]
```

可见它把"整体能量"归一到 1 附近，但**不改变向量的方向/对称结构**（没有平移）。

### 3.3 Pre-norm：归一化放在子层"前"

```
Post-norm (旧): x ← Norm( x + Sublayer(x) )    残差里夹着未归一化的量
Pre-norm  (新): x ← x + Sublayer( Norm(x) )    残差是"干净的恒等通路"
```

**为什么 Pre-norm 更好训？** Pre-norm 让残差分支 $x\to x$ 成为一条**没有任何缩放的恒等高速路**，梯度从顶层直接流到底层不衰减，深层（32~80 层）也能稳定训练、可以用更大学习率、几乎不需要 warmup 调参。代价是：表征能力略弱一点，但对超大模型而言**训得稳 >> 一点点表达力**，所以 LLaMA/GPT 全系都用 Pre-norm。

> LLaMA 每个 Block 有 **2 个 RMSNorm**：`input_layernorm`（Attention 前）、`post_attention_layernorm`（FFN 前）；外加整个 stack 末尾 1 个 `norm`。

## 4. RoPE：旋转位置编码（细节见 [[llm-algo/旋转编码RoPE]]）

### 4.1 动机

绝对正弦编码是"加"到 embedding 上的，模型要从绝对位置里**间接学**相对距离，且换更长上下文时不友好。我们真正想要的是：**注意力分数只依赖两个 token 的相对距离 $m-n$**。

### 4.2 做法：把维度两两配对、按位置旋转

把 $d$ 维向量切成 $d/2$ 个二维子平面，第 $i$ 对用频率 $\theta_i=10000^{-2i/d}$。位置为 $m$ 的 token，其 query 的第 $i$ 对 $(x_{2i},x_{2i+1})$ 被旋转角度 $m\theta_i$：

$$
\begin{pmatrix}x'_{2i}\\x'_{2i+1}\end{pmatrix}=
\begin{pmatrix}\cos m\theta_i & -\sin m\theta_i\\ \sin m\theta_i & \cos m\theta_i\end{pmatrix}
\begin{pmatrix}x_{2i}\\x_{2i+1}\end{pmatrix}
$$

**关键性质**：旋转后的 $q_m$ 与 $k_n$ 做内积，只跟 **$m-n$** 有关（两个旋转矩阵相乘，角度相减）：
$$\langle R_m q,\,R_n k\rangle = \langle q,\,R_{n-m}k\rangle$$
于是**相对位置天然内建在注意力里**。

```
位置0:    →  (不旋转)
位置1:    ↗  (每对转 θ_i)
位置2:    ↑  (转 2θ_i)
位置m:    转 m·θ_i ...   高频对转得快(管局部)，低频对转得慢(管长程)
```

### 4.3 为什么能外推 / base 缩放

RoPE 只对 q、k 施加，**不进残差、不进 V**。想支持更长上下文，只需把 base（10000）调大或做 NTK/线性插值，就能让训练时没见过的长位置仍落在合理角度范围内——这就是 LLaMA-2 从 2k→4k、LLaMA-3 到 8k 时调位置编码的抓手。

## 5. GQA：分组查询注意力（省 KV Cache）

### 5.1 三种注意力对比

```
MHA (多头)   : Q=h头   K=h头   V=h头     每个Q头有专属KV   → KV Cache 最大
MQA (多查询) : Q=h头   K=1头   V=1头     所有Q头共享1组KV   → 最省但质量略降
GQA (分组)   : Q=h头   K=g组   V=g组     每g_size个Q头共享一组KV  → 折中，LLaMA-2/3 采用
                                         (g=1→MQA, g=h→MHA)
```

ASCII（h=8 Q 头，g=2 KV 组，每组 4 个 Q 头）：

```
 Q头:  q0 q1 q2 q3   q4 q5 q6 q7
        \  \  /  /     \  \  /  /
         ╲ ╲ ╱ ╱       ╲ ╲ ╱ ╱
          KV组0          KV组1
   (q0~q3 共用 K0,V0)  (q4~q7 共用 K4,V4)
```

代码里靠 `repeat_kv` 把 K、V 沿头维复制 `h/g` 份，再走标准注意力。

### 5.2 为什么要 GQA：KV Cache 是推理显存大头

自回归生成时，每生成一个 token 都要缓存所有历史 token 的 K、V。MHA 下 KV Cache 大小 ∝ 头数。把 KV 头从 32 砍到 8，**KV Cache 直接降到 1/4**，长上下文 + 大 batch 时显存和带宽全都受益，而质量几乎不掉。这是"该减的减"在显存上的体现。

> 注意：LLaMA-1 用的还是 **MHA**；GQA 是 LLaMA-2（34B/70B）和 LLaMA-3 全系才用的。

## 6. SwiGLU 前馈网络（细节见 [[llm-algo/mlp]]）

### 6.1 从 ReLU-FFN 到门控 GLU

原始 FFN：$\text{FFN}(x)=\text{ReLU}(xW_1)W_2$（两层）。LLaMA 换成 **SwiGLU**，三层带门控：

$$\text{SwiGLU}(x)=\big(\underbrace{\text{SiLU}(xW_{\text{gate}})}_{\text{门}}\;\odot\;\underbrace{xW_{\text{up}}}_{\text{值}}\big)\,W_{\text{down}}$$

其中 $\text{SiLU}(z)=z\cdot\sigma(z)=\dfrac{z}{1+e^{-z}}$（也叫 Swish）。

```
        x
       ╱ ╲
 W_gate   W_up        ← 两个并行投影 (d → d_ff)
   │       │
 SiLU      │
   │       │
   └──×─────┘          ← 逐元素相乘 (门控：门决定每个通道放多少value过)
       │
     W_down            ← 投回 (d_ff → d)
       │
     输出
```

### 6.2 为什么用门控 + 为什么中间维是 $\frac83 d$

- **门控**：$\text{SiLU}(xW_{\text{gate}})$ 给每个隐藏通道一个"开关强度"，让网络**有选择地**让信息通过，表达力强于固定 ReLU，实证 PPL 更低。
- **$\frac83 d$ 的来历**：普通 FFN 中间维是 $4d$，有 2 个权重矩阵，参数量 $\approx 2\cdot d\cdot 4d=8d^2$。SwiGLU 有 **3 个**矩阵（gate/up/down），要保持参数量大致相等：$3\cdot d\cdot d_{ff}\approx 8d^2 \Rightarrow d_{ff}\approx\frac83 d$。所以 LLaMA 取 $d_{ff}\approx\frac83 d$ 再向上对齐到 256 的倍数。

逐数验证（7B，$d=4096$）：$\frac83\times4096=10922.7$，对齐后官方取 **11008**。✔ 和公式吻合。

## 7. LLaMA 1 / 2 / 3 演进

| 维度 | LLaMA-1 (2023.02) | LLaMA-2 (2023.07) | LLaMA-3 (2024.04) |
|------|------|------|------|
| 规格 | 7/13/33/65B | 7/13/34/70B | 8/70B(后续405B) |
| 上下文 | 2048 | 4096 | 8192 |
| 注意力 | MHA | GQA(34B/70B) | **GQA(全系)** |
| 词表大小 | 32000 (SentencePiece) | 32000 | **≈128000 (tiktoken BPE)** |
| 训练 token | 1.0~1.4T | 2.0T | **≈15T** |
| 对齐 | 仅预训练 | +Chat(SFT+RLHF) | +Instruct(SFT+DPO/RLHF) |
| 共同点 | 全系都是 RMSNorm + RoPE + SwiGLU + Pre-norm | | |

**演进主线**（数字以官方技术报告为准，不确定处标注"约"）：
1. **LLaMA-1**：证明"小模型 + 喂更多数据"能超过更大模型（呼应 Chinchilla：算力该多花在数据上）。13B 在多项基准超过 GPT-3 175B。
2. **LLaMA-2**：上下文翻倍到 4k；大模型引入 GQA 降推理成本；首次放出对齐过的 Chat 版（SFT + RLHF）。
3. **LLaMA-3**：词表从 3.2 万扩到约 12.8 万（更高压缩率、更省 token），数据量飙到约 15T，全系 GQA，上下文 8k（后续长上下文变体更长）。

## 8. 参数量逐数手算（以 7B 为例）

配置（公开）：$d=4096$，层数 $L=32$，头数 $h=32$（LLaMA-1 是 MHA，$g=h$），$d_{ff}=11008$，词表 $V=32000$。

**单层参数**：

```
注意力 (MHA, Q/K/V/O 各 d×d):
   4 × d²        = 4 × 4096²        = 67,108,864
FFN (SwiGLU, 3 个矩阵 d×d_ff):
   3 × d × d_ff  = 3 × 4096 × 11008 = 135,266,304
2 个 RMSNorm:
   2 × d         = 2 × 4096         = 8,192   (可忽略)
────────────────────────────────────────────
单层合计 ≈ 202,383,360  ≈ 0.202 B
```

**全模型**：

```
32 层:        32 × 0.2024 B ≈ 6.477 B
Embedding:    V × d = 32000 × 4096 ≈ 0.131 B
(LM Head 与 Embedding 是否共享视实现而定，这里另算/或共享)
最后 RMSNorm: 4096                 (忽略)
────────────────────────────────────────
合计 ≈ 6.6 B  → 习惯称 "7B" ✔
```

> 经验公式：$\text{参数} \approx 12\,L\,d^2$（注意力 $4d^2$ + FFN 约 $8d^2$）。代入 $12\times32\times4096^2\approx6.44\text{B}$，与上面吻合。

## 9. 显存 / KV Cache 逐数手算

### 9.1 权重显存

```
7B 参数, 每参数字节数随精度:
  FP32: 7B × 4 = 28 GB
  FP16: 7B × 2 = 14 GB     ← 推理常用
  INT8: 7B × 1 =  7 GB
  INT4: 7B × 0.5 ≈ 3.5 GB  ← 量化部署
```

### 9.2 KV Cache（看 GQA 的威力）

公式：$\text{KV Cache} = 2 \times L \times T \times n_{kv} \times d_{head} \times \text{bytes}$（2 = K 和 V）。

设 $T=4096$，FP16，$d_{head}=d/h=128$：

```
MHA (n_kv = 32 头):
  2 × 32 × 4096 × 32 × 128 × 2 B
  = 2 × 32 × 4096 × 4096 × 2
  ≈ 4.29 GB

GQA (n_kv = 8 组):
  上式头数 32 → 8
  ≈ 1.07 GB     ← 直接降到 1/4 !
```

**结论**：GQA 在 4k 上下文就把单条序列的 KV Cache 从 ~4.3GB 降到 ~1.1GB，长上下文 + 大 batch 时省的显存是数量级的——这就是它存在的全部理由。

## 10. 对照 / 复杂度表

| 组件 | 原始 Transformer | LLaMA | 收益 |
|------|------|------|------|
| 归一化 | LayerNorm(μ,σ²,γ,β) | RMSNorm(RMS,g) | 更快、更稳 |
| 归一化位置 | Post-norm | **Pre-norm** | 深层好训、可大 LR |
| 位置编码 | 绝对正弦(加到emb) | **RoPE**(旋转q,k) | 相对位置、可外推 |
| 注意力 | MHA | **GQA**(2/3代) | KV Cache 砍数倍 |
| FFN | ReLU, 中间 4d | **SwiGLU**, 中间 8/3·d | 门控、效果更好 |
| 偏置项 bias | 通常有 | **基本去掉** | 省参、更稳 |

复杂度（单层，序列 $T$，维度 $d$）：注意力 $O(T^2 d)$（GQA 不改 FLOPs，只省 KV 显存/带宽）；FFN $O(T\,d\,d_{ff})$。

## 11. 高频面试问答（踩点 + 追问）

| 高频问题 | 踩点答案（可背） | 追问 / 陷阱 |
|---|---|---|
| LLaMA 相比原始 Transformer 改了什么？ | 四换一前置：RMSNorm、RoPE、SwiGLU、GQA(2/3代)，全用 Pre-norm，去 bias | 追问：每个改动解决什么问题？ |
| RMSNorm 为何比 LayerNorm 好？ | 去掉减均值和 β，只保 RMS 缩放；少统计量少参数、更快，效果不掉 | 陷阱：别说"更准"，是"更省更稳、效果相当" |
| 为什么 Pre-norm？ | 残差是干净恒等路，梯度直达底层，深层稳、可大 LR、少 warmup | 追问：Pre-norm 缺点？(表达力略弱，需末尾再加一个 norm) |
| RoPE 凭什么是相对位置？ | 旋转后 q·k 只依赖角度差 m−n | 追问：怎么外推？(调 base / NTK / 位置插值；RoPE 不进 V) |
| GQA 和 MHA/MQA 区别？ | g=1 是 MQA，g=h 是 MHA，GQA 折中；省 KV Cache | 追问：省多少？(∝ 头数比，32→8 降 1/4)；LLaMA-1 用的是 MHA |
| SwiGLU 中间维为什么 8/3·d？ | 3 个矩阵要和 ReLU-FFN 的 8d² 参数对齐 → d_ff≈8/3·d | 陷阱：别答 4d，那是普通 FFN |
| 为什么去掉所有 bias？ | 大模型上 bias 收益微弱，去掉省参、训练更稳 | — |
| LLaMA-1→2→3 主要变化？ | 上下文 2k→4k→8k；词表 3.2万→3.2万→约12.8万；数据 1.4T→2T→约15T；GQA 普及 | 追问：为什么扩词表？(压缩率高、同样文本更少 token、更省算) |
| 7B 参数怎么估？ | ≈12·L·d² = 12×32×4096² ≈ 6.4B | 追问：FP16 推理权重多大？(14GB) |
| 为什么"小模型+更多数据"打得过大模型？ | Chinchilla 思路：固定算力下，数据量比单纯堆参数更划算 | 追问：推理成本谁更低？(小模型，部署友好) |
