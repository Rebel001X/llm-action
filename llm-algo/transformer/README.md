## 0. 一句话锚点

在 Transformer 之前，处理"一句话"靠 **RNN**：像读书一样一个字一个字地读，第 $t$ 个字必须等第 $t-1$ 个字算完——**串行、慢、还容易忘记很久以前的内容**。

Transformer 的核心主张：**"任意两个词之间，直接、并行地算一次相关性"**。
- 不再串行 → **可大规模并行训练**（吃满 GPU）。
- 任意两词一步可达 → **长距离依赖不再衰减**。

这两点，就是后来"大模型"得以诞生的工程地基。

```
RNN：  词1 → 词2 → 词3 → 词4   (必须排队，第4个等前3个)
                              ↘ 远处的"词1"信息一路衰减

Transformer：
        词1   词2   词3   词4
          \   |    |   /
           全连接注意力（一步直达，且同时算）
```

## 1. 地基 / 前置

**(a) 什么是序列（sequence）？** 一段文本被切成 token（词/子词），例如 "我 爱 你" → 3 个 token。每个 token 先查表变成一个向量（**Embedding**，维度记作 $d_{model}$，原论文取 512）。所以"一句话"在模型里是一个矩阵 $X \in \mathbb{R}^{n \times d_{model}}$，$n$ 是句子长度。

**(b) RNN 怎么工作？** 维护一个"记忆"隐状态 $h_t$，每读一个词更新一次：
$$ h_t = f(h_{t-1}, x_t) $$
问题有二：① $h_t$ 依赖 $h_{t-1}$，**没法并行**；② 词1的信息要经过 $n$ 次乘法才能传到词 $n$，**梯度消失 / 信息遗忘**（LSTM/GRU 缓解但没根治）。

**(c) "注意力"的朴素直觉。** 翻译 "it" 时，我们想知道 "it" 指代前文的哪个名词。注意力就是：让 "it" 这个词**主动去"看"句子里所有词，给每个词打一个相关性分数，按分数加权汇总信息**。这个"看一眼全句"的动作，正是取代 RNN 串行记忆的关键。

```
token → embedding → (矩阵 X) → 进入 Transformer 层
 "猫"  →  [0.2, -1.1, 0.7, ...]  (长度 d_model=512 的向量)
```

## 2. 整体骨架：Encoder-Decoder 全貌

原始 Transformer 是为**机器翻译**设计的，天然是 **Encoder-Decoder** 结构：Encoder 读懂源语言（中文），Decoder 生成目标语言（英文）。两边各 **堆叠 6 层**（$N=6$）。

```
        源句子 "我 爱 你"                       目标句子 "I love you"
              │                                      │（右移一位，含<bos>）
       Input Embedding                         Output Embedding
              + 位置编码                              + 位置编码
              ▼                                      ▼
    ┌──────────────────┐                  ┌──────────────────────┐
    │   Encoder Layer   │ ×6              │    Decoder Layer       │ ×6
    │ ┌──────────────┐ │                  │ ┌────────────────────┐ │
    │ │ 多头自注意力   │ │                  │ │ 带掩码 多头自注意力  │ │ (看不到未来)
    │ │ Add & Norm    │ │                  │ │ Add & Norm          │ │
    │ ├──────────────┤ │   ── K,V ──┐     │ ├────────────────────┤ │
    │ │  前馈网络 FFN  │ │            └──►  │ │ 交叉注意力(Enc-Dec) │ │ ◄ Q来自Decoder
    │ │ Add & Norm    │ │                  │ │ Add & Norm          │ │   K,V来自Encoder
    │ └──────────────┘ │                  │ ├────────────────────┤ │
    └──────────────────┘                  │ │  前馈网络 FFN        │ │
              │                            │ │ Add & Norm          │ │
       编码完成的语义表示 ──────────────────│ └────────────────────┘ │
                                           └──────────────────────┘
                                                      ▼
                                               Linear + Softmax
                                                      ▼
                                            下一个词的概率分布
```

三种注意力一图分清：
- **Encoder 自注意力**：源句内部互相看，无掩码（双向）。
- **Decoder 掩码自注意力**：目标句内部看，**但只能看已生成的左侧**（防作弊偷看答案）。
- **交叉注意力（Cross-Attention）**：Decoder 出 Query，去 Encoder 的输出里取 Key/Value——这是"翻译时对齐源词"的地方。

## 3. 自注意力（Self-Attention）逐公式拆解

这是整个架构的心脏。给定输入矩阵 $X \in \mathbb{R}^{n \times d_{model}}$，做三件事：

**第一步：投影出 Q、K、V。** 用三个可学习权重矩阵把每个词向量映射成三种角色：
$$ Q = XW^Q,\quad K = XW^K,\quad V = XW^V $$
- **Query（查询）**：我（这个词）想找什么。
- **Key（键）**：我（每个词）能提供什么标签。
- **Value（值）**：我（每个词）实际携带的信息。

朴素类比：在图书馆，你的需求是 Query，每本书的书脊标签是 Key，书的内容是 Value。

**第二步：算相关性分数（Q 点乘 K）。**
$$ \text{score} = QK^\top \in \mathbb{R}^{n \times n} $$
这是一个 $n\times n$ 矩阵，第 $(i,j)$ 项 = 词 $i$ 对词 $j$ 的关注度。**任意两词一步直达**，这正是长依赖问题的解法。

**第三步：缩放 + Softmax 归一化。**
$$ \text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$
- 除以 $\sqrt{d_k}$：当维度 $d_k$ 大时点积数值会很大，把 softmax 推向梯度极小的饱和区；缩放让方差回到 1 量级。
- Softmax：把每一行分数变成"和为 1 的权重"。
- 乘 $V$：按权重把所有词的 Value 加权汇总，得到该词的新表示。

```
    一行（词"it"）的注意力权重示意：
    词:   The  animal  didn't  cross  ...  it
    权重: 0.05  0.62    0.03    0.10  ... 0.20
                ↑ "it" 高度关注 "animal" → 正确指代消解
```

## 4. 多头注意力（Multi-Head）

只算一次注意力，模型只能学到"一种"关注模式。**多头** = 并行做 $h$ 套独立的注意力（原文 $h=8$），每套在不同的低维子空间里看问题（一头管语法、一头管指代、一头管词义……），最后拼接。

$$ \text{head}_i = \text{Attention}(XW_i^Q, XW_i^K, XW_i^V) $$
$$ \text{MultiHead} = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\,W^O $$

维度分配：$d_k = d_v = d_{model}/h = 512/8 = 64$。**总计算量与单头相当**（每头维度小了 8 倍），却得到 8 倍的"视角"。

```
 X ──┬─► head1 (子空间64维) ─┐
     ├─► head2 (子空间64维) ─┤
     │      ...             ├─► Concat(8×64=512) ─► W^O ─► 输出
     └─► head8 (子空间64维) ─┘
```

## 5. 位置编码（Positional Encoding）

**致命点**：自注意力是"集合操作"——打乱词序，$QK^\top$ 的结果集合不变，**模型根本看不见顺序**！必须显式注入位置信息。原文用固定的正弦/余弦编码，加到词向量上：

$$ PE_{(pos,2i)} = \sin\!\Big(\frac{pos}{10000^{2i/d_{model}}}\Big),\quad PE_{(pos,2i+1)} = \cos\!\Big(\frac{pos}{10000^{2i/d_{model}}}\Big) $$

- 不同维度对应不同波长（从 $2\pi$ 到 $10000\cdot2\pi$），像二进制的高低位，唯一编码每个位置。
- 三角函数性质让模型易于学习"相对位置"（$PE_{pos+k}$ 可由 $PE_{pos}$ 线性表出）。
- 后续演化出可学习 PE、RoPE（旋转位置编码，LLaMA/DeepSeek 用）、ALiBi 等。

```
位置:   0     1     2     3
        ↓     ↓     ↓     ↓
        +     +     +     +   （逐元素加到词向量）
       PE0   PE1   PE2   PE3  （每个是 d_model 维的正弦图样）
```

## 6. FFN、残差、LayerNorm

每个注意力子层后接一个**逐位置前馈网络（FFN）**——对每个 token 独立做两层全连接，中间升维（512→2048→512），用 ReLU：
$$ \text{FFN}(x) = \max(0,\ xW_1 + b_1)\,W_2 + b_2 $$

> 补充两个重要工程事实：
> 1. **FFN 层参数量巨大**，约占整个模型参数量的 **三分之二**左右（注意力部分只占约三分之一）。
> 2. FFN 的激活存在较大**稀疏性**——对某一具体输入，FFN 中只有一部分参数真正被"点亮"。这一观察正是后来 **MoE（混合专家）** 把单个稠密 FFN 拆成多个专家、按需稀疏激活的动机。

**残差连接 + 层归一化**包裹每个子层：$\text{LayerNorm}(x + \text{Sublayer}(x))$。残差让梯度有"高速公路"直达深层（否则 6 层叠 6 层太深难训），LayerNorm 稳定每层激活的分布。

```
 x ──►┌─Sublayer(注意力/FFN)─┐──►(+)──► LayerNorm ──► 输出
   └──────────残差跳连─────────┘
```

## 7. 自注意力为什么取代 RNN（复杂度对照）

这是面试高频题。三个维度对比每层的代价（$n$=序列长，$d$=维度）：

| 层类型 | 每层计算复杂度 | 顺序操作数（串行步） | 最大路径长度（任意两词信息传递） |
|--------|--------------|-------------------|------------------------------|
| 自注意力 | $O(n^2 \cdot d)$ | $O(1)$ | $O(1)$ ← 一步直达 |
| 循环 RNN | $O(n \cdot d^2)$ | $O(n)$ ← 必须排队 | $O(n)$ ← 远依赖衰减 |
| 卷积 | $O(k\cdot n\cdot d^2)$ | $O(1)$ | $O(\log_k n)$ |

读这张表的三个结论：
1. **顺序操作数**：RNN 是 $O(n)$（不可并行的瓶颈），自注意力是 $O(1)$ → **可并行**。
2. **最大路径长度**：RNN 远距离要走 $n$ 步（信息一路衰减），自注意力**任意两词 1 步直达** → **长依赖强**。
3. **代价**：自注意力是 $n^2$（序列越长越贵），当 $n < d$ 时（多数 NLP 场景 $n\!\approx\!512, d\!\approx\!512$）反而比 RNN 的 $n d^2$ 划算；$n$ 极大时 $n^2$ 成为瓶颈 → 催生 FlashAttention、稀疏注意力、线性注意力等优化。

```
 信息从"词1"传到"词n"要走几步？
 RNN:           1→2→3→...→n      (n 步，越远越糊)
 Self-Attn:     1 ────────► n     (1 步，清晰)
```

## 8. 并行性：训练为什么快这么多

RNN 训练时，时间步 $t$ 必须等 $t-1$ 算完——**整个 batch 内每条样本都得串行走 $n$ 步**，GPU 大量空转。

Transformer 把"句子内所有位置"打包成矩阵，一次大矩阵乘法 $QK^\top$ 同时算出**所有位置对所有位置**的关系。GPU/TPU 最擅长的就是大矩阵乘——**整层一次算完，无时间步依赖**。

```
RNN 一个 batch 的时间轴：    [t1]→[t2]→[t3]→...→[tn]   (墙钟时间 ∝ n)
Transformer：               [所有 t 一次性并行]        (墙钟时间 ∝ 1 个大 matmul)
```

注意：**训练**时 Decoder 也能并行（Teacher Forcing + 掩码，整句一次喂入）；但**推理生成**时仍需逐 token 自回归（这就是 KV-Cache 优化的战场，见 [[llm-algo/gpt2/模型架构]]）。

## 9. 演化史：三大分支

原始 Encoder-Decoder 之后，社区按"只保留哪半边"分裂出三条路线：

```
                  2017 原始 Transformer (Encoder + Decoder)
                       │
        ┌──────────────┼───────────────────┐
        ▼              ▼                     ▼
   Encoder-only   Encoder-Decoder      Decoder-only
   (只读懂)       (读懂+生成)          (只生成，自回归)
   BERT/RoBERTa   T5/BART              GPT/LLaMA/DeepSeek
   理解类任务     翻译/摘要            对话/通用大模型 ★主流
```

| 分支 | 注意力可见性 | 代表 | 擅长 | 笔记 |
|------|------------|------|------|------|
| Encoder-only | 双向（看全文） | BERT | 分类、NER、检索 | [[llm-algo/bert]] |
| Encoder-Decoder | Enc双向 + Dec掩码 | T5、BART | 翻译、摘要 | — |
| **Decoder-only** | **单向掩码（只看左侧）** | GPT-2/3、LLaMA、DeepSeek | **生成、对话、通用** | [[llm-algo/gpt2/模型架构]] |

**为什么 Decoder-only 成为大模型主流？**
1. **训练目标统一且简单**：next-token prediction，任何文本都是免费标注，**数据规模可无限扩展**——契合 Scaling Law。
2. **架构最简洁**：去掉 Encoder 与交叉注意力，纯堆 Decoder 层，工程与并行最干净。
3. **In-Context Learning 涌现**：自回归预训练天然学会"看上文续写"，少样本提示即可完成新任务，无需为每个任务改架构。
4. 现代化改造：Pre-Norm（LN 放子层前，更稳）、RMSNorm、RoPE、SwiGLU 激活、GQA、MoE 稀疏 FFN……但骨架仍是 2017 那套自注意力。

## 10. 影响

- **统一了 AI 的"主干网络"**：NLP、CV（ViT）、语音、蛋白质（AlphaFold）、多模态（CLIP/GPT-4V）几乎都收敛到 Transformer，一套架构吃天下。
- **确立了"预训练 + 微调/提示"范式**：先在海量无标注语料自监督预训练，再下游适配——把 NLP 从"为每个任务造模型"带入"一个大模型解所有任务"。
- **打开了 Scaling Law 时代**：因为可并行、可堆深、数据无限，"加参数 + 加数据 + 加算力 = 更强"成立，直接孕育了 GPT-3/4、LLaMA、DeepSeek 等大模型。
- **重塑了 AI-Infra**：$O(n^2)$ 注意力与巨大 FFN 催生了 FlashAttention、KV-Cache、张量/流水/序列并行、MoE、量化等一整套系统优化栈（本仓库后续章节的主战场）。

## 数值例子 / 对照（手算建立量纲感）

**例：原始 base 模型参数量粗算**（$d_{model}=512,\ d_{ff}=2048,\ h=8,\ N=6$ 层 Encoder + 6 层 Decoder）。

单个 Encoder 层主要权重：
- 多头注意力 $W^Q,W^K,W^V,W^O$ 各 $512\times512$ → $4 \times 512^2 \approx 1.05\text{M}$。
- FFN：$W_1\ (512\times2048) + W_2\ (2048\times512) = 2\times512\times2048 \approx 2.10\text{M}$。
- 单 Encoder 层 $\approx 1.05 + 2.10 = 3.15\text{M}$（忽略 bias / LN）。

**验证"FFN 约占 2/3"**：$2.10 / 3.15 \approx 0.667$ ✓ —— 与文首结论吻合：**FFN 吃掉约三分之二参数**。

整机粗估：Encoder 6 层 + Decoder 8 层（Decoder 多一个交叉注意力，约 4.2M/层）：
$$ 6\times3.15 + 8\times4.2 \approx 18.9 + 33.6 \approx 52.5\text{M（权重）} $$
加上词嵌入（词表约 37000 × 512 ≈ 19M，输入输出共享）后总量 **约 65M 参数**，与论文公布的 base 模型 **约 65M** 量级一致（具体以官方论文为准）。

**例：注意力分数矩阵的显存**。序列长 $n=1024$、$h=8$ 头、batch=1、FP16（2 字节）：
$$ \text{attn 矩阵} = 8 \times 1024 \times 1024 \times 2\,\text{B} \approx 16\,\text{MB（单层）} $$
$n$ 翻倍到 2048 → 约 64MB（**四倍增长**，$O(n^2)$ 的直观痛点）。这就是为什么长上下文要 FlashAttention（不实体化整个 $n\times n$ 矩阵）。

**例：单层注意力 FLOPs**（$n=512,d=512$）：$QK^\top$ 约 $2n^2 d = 2\times512^2\times512 \approx 0.27\,$GFLOP，乘 $V$ 同量级——配合表 7 的 $O(n^2 d)$ 复杂度，量纲自洽。

## 常见问题

| 问题 | 一句话答案 |
|------|-----------|
| 为什么除以 $\sqrt{d_k}$？ | 防止点积过大把 softmax 推入饱和区导致梯度消失。 |
| 自注意力天生看得见词序吗？ | **看不见**，必须靠位置编码注入，否则等价于词袋。 |
| 多头比单头强在哪？ | 在多个子空间并行捕捉不同关系（语法/指代/语义），代价却与单头相当。 |
| 为什么能取代 RNN？ | 顺序操作 $O(1)$ 可并行 + 任意两词路径 $O(1)$ 长依赖强（见表 7）。 |
| Decoder 的掩码作用？ | 训练时遮住未来词，保证自回归"只能看左侧"，防止偷看答案。 |
| 为什么现代大模型多是 Decoder-only？ | 目标统一(next-token)、数据无限可扩、ICL 涌现、架构最简，契合 Scaling Law。 |
| 自注意力的最大缺点？ | 复杂度 $O(n^2)$，长序列又慢又费显存 → FlashAttention / 稀疏 / 线性注意力。 |
| FFN 为什么值得优化？ | 占约 2/3 参数且激活稀疏 → MoE 把它拆成稀疏激活的多专家。 |
