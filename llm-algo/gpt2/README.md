## 0. 一句话锚点

**GPT-2 = GPT-1 的架构 + 更大的模型（最大 ~15 亿参数）+ 更大更干净的数据（WebText ~40GB）+ 一个大胆论断：只要语言模型训得足够好，它在没见过任何任务标注的情况下，也能直接做翻译、摘要、问答。**

这个论断的官方说法就是论文标题：
> *Language Models are Unsupervised Multitask Learners*（语言模型是无监督多任务学习者，2019，Radford et al.，以官方为准）

记住三个词就够了：**放大（scale）**、**网页数据（WebText）**、**零样本（zero-shot）**。

```
            GPT-1                         GPT-2
   ┌──────────────────────┐    ┌─────────────────────────────┐
   │ 预训练 + 每个任务微调  │ ──▶ │ 只预训练，不微调，用提示做任务 │
   │  117M 参数            │    │  最大 1.5B 参数（×13）        │
   │  BooksCorpus(~5GB)    │    │  WebText(~40GB)             │
   └──────────────────────┘    └─────────────────────────────┘
```

## 1. 地基 / 前置：先把"语言模型"拆到原子

### 1.1 语言模型在算什么？

一个**语言模型（Language Model, LM）** 的任务，就是给一串词，预测**下一个词**。形式化：给定前面的 token 序列 $x_1, x_2, \dots, x_{t-1}$，模型输出下一个 token 的概率分布

$$p(x_t \mid x_1, x_2, \dots, x_{t-1})$$

把整句话的概率用**链式法则**拆开：

$$p(x_1, \dots, x_n) = \prod_{t=1}^{n} p(x_t \mid x_1, \dots, x_{t-1})$$

这叫**自回归（autoregressive）**：每生成一个词，就把它接到输入末尾，再预测下一个。

```
输入: "中 国 的 首 都 是"
                          │
                          ▼
               ┌─────────────────────┐
               │   GPT-2 (Decoder)   │
               └─────────────────────┘
                          │
                          ▼
   下一个 token 的概率分布:  北京 0.62 | 上海 0.05 | 一 0.03 | ...
                          │ 取最高(或采样)
                          ▼
                       输出 "北京"  → 接回输入，循环
```

**为什么这件事重要？** 因为"预测下一个词"看似简单，但要预测得准，模型必须隐式地学会语法、常识、世界知识，甚至简单推理。这是 GPT-2 论文的核心直觉：**把下一个词预测做到极致，等于学会了很多任务。**

### 1.2 训练目标（损失函数）

训练就是让模型对**真实的下一个词**给出尽可能高的概率。用**交叉熵（cross-entropy）**，对整个语料最小化：

$$\mathcal{L} = -\sum_{t} \log p(x_t \mid x_{<t})$$

这里 $x_{<t}$ 是 $x_t$ 之前所有 token 的简写。注意：**没有任何人工标注**——标签就是"文本里的下一个词"，文本自己就是答案。这就是"无监督"的来源。

### 1.3 GPT-2 用的架构（一句话，细节见 [[llm-algo/gpt2/模型架构]]）

GPT-2 是 **Decoder-only Transformer**：只有 Transformer 的解码器堆叠，配**因果掩码（causal mask）**，保证位置 $t$ 只能看到 $\le t$ 的 token（不能偷看未来）。

```
  token ──▶ [词嵌入 + 位置嵌入]
                 │
                 ▼
        ┌─────────────────────┐   ×N 层
        │  Masked Self-Attn   │   (因果掩码: 只看左边)
        │  + Feed-Forward     │
        │  (Pre-LayerNorm)    │
        └─────────────────────┘
                 │
                 ▼
        [LayerNorm] ─▶ [输出投影 = 词嵌入转置]
                 │
                 ▼
         softmax → 下一个 token 概率
```

## 2. GPT-2 相对 GPT-1 到底改了什么？

GPT-2 **没有发明新架构**，它是工程化的"放大 + 微调结构"。关键改动：

| 维度 | GPT-1 (2018) | GPT-2 (2019) | 为什么改 |
|------|--------------|--------------|----------|
| 参数量 | 117M | 117M / 345M / 762M / **1.5B** | 验证 scale 带来能力 |
| 数据 | BooksCorpus ~5GB | WebText ~40GB | 更广、更多任务自然出现 |
| 上下文长度 | 512 token | **1024** token | 看更长上下文 |
| 词表 | ~40K | **50257**（BPE，字节级） | 任意 Unicode 不 OOV |
| LayerNorm 位置 | Post-LN（在残差后） | **Pre-LN**（在残差前）+ 末尾加一个 LN | 深层更稳、好训练 |
| 残差初始化 | 标准 | 残差层权重 ×$\frac{1}{\sqrt{N}}$（$N$=层数） | 防深层激活爆炸 |
| 使用方式 | 预训练 + **每任务微调** | 预训练 + **zero-shot 提示** | 核心论断 |

**Post-LN vs Pre-LN（这是最常被问的结构改动）：**

```
   Post-LN (GPT-1/原始Transformer)      Pre-LN (GPT-2)
   x ─┬─▶ Sublayer ─▶ (+) ─▶ LN ─▶     x ─┬─▶ LN ─▶ Sublayer ─▶ (+) ─▶
      └──────────────┘                    └─────────────────────┘
   归一化在残差相加"之后"               归一化在进子层"之前"
   深层时梯度不稳，需 warmup            残差是干净的恒等通路，深层更好训
```

为什么 Pre-LN 更稳？因为残差通路 $x \to x + \text{Sublayer}(\text{LN}(x))$ 上的 $x$ 没有被反复归一化"压缩"，梯度可以直接顺着加法回传，深到几十层也不容易梯度消失/爆炸。

## 3. 四种规模：参数量是怎么来的？

GPT-2 一共放出 4 个尺寸（以官方为准，约数）：

| 名称 | 层数 $L$ | 隐藏维 $d_{model}$ | 头数 $h$ | 参数量 |
|------|---------|------------------|---------|--------|
| Small (117M/124M) | 12 | 768 | 12 | ~1.24 亿 |
| Medium (345M) | 24 | 1024 | 16 | ~3.5 亿 |
| Large (762M) | 36 | 1280 | 20 | ~7.6 亿 |
| XL (1.5B) | 48 | 1600 | 25 | ~15 亿 |

注意：每个头的维度 $d_{head} = d_{model}/h$，四个尺寸都约等于 64（768/12 = 1024/16 = 1280/20 = 1600/25 = 64）。这是 Transformer 的经典选择。

```
   规模阶梯 (参数量 ~对数级增长)
   Small  ▏ 0.12B
   Medium ▍ 0.35B
   Large  ▋ 0.76B
   XL     █ 1.5B    ← "GPT-2" 通常默认指这个
```

**核心发现：随着模型变大，zero-shot 各项任务的成绩稳步上升，还没有饱和**——这条曲线直接催生了后来的 GPT-3（再放大 100 多倍）。

## 4. WebText：数据质量从哪来？

模型再大，喂垃圾也学垃圾。GPT-2 的关键是数据**又多又干净**。

**WebText 的构造逻辑（以官方为准）：**

```
   Reddit 上所有外链
        │  过滤: 这条链接所在的帖子 karma(赞) ≥ 3
        ▼              （人类点了赞 = 内容大概率有价值）
   保留高质量网页 ──▶ 抓正文、去重、清洗
        │
        ▼  并且: 移除所有 Wikipedia 页面
   WebText ≈ 800万文档, ~40GB 文本
```

两个设计很妙：

1. **用 Reddit karma 当"人类质量过滤器"**：不需要人工标注，借众包点赞筛掉低质内容——这本身就是"无监督"思想的延伸。
2. **故意删掉 Wikipedia**：因为很多下游评测（问答等）用 Wikipedia 当测试集，删掉它能让 zero-shot 评测更可信（避免训练集泄漏测试答案）。

**为什么 WebText 支撑了"多任务"？** 因为网页文本里天然包含各种任务的"示范"：有人写"翻译：…→…"，有人写"TL;DR（太长不看）：…"，有人写问答。模型在预测下一个词时，**顺带就把这些任务的输入-输出模式学了进去**。

## 5. 为什么是"无监督多任务学习者"？（核心思想）

这是整篇论文最值钱的一句话，拆开看：

### 5.1 传统做法：一个任务一个模型

```
   翻译数据 ─▶ 训练翻译模型 (有监督, 需配对标注)
   摘要数据 ─▶ 训练摘要模型 (有监督, 需配对标注)
   问答数据 ─▶ 训练问答模型 (有监督, 需配对标注)
```

每个任务都要专门标注数据、专门微调，互不相通。

### 5.2 GPT-2 的视角：所有任务都是条件语言建模

把"做任务"重写成一个统一的条件概率：

$$p(\text{output} \mid \text{input}, \text{task})$$

而**任务（task）本身可以用自然语言写在输入里**。例如：

- 翻译：输入 `"把下面翻译成法语: cheese ="`，输出 `"fromage"`
- 摘要：输入 `"……（长文）…… TL;DR:"`，输出 `"……摘要……"`
- 问答：输入 `"问题: 法国首都? 答案:"`，输出 `"巴黎"`

于是**所有任务都退化成"预测下一个词"**。一个语言模型只要在海量自然文本上学得够好，就同时学会了无数个任务——因为这些任务的范例本来就散落在网页文本里。

```
   单一目标: 预测下一个词
   ────────────────────────────────────────────
   隐式学到 ▶ 语法  ▶ 常识  ▶ 翻译模式  ▶ 摘要模式  ▶ 问答模式 ...
   ────────────────────────────────────────────
   = 无监督(没标注) + 多任务(一锅端) 的学习者
```

**"无监督"** = 训练时只用原始文本、没有任务标签。
**"多任务"** = 同一个模型、同一套权重，能做很多种任务。
**"学习者"** = 这些能力是**学**出来的，不是规则写死的。

## 6. zero-shot：不微调怎么"做任务"？

GPT-2 最震撼的演示是：**评测时完全不更新任何参数**，只靠在输入里写提示。

```
                  ┌────────── 你提供的提示(prompt) ──────────┐
   输入文本:  "Translate English to French:  sea otter =>"
                  └───────────────────────────────────────────┘
                                   │
                                   ▼
                          GPT-2 (权重冻结!)
                                   │
                                   ▼
                自回归续写 ──▶ " loutre de mer"
```

- **zero-shot（零样本）**：提示里**只给任务说明**，不给任何范例。
- 对比 GPT-3 后来提出的 **few-shot**：提示里塞**几个示范**再让模型续写（in-context learning），但 GPT-3 同样**不更新权重**。

GPT-2 的论文主要展示 zero-shot，并在多个数据集上取得当时惊人的成绩（如在 LAMBADA 语言建模、阅读理解 CoQA、部分翻译/摘要上以官方数字为准）。它**没有全面超过专门微调的有监督模型**，但"完全不训练就能做到这个程度"本身就是突破。

**关键区分（容易混）：**

```
   微调(fine-tune)    : 用任务数据 → 改模型权重   (GPT-1 路线)
   zero/few-shot 提示 : 权重不动 → 改输入提示词   (GPT-2 / GPT-3 路线)
```

## 7. GPT-1 / GPT-2 / GPT-3：一条放大主义的直线

三代 GPT 共享**同一个 Decoder-only 架构思路**，差别几乎全在"规模 + 数据 + 使用方式"。

```
   GPT-1 (2018)        GPT-2 (2019)         GPT-3 (2020)
   117M                117M ~ 1.5B          125M ~ 175B
   BooksCorpus ~5GB    WebText ~40GB        ~570GB+ 清洗后(CommonCrawl等)
   预训练+微调          预训练+zero-shot     预训练+few-shot(上下文学习)
   "迁移学习有效"       "LM 是无监督多任务"  "LM 是 few-shot 学习者"
        │                    │                    │
        └──── 同架构, 越变越大, 能力越来越强 (涌现) ────┘
```

| 维度 | GPT-1 | GPT-2 | GPT-3 |
|------|-------|-------|-------|
| 最大参数 | 0.117B | 1.5B | 175B |
| 上下文 | 512 | 1024 | 2048 |
| 论文标题主张 | 生成式预训练改善理解 | 无监督多任务学习者 | few-shot 学习者 |
| 核心用法 | 每任务微调 | zero-shot 提示 | few-shot 提示 |
| 架构变化 | 原始 Post-LN | Pre-LN + 残差缩放 | 同 GPT-2 + 稀疏/稠密注意力交替 |

**主线逻辑**：GPT-2 证明"放大有用、不微调也行"，GPT-3 就把这条路走到极致——再放大 100 多倍，发现 few-shot 能力"涌现"。所以理解 GPT-2，是理解整个大模型时代的钥匙。详见 [[llm-algo/gpt3/README]]。

## 数值例子 / 对照

### 例 1：手算 GPT-2 XL 的参数量（量级估算）

Transformer 参数主要来自两部分：**嵌入** 和 **每层的 Attention+FFN**。取 XL：$L=48$，$d=1600$，词表 $V=50257$，上下文 $T=1024$。

**(1) 嵌入层**
- 词嵌入：$V \times d = 50257 \times 1600 \approx 8.04 \times 10^7$（约 0.08B）
- 位置嵌入：$T \times d = 1024 \times 1600 \approx 1.6 \times 10^6$（约 0.0016B）
- 输出投影与词嵌入**权重共享**（weight tying），不额外算。

**(2) 每层 Transformer Block**（忽略 LayerNorm 的微小项）
- 自注意力 $Q,K,V$ 投影 + 输出投影：$4 \times d^2 = 4 \times 1600^2 \approx 1.02 \times 10^7$
- 前馈 FFN（中间维 $4d$）：$2 \times d \times 4d = 8 d^2 = 8 \times 1600^2 \approx 2.05 \times 10^7$
- 每层合计 ≈ $12 d^2 \approx 3.07 \times 10^7$（约 0.031B）

**(3) 48 层总和**
$$48 \times 3.07\times10^7 \approx 1.47 \times 10^9$$

加上嵌入 ≈ $1.47\text{B} + 0.08\text{B} \approx 1.55\text{B}$ ✅，与官方 ~1.5B 量级吻合。

> 经验公式：纯 Transformer 主体参数 $\approx 12 \cdot L \cdot d^2$。记住它，任何尺寸都能秒估。

### 例 2：zero-shot 的"句子概率"直觉

假设让 GPT-2 续写 `"The capital of France is"`，下一词分布（示意）：

| 候选 | 概率 |
|------|------|
| Paris | 0.71 |
| the | 0.06 |
| a | 0.04 |
| London | 0.01 |

模型把概率质量压倒性地给了 `Paris`——**它不是被"问答任务"训练过，而是在 WebText 里见过无数"…capital of France is Paris…"**。这就是 zero-shot 问答的本质：**知识藏在下一个词的条件概率里**。

整句对数概率（贪心取最高）：
$$\log p(\text{"Paris"} \mid \text{prefix}) = \log 0.71 \approx -0.34$$
越接近 0，模型越"确信"。

## 常见问题

| 问题 | 答案 |
|------|------|
| GPT-2 用了 Encoder 吗？ | 没有。它是 **Decoder-only**，只有带因果掩码的自注意力。 |
| "1.5B" 是唯一的 GPT-2 吗？ | 不是，有 4 个尺寸（117M/345M/762M/1.5B）。1.5B 是最大、常被默认指代的那个。 |
| zero-shot 和微调差在哪？ | 微调改权重、需任务数据；zero-shot **权重冻结**，只改输入提示。 |
| GPT-2 比有监督模型强吗？ | 多数任务上**还没超过**专门微调的模型，但"完全不训练就能做"是质的突破。 |
| 为什么删掉 Wikipedia？ | 防止训练集泄漏到下游评测集，让 zero-shot 成绩可信。 |
| Pre-LN 是 GPT-2 发明的吗？ | GPT-2 把 LN 移到子层前并在末尾加一个 LN（细节以官方为准），让深层训练更稳，后续大模型普遍沿用。 |
| 为什么叫"无监督多任务"？ | 训练只用原始文本（无监督），但一个模型能做多种任务（多任务）。 |
| 和 GPT-3 最大区别？ | 规模（1.5B vs 175B）和用法（zero-shot vs few-shot 上下文学习）。 |
| 词表为何是字节级 BPE？ | 50257 的字节级 BPE 能编码任意 Unicode，永不 OOV（未登录词）。 |
| GPT-2 当年为何分阶段开源？ | OpenAI 出于"被滥用生成假信息"的担忧，先放小模型、后放 1.5B（以官方公告为准）。 |
