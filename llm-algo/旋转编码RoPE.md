## 0. 一句话锚点

> **RoPE = 给 query 和 key 各自「按位置转一个角度」**。位置 $m$ 的向量被旋转 $m\theta$，位置 $n$ 的被旋转 $n\theta$。两者做点积时，旋转角度相减，结果只依赖 $(m-n)$——**绝对位置喂进去，相对位置自动留下来**。

记住这张图，后面全是它的展开：

```
   原始向量              旋转 m·θ 后
   q (位置 m)  ──旋转──►  R(mθ)·q
   k (位置 n)  ──旋转──►  R(nθ)·k

   点积:  (R(mθ)q)·(R(nθ)k) = qᵀ R((m-n)θ) k
                                      └────┬────┘
                                   只剩相对位置 (m-n)！
```

---

## 1. 地基：注意力为什么「看不见」位置

Transformer 的自注意力核心是一个**点积**：第 $i$ 个 token 对第 $j$ 个 token 的打分

$$\text{score}(i,j) = q_i \cdot k_j = \sum_d q_{i,d}\,k_{j,d}$$

**问题来了**：这个公式里只有「内容」$q_i, k_j$，**没有任何下标 $i,j$ 的影子**。

把句子里的词随便打乱顺序，每个 $q,k$ 向量不变，所有点积分数也完全不变。也就是说——

```
"狗 咬 人"     的注意力分数矩阵
        ‖   （只要词向量相同）
"人 咬 狗"     完全一样！

注意力本身是「集合运算」，不是「序列运算」。
```

**为什么这是灾难**：语言的意义高度依赖顺序（"猫吃鱼" ≠ "鱼吃猫"）。所以我们**必须**人为往模型里注入「谁在前、谁在后、隔多远」的信息。这就是**位置编码 (Positional Encoding)** 存在的唯一理由。

---

## 2. 位置编码三流派

| 流派 | 做法 | 关键缺陷 |
|------|------|---------|
| **绝对位置编码** | 给每个位置 $m$ 一个固定向量 $p_m$，**加**到词向量上：$x_m + p_m$ | 模型学到的是「第 5 个位置」这种绝对坐标；换个起点（长文本/平移）就失灵；外推差 |
| **相对位置编码** | 在注意力分数里显式加一项 $b_{i-j}$，只看间距 | 通常要改注意力公式、加可学习参数或查表，和高效 kernel（FlashAttention/线性注意力）不友好 |
| **旋转位置编码 RoPE** | 不加偏置、不查表，**把 $q,k$ 旋转一个正比于位置的角度** | 几乎没有缺陷，是当前主流（LLaMA / GLM / Qwen / DeepSeek 等都用） |

**核心诉求**：我们想要一个函数 $f$，让

$$\langle f(q, m),\; f(k, n)\rangle = g(q, k,\; m-n)$$

即「带位置的 q 和带位置的 k」的内积，**只依赖相对位置 $m-n$**，而不依赖各自的绝对位置。RoPE 给出了这个 $f$ 的一个**优雅闭式解：旋转**。

```
绝对编码： x + p_m        ← 加法，污染了内容向量
RoPE：     R(mθ) · x      ← 旋转(乘法)，保模长，只改方向
                          ← 旋转角与位置成正比，是关键
```

---

## 3. 二维旋转矩阵——RoPE 的最小单元

RoPE 先把高维向量**两两分组**，每组是一个二维平面。先彻底搞懂二维。

**二维旋转矩阵**（把平面向量逆时针转 $\phi$ 弧度）：

$$R(\phi) = \begin{pmatrix} \cos\phi & -\sin\phi \\ \sin\phi & \cos\phi \end{pmatrix}$$

它作用在向量 $\binom{x}{y}$ 上：

$$R(\phi)\binom{x}{y} = \binom{x\cos\phi - y\sin\phi}{\;x\sin\phi + y\cos\phi}$$

```
   y
   ↑        旋转 φ
   |      ·  v'=(x', y')
   |    ·  ╱
   |  · ╱ φ
   |  ╱___________  v=(x, y)
   +----------------→ x
   旋转只转方向，长度 |v'| = |v| 不变（正交矩阵）
```

**RoPE 的二维定义**：位置为 $m$ 的二维向量 $q=(q_0,q_1)$，旋转角度取 $m\theta$（$\theta$ 是该平面的固定基频）：

$$f(q, m) = R(m\theta)\,q = \begin{pmatrix} q_0\cos m\theta - q_1\sin m\theta \\ q_0\sin m\theta + q_1\cos m\theta \end{pmatrix}$$

**为什么旋转角正比于位置 $m$**？因为旋转矩阵有个黄金性质：

$$R(\alpha)\,R(\beta) = R(\alpha+\beta), \qquad R(\alpha)^{\top} = R(-\alpha)$$

「角度可加」正是让点积里出现「角度相减 = 相对位置」的根本机制（见第 5 节）。

---

## 4. 复数视角：一行欧拉公式看穿 RoPE

二维平面 $(x, y)$ 等价于一个复数 $z = x + iy$。**旋转 $\phi$ = 乘以 $e^{i\phi}$**：

$$e^{i\phi}\,z = (\cos\phi + i\sin\phi)(x+iy)$$

展开实部虚部，**和第 3 节的矩阵乘法逐项相等**（这就是为什么复数视角 = 旋转矩阵）：

$$\text{实部} = x\cos\phi - y\sin\phi,\qquad \text{虚部} = x\sin\phi + y\cos\phi$$

于是 RoPE 在复数下极简：把位置 $m$ 的复向量 $q$ 乘上 $e^{im\theta}$：

$$f(q,m) = q\,e^{im\theta}, \qquad f(k,n) = k\,e^{in\theta}$$

```
复数 = 模长 × 旋转角
   z = r·e^{iα}
RoPE: 模长 r 不动（保内容），只把相位 α 推进 m·θ（注入位置）
```

复数视角的威力在下一节立刻兑现：相位运算变成简单的指数加减。

---

## 5. 关键魔法：点积里如何「自然冒出」相对位置

注意力点积在复数下写成 $\langle a,b\rangle = \mathrm{Re}(a\,\bar b)$（$\bar b$ 是共轭）。代入旋转后的 q、k：

$$
\langle f(q,m),\, f(k,n)\rangle
= \mathrm{Re}\big[(q\,e^{im\theta})\,\overline{(k\,e^{in\theta})}\big]
$$

共轭把第二个指数变号：$\overline{k\,e^{in\theta}} = \bar k\,e^{-in\theta}$，于是

$$
= \mathrm{Re}\big[q\,\bar k\;e^{i(m-n)\theta}\big]
$$

```
   e^{imθ} · e^{-inθ}  =  e^{i(m-n)θ}
        │        │              │
     q 的位置  k 的位置    只剩相对位置 (m-n)！
   绝对 m、绝对 n 在指数相加时互相抵消，神奇地融合成 m-n
```

**这就是全部魔法**：

- 我们**输入**的是绝对位置 $m$ 和 $n$（实现简单，每个 token 独立算）；
- 点积**输出**的相关性 $g(q,k,m-n)$ **只依赖 $m-n$**（语义上正是我们要的相对位置）。

用矩阵语言等价表述（第 3 节 $R$ 的性质 $R(m\theta)^\top R(n\theta)=R((n-m)\theta)$）：

$$(R(m\theta)q)^{\top}(R(n\theta)k) = q^{\top}R(m\theta)^{\top}R(n\theta)k = q^{\top}R((n-m)\theta)\,k$$

**绝对喂入，相对留下**——一句话概括 RoPE 的灵魂。它无需任何额外参数，不改注意力公式，因此天然兼容 FlashAttention、线性注意力等高效 kernel。

## 6. 多维拼装：高维向量怎么分组旋转 + 频率设计

实际 $q,k$ 是 $d$ 维（如 128 维）。RoPE 把它们**切成 $d/2$ 个二维对**：$(x_0,x_1),(x_2,x_3),\dots$。每一对用**自己的基频** $\theta_i$ 做旋转。

**频率（参考正弦编码，几何递减）**：

$$\theta_i = \text{base}^{-2i/d}, \quad i = 0,1,\dots,\tfrac d2-1,\quad \text{base}=10000$$

- $i=0$：$\theta_0 = 1$，**高频**，转得快——刻画近距离、细粒度的位置差异。
- $i$ 增大：$\theta_i \to$ 很小，**低频**，转得慢——刻画远距离、粗粒度的位置。

```
分组旋转（d 维向量，位置 m）：
  ┌ (x0,x1) ─ 旋转 m·θ0 (高频，转快) ┐
  │ (x2,x3) ─ 旋转 m·θ1            │
  │   ...        ...               │ → 拼回 d 维
  └ (x_{d-2},x_{d-1}) ─ 旋转 m·θ_{d/2-1} (低频，转慢) ┘

完整旋转矩阵是块对角的（每块一个 2×2 R）：
   ┌ R(mθ0)            ┐
   │       R(mθ1)      │   ← 稀疏，实现时根本不建大矩阵，
   │            ...    │     只对每对做 4 次乘加
   └              R(..)┘
```

**高效实现**（不显式构造矩阵，逐元素）：设 $\cos,\sin$ 已预算好，

$$q'_{\text{even}} = q_{\text{even}}\cos - q_{\text{odd}}\sin,\qquad q'_{\text{odd}} = q_{\text{even}}\sin + q_{\text{odd}}\cos$$

每个 token 仅 $O(d)$ 次乘加，可忽略不计。

## 7. 长度外推：为什么会崩，NTK / YaRN 怎么救

**外推 = 训练只见过短序列（如 4K），推理却要处理长序列（如 32K）**。RoPE 比绝对编码外推好，但**直接外推到远超训练长度仍会崩**。

**为什么崩**：位置 $m$ 越大，高频分量 $m\theta_0$ 累积的总旋转角越大。当 $m$ 超过训练见过的范围，高频对的相位进入「**从未见过的角度区间**」，注意力分数失真，PPL（困惑度）爆炸。

```
训练长度 L_train
   位置:  0 ........... L_train | L_train+1 ...... (外推区)
   高频相位 m·θ0:  见过的角度    | 全新角度→模型懵了
```

三种主流拯救方案：

| 方法 | 核心思想 | 直觉 | 代价 |
|------|---------|------|------|
| **PI 位置插值** (Position Interpolation) | 把位置 $m$ 缩放为 $m\cdot \frac{L_\text{train}}{L_\text{new}}$，即把长序列「压」回训练区间 | 不外推、改成「内插」，角度都在见过范围 | 需少量微调；高频分辨率被压缩，细粒度位置变模糊 |
| **NTK-aware 插值** | 不均匀缩放：**高频几乎不动、低频大幅放缩**。等价于把 base 从 10000 调大 | 高频管细节别动它；低频管长程，拉开它来覆盖长距离 | 通常**免微调**即可显著降 PPL |
| **YaRN** | NTK 的精细版：按波长分段处理（高频原样 / 低频插值 / 中间过渡带），并对注意力 logits 乘温度系数 $1/t$ 补偿 | 分波长精调 + 修正注意力熵 | 当前长上下文 SOTA 方案之一，少量微调即可扩到极长 |

```
频率轴上三方案如何动 θ：
  高频 θ0 ────────────── 低频 θ_{d/2-1}
  PI:    全部均匀压缩  ←←←←←←←←←←←←
  NTK:   高频几乎不变      低频大幅压缩 ←←
  YaRN:  原样   │ 过渡带 │  插值   （+ 注意力温度修正）
```

> 数值/公式细节（如 NTK 的 base 修正公式、YaRN 的温度系数）以官方论文与实现为准；此处给稳定直觉。

## 8. 数值示例：手算二维向量在几个位置的旋转与点积

取一个二维平面，基频 $\theta = 1.0$ rad/位置。设
- query 向量 $q = (1, 0)$，
- key 向量 $k = (1, 0)$（先取相同，方便看相对位置效果）。

**第一步：算各位置的旋转后向量**（$f(q,m)=R(m\theta)q$，$\theta=1$，角度 = $m$ 弧度）

用 $\cos,\sin$ 值：$\cos 0=1,\sin 0=0$；$\cos1\approx0.5403,\sin1\approx0.8415$；$\cos2\approx-0.4161,\sin2\approx0.9093$；$\cos3\approx-0.9900,\sin3\approx0.1411$。

| 位置 $m$ | 旋转角 | $R(m\theta)\binom{1}{0}=\binom{\cos m}{\sin m}$ |
|---------|-------|------------------------------------------------|
| 0 | 0 | $(1.0000,\ 0.0000)$ |
| 1 | 1 rad | $(0.5403,\ 0.8415)$ |
| 2 | 2 rad | $(-0.4161,\ 0.9093)$ |
| 3 | 3 rad | $(-0.9900,\ 0.1411)$ |

**第二步：算点积，验证「只依赖相对位置」**。

理论保证：$f(q,m)\cdot f(k,n) = q^\top R((n-m)\theta)k = \cos\big((m-n)\theta\big)$（因为 $q=k=(1,0)$，点积就是夹角余弦，夹角 = $(m-n)$ 弧度）。

逐数验证 query 在 $m$、key 在 $n$ 的点积 $= q'_x k'_x + q'_y k'_y$：

- **$m=2, n=1$**（相对 $=1$）：
  $(-0.4161)(0.5403) + (0.9093)(0.8415) = -0.2248 + 0.7652 = \mathbf{0.5404}$
  与理论 $\cos(2-1)=\cos 1 = 0.5403$ ✔
- **$m=3, n=1$**（相对 $=2$）：
  $(-0.9900)(0.5403) + (0.1411)(0.8415) = -0.5349 + 0.1188 = \mathbf{-0.4161}$
  与理论 $\cos(3-1)=\cos 2 = -0.4161$ ✔
- **$m=1, n=0$**（相对 $=1$）：
  $(0.5403)(1) + (0.8415)(0) = \mathbf{0.5403}$
  与 $m=2,n=1$ 的 0.5404 **几乎相同**——绝对位置不同 $(2,1)$ vs $(1,0)$，但**相对距离同为 1，点积相同** ✔✔

```
关键观察（同样相对距离 → 同样分数）：
  (m,n)=(1,0)  相对1  → 点积 0.5403
  (m,n)=(2,1)  相对1  → 点积 0.5404   ←  绝对位置变了，分数没变！
  (m,n)=(3,1)  相对2  → 点积 -0.4161
  相对距离越大(1→2)，余弦从 0.54 掉到 -0.42 → 远的 token 关注度自然衰减
```

**结论**：手算完美复现了第 5 节的理论——**点积值只由相对位置 $m-n$ 决定，且随距离增大单调变化**，这正是 RoPE 想要的「近相似、远相异」。

## 对照 / 复杂度表

| 维度 | 绝对(正弦) | 可学习绝对 | 相对(查表/偏置) | **RoPE** |
|------|-----------|-----------|----------------|----------|
| 注入方式 | 加到 embedding | 加到 embedding | 加到注意力分数 | **乘(旋转)到 q,k** |
| 额外参数 | 无 | $O(L\cdot d)$ | 通常需要 | **无** |
| 编码的是 | 绝对 | 绝对 | 相对 | **绝对喂入→点积出相对** |
| 外推能力 | 较差 | 差(超表崩) | 中 | **好(可配 NTK/YaRN)** |
| 高效 kernel 兼容 | 好 | 好 | **差** | **好** |
| 每 token 开销 | $O(d)$ 加 | 查表 | $O(L)$ | **$O(d)$ 乘加** |

## 常见问题

| 疑问 | 真相 |
|------|------|
| RoPE 是加还是乘？ | **乘**（旋转 = 正交矩阵左乘 / 复数乘 $e^{i\theta}$）。绝对编码才是加。 |
| 为什么旋转能保留内容信息？ | 旋转是正交变换，**模长不变**，只改方向（相位）。内容（模长）不被污染，位置只写进相位。 |
| 只对 q、k 旋转，value 要旋转吗？ | **不旋转 value**。RoPE 只作用于 q、k，因为相对位置只需在「打分」（点积）阶段体现。 |
| 为什么用几何递减的频率 $\theta_i$？ | 多尺度：高频管细粒度近距、低频管粗粒度远距，覆盖从 1 到上万的位置跨度。 |
| RoPE 凭什么外推比绝对好？ | 它编码的是相对位置且角度连续可外推；但仍需 NTK/YaRN 修正高频，才能稳上长上下文。 |
| RoPE 会增加多少计算？ | 每 token 仅 $O(d)$ 次乘加，$\cos/\sin$ 可预计算并缓存，开销可忽略。 |
| 长上下文为什么改 base（如 1e4→1e6）？ | 调大 base 等价于压低所有频率、拉长波长，让低频对覆盖更远位置——NTK 思路的简化实现。 |
| 词序打乱注意力真不变吗？ | 不加位置编码时**真不变**（集合运算）；正是这个事实逼出了 RoPE 的必要性。 |
