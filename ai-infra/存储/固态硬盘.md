## 0. 一句话锚点

固态硬盘 = **主控（大脑）+ 闪存颗粒（仓库）+ 缓存（暂存台）+ PCB（地基）**。颗粒决定寿命与容量价格，主控决定速度与算法，接口/协议（M.2 NVMe）决定带宽上限。

> 一句对照：机械硬盘像"图书管理员跑去书架取书"（有物理移动，毫秒级）；SSD 像"给每本书一个电子编号、直接电寻址"（无移动，微秒级，且可同时取很多本）。

## 1. 地基：SSD 为什么比机械硬盘快几个数量级

机械硬盘（HDD）的延迟由两个物理动作主导：

```
HDD 一次随机读：
  寻道(磁头移到目标磁道) ~3-10 ms
  + 旋转等待(盘片转到目标扇区) ~2-4 ms（7200rpm 半圈≈4.17ms）
  = 约 5-12 ms，且随机 IOPS 仅 ~100-200
```

SSD 没有任何机械部件，读一个数据 = 给闪存单元一个地址、施加电压、读出电荷状态：

```
NAND SSD 一次随机读：
  闪存读延迟 ~50-100 µs（µs = 千分之一 ms）
  随机读 IOPS：SATA SSD ~10万，NVMe SSD ~50万-100万+
```

**数值手算**：同样跑 100 万次 4KB 随机读——
- HDD：$10^6 \times 5\,\text{ms} = 5000\,\text{s} \approx 83\,\text{min}$
- NVMe：$10^6 \div 5\times10^5\,\text{IOPS} = 2\,\text{s}$

差约 **2500 倍**。这就是为什么大模型训练把数据集放 SSD（甚至本地 NVMe）而非网络 HDD——否则 GPU 会被 IO 饿死（GPU starvation）。

SSD 快的第二个秘密是**并行**：一块盘内有多个闪存 Die / Plane，主控可以同时向它们发命令，就像多条流水线并行取货。NVMe 协议进一步把这个并行能力释放出来（见第 5 节）。

## 2. 固态硬盘的四大组成部件

> 原文真料：固态硬盘一般由四个部分组成——控制单元（主控）、存储单元（颗粒）、缓存单元、电路板。为节省成本，很多固态硬盘已不使用缓存芯片。

```
        ┌──────────────────────────────────────────┐
        │                  PCB 电路板                │
        │  ┌────────┐   ┌─────────┐   ┌──────────┐  │
   主机 │  │ 主控   │←→│ 缓存    │   │ NAND 颗粒 │  │
  (CPU)←┼─→│ 控制器 │   │(DRAM/无) │←→│ ×N 颗   │  │
  PCIe/ │  └────────┘   └─────────┘   └──────────┘  │
  SATA  │      ↑ FTL/纠错/磨损均衡         ↑ 实际存数据   │
        └──────────────────────────────────────────┘
```

**① 主控芯片（控制单元）=固态硬盘的大脑。** 数据处理能力、算法都靠它。它负责：地址映射（FTL，把主机看到的"逻辑块"翻译成颗粒上的"物理块"）、ECC 纠错、磨损均衡（让每个块擦写次数尽量平均）、垃圾回收（GC）。
- 原文主流主控厂商：马牌 **Marvell**、**三星**、慧荣 **Silicon Motion**、群联 **Phison**、智微 **Jmicron**、英韧 **InnoGrit** 等。

**② 闪存颗粒（存储单元）=仓库。** 真正存数据的地方，按"一个单元存几比特"分级（见第 3 节）。

**③ 缓存芯片（缓存单元）=暂存台。**
- 原文要点：缓存不是主要参数，但在**常用文件的随机读写**上有意义；主要品牌有南亚。如今"无外置缓存"卖得很好，很多厂商已取消缓存芯片以省成本，**实际缓存带来的提升普通用户体验不出来**。
- 原理补充：有 DRAM 缓存（DRAM-Cache）的盘把 FTL 映射表放在独立 DRAM 里，查表快；无 DRAM 盘用 **HMB（Host Memory Buffer）**借主机内存，或直接放部分 NAND，随机性能略弱但成本低。

**④ PCB 板=地基。** 把主控、颗粒、缓存三样焊在一块 PCB 上，就形成一个 M.2 固态硬盘。

## 3. 闪存颗粒：SLC→QLC 分级 与 正片/白片/黑片

### 3.1 按"每单元存几比特"分级

闪存的本质是给一个浮栅晶体管充入不同电荷量，用电压阈值区分"状态"。一个单元区分越多状态，存的比特越多，但状态间电压窗口越窄、越容易出错、寿命越短。

> 原文真料：根据密度差异分为 **SLC、MLC、TLC、QLC、PLC**，PLC 还没面世。稳定性、速度、价格排序为 **SLC ＞ MLC ＞ TLC ＞ QLC ＞ PLC**。现主流固态基本采用 **TLC 和 QLC** 居多。

| 类型 | 每单元比特 | 区分状态数 | 典型擦写寿命(P/E) | 速度/稳定 | 成本/容量 |
|------|-----------|-----------|------------------|----------|----------|
| SLC | 1 bit | 2 ($2^1$) | ~10万次 | 最强 | 最贵 |
| MLC | 2 bit | 4 ($2^2$) | ~3千-1万次 | 强 | 贵 |
| TLC | 3 bit | 8 ($2^3$) | ~1千-3千次 | 主流均衡 | 主流 |
| QLC | 4 bit | 16 ($2^4$) | ~数百-1千次 | 弱、缓外掉速 | 便宜大容量 |
| PLC | 5 bit | 32 ($2^5$) | 更低 | 未面世 | 理论最便宜 |

记忆锚点：每多 1 bit，要区分的电压档位**翻倍**（$2^n$），窗口被切得更细——这就是稳定性和寿命随 bit 数下降的物理原因。

### 3.2 颗粒等级：正片 / 白片 / 黑片

> 原文真料逐条保留：

- **正片**：分两种——① 闪存颗粒生产商（原厂）封装的好颗粒；② 品牌方向原厂直接采购**晶圆**再自行封装，品质与原厂封装无异。原厂封装型号可参考**金士顿 KC2500**。
- **白片**：正片中多次检测有小瑕疵的，实际使用可能好也可能一般，但基本问题不大；**不建议当主盘**，价格更便宜，可当游戏副盘。
- **黑片**：刚检测就有问题的次品，被厂商低价收去重新包装做成固态硬盘，**容易翻车、数据丢失几率大**。

```
晶圆(Wafer) → 切割 → 测试分级
                       ├─ 全优 → 正片（主盘首选）
                       ├─ 小瑕疵 → 白片（副盘可用）
                       └─ 有问题 → 黑片（次品，避坑）
```

## 4. M.2 固态硬盘规格 与 接口识别

> 原文真料：现在市场主流规格是 **M.2 2280**。

**M.2 2280 数字含义**：`22` = 宽度 22mm，`80` = 长度 80mm。同系列还有 2242、2260、22110 等，主控/颗粒越多越长。

### 4.1 怎么区分 NVMe 协议和 SATA 协议？

> 原文真料：最简单的区分方法就是看接口的位置——**NVMe 协议只有一个口（缺口），SATA 协议有两个口（缺口）**。但也有个别品牌把 NVMe 搞成两口的"另类"，需结合规格书确认。

```
金手指缺口（Key）位置示意：

M Key (NVMe 主流，单缺口)：
  ████████████ ▌█████████████████
                ↑ 一个缺口

B+M Key (SATA 常见，双缺口)：
  ███████ ▌███████ ▌██████████████
          ↑        ↑ 两个缺口
```

### 4.2 接口类型：B Key 与 M Key

> 原文真料：M.2 实际就是 **NGFF 接口**，分 **B Key 和 M Key**，目前 **M Key 是主流**，也就是现在的 NVMe 协议固态硬盘。

> 原文真料：M.2 接口固态硬盘体积小，适用台式机与笔记本（**单面颗粒台式/笔记本都可用，双面颗粒不兼容一些笔记本**）；NVMe 协议读写速度高于 SATA 协议几倍，所以现在几乎没人选 B Key 了。

- **单面颗粒 vs 双面颗粒**：颗粒只焊一面更薄，兼容超薄笔记本的限高卡槽；双面更厚，部分笔记本装不进。台式机 M.2 槽一般都能装。

## 5. PCIe vs SATA：通道、协议与带宽

同样是 M.2 外形，底下走的"路"完全不同，这是速度差几倍的根因。

```
SATA 通道：单条串行链路，AHCI 协议（为机械盘设计）
  主机 ──[1 队列 × 深度32]── SSD     上限 ~600 MB/s

PCIe 通道：多 lane 并行，NVMe 协议（为闪存设计）
  主机 ═[最多 65535 队列 × 每队列 64K 命令]═ SSD
  PCIe 3.0 ×4 ≈ 3500 MB/s
  PCIe 4.0 ×4 ≈ 7000 MB/s
```

**为什么 NVMe 比 SATA/AHCI 快不止"带宽"那点**：
- AHCI 只有 **1 个命令队列、深度 32**——为转速固定的机械盘设计，发再多命令盘也只能一个个寻道。
- NVMe 支持**最多 65535 个队列、每队列 65536 条命令**，正好喂饱 SSD 内部多 Die 的并行能力（呼应第 1 节"并行"）。在高并发随机 IO（如训练 DataLoader 多 worker 同时读）下，NVMe 优势被放大。

> 原文标题对应 **PCIe 3.0 篇**：PCIe 3.0 ×4 顺序读写理论上限约 3.5 GB/s，是 SATA SSD（~0.55 GB/s）的约 6 倍——印证原文"读写速度高于 SATA 协议几倍"。

**数值手算**：加载一个 50GB 的 tokenized 数据分片——
- SATA 600MB/s：$50\,\text{GB} \div 0.6\,\text{GB/s} \approx 83\,\text{s}$
- PCIe3.0 NVMe 3.5GB/s：$50 \div 3.5 \approx 14\,\text{s}$
- PCIe4.0 NVMe 7GB/s：$50 \div 7 \approx 7\,\text{s}$

## 6. 固态硬盘品牌：自产颗粒 vs 贴牌 vs 避坑

> 原文真料：品牌主要分**自产颗粒**和**贴牌**两类。

- **自产颗粒（有原厂晶圆/封装能力，质量可控）**：三星、西数（闪迪）、致钛（长江存储）、英特尔、海力士、铠侠（东芝）、英睿达（美光）等。
- **其它品牌（贴牌/采购颗粒封装）**：金士顿、威刚、影驰、雷克沙、浦科特、爱国者、海康威视、大华等。
- **避坑品牌**：某胜、某速、某维、某储及其它杂牌——多用白片/黑片，翻车率高。

选购逻辑：颗粒来源 > 主控型号 > 是否有 DRAM 缓存 > 质保年限/TBW。

> 原文 PCIe 固态硬盘优点：① 读写速度高于 SATA 协议几倍；② 体积小，适用台式机与笔记本。

## 7. AI-Infra 视角：SSD 在大模型训练/推理里到底干什么

这是把"消费级选盘知识"接到 [[00-知识地图]] 的关键一节。SSD（尤其本地 NVMe）是 GPU 之外最容易成为瓶颈的一环。

```
训练数据流（IO 链）：
  NVMe SSD ──顺序大块读──→ 内存(page cache) ──→ DataLoader workers
       │                                            │
       └─ 若太慢 → GPU 等数据(starvation) ←──── GPU 计算

Checkpoint 落盘（写）：
  GPU/CPU 内存 ──大块顺序写──→ NVMe（百 GB 级，要求高写带宽）

显存外溢 / Offload（读写混合）：
  KV-Cache / 优化器状态 ── 换出 ──→ NVMe（呼应 ZeRO-Infinity）
```

- **DataLoader**：训练时多个 worker 并发随机/顺序读分片，正是 NVMe 高 IOPS + 多队列的用武之地（见第 5 节）。
- **Checkpoint**：百 GB 级模型权重定期落盘，吃**顺序写带宽**与 TBW 寿命——这里 QLC 缓外掉速会拖慢保存。
- **NVMe Offload**：DeepSpeed 的 **ZeRO-Infinity** 可把优化器状态/参数卸载到 NVMe，用磁盘换显存，前提是盘够快（见 [[ai-framework/deepspeed/README]]）。
- **KV-Cache 卸载**：长上下文推理时 KV-Cache 巨大，部分方案把冷 KV 换到 NVMe（见 [[llm-optimizer/kv-cache]]、[[llm-inference/PD分离]]）。

记忆锚点：**训练读、Checkpoint 写、Offload 读写混合**——SSD 的三类负载，分别对应 IOPS、写带宽、混合时延三项指标。

## 实操：选购参数 + Linux 查盘/测速命令

### 选购看这几个参数

| 参数 | 含义 | 怎么挑 |
|------|------|--------|
| 接口/协议 | M.2 NVMe（PCIe）vs SATA | AI/重负载选 NVMe |
| PCIe 版本×lane | 3.0×4 / 4.0×4 | 决定带宽上限 |
| 颗粒类型 | TLC / QLC | 主盘/高写入选 TLC |
| 是否有 DRAM 缓存 | DRAM / HMB / 无 | 随机性能在意则选 DRAM |
| TBW | 总写入字节寿命 | 越大越耐写 |
| 单/双面颗粒 | 厚度 | 超薄笔记本选单面 |

### Linux 下查盘信息（nvme-cli）

```bash
# 列出所有 NVMe 盘及容量、型号
sudo nvme list

# 查看某盘的 SMART 健康/温度/已写入量（判断寿命）
sudo nvme smart-log /dev/nvme0n1

# 查看盘的链路速率与队列等控制器信息
sudo nvme id-ctrl /dev/nvme0n1
lspci -vv | grep -i -A2 'Non-Volatile'   # 看 PCIe LnkSta 协商到几.0 ×几
```

### 测顺序/随机性能（fio）

```bash
# 顺序读带宽（对标"读写速度高于 SATA 几倍"）
fio --name=seqread --filename=/dev/nvme0n1 --rw=read \
    --bs=1M --iodepth=32 --numjobs=1 --runtime=30 --direct=1

# 4K 随机读 IOPS（对标 DataLoader 多并发场景）
fio --name=randread --filename=/dev/nvme0n1 --rw=randread \
    --bs=4k --iodepth=128 --numjobs=4 --runtime=30 --direct=1
```

> 说明：`--filename` 直接指向裸设备会破坏数据，生产盘上请改成一个测试文件路径并保留 `--direct=1`。

参考阅读（原文链接保留）：**NVMe 高端固态硬盘推荐（PCIe 3.0 篇）**——https://zhuanlan.zhihu.com/p/455414014

## 常见问题 / 坑

| 坑 | 现象 | 原理 / 规避 |
|----|------|------------|
| 缓外掉速 | 大文件写到一半速度暴跌 | SLC Cache 用尽后写真实 QLC/TLC；大量写入选 TLC/大缓盘 |
| 双面颗粒装不进笔记本 | 物理装不上或顶盖 | 超薄本认准**单面颗粒** |
| 把 SATA 当 NVMe 买 | 速度只有 ~550MB/s | 看缺口：**单缺口=NVMe，双缺口多为 SATA**；以规格书为准 |
| 无 DRAM 盘随机弱 | 4K 随机/掉电后恢复慢 | 在意随机性能选 DRAM-Cache 盘 |
| 黑片/杂牌翻车 | 数据丢失、掉盘 | 选自产颗粒大厂；白片只做副盘，黑片避坑 |
| PCIe 协商降速 | 4.0 盘只跑出 3.0 速度 | 主板槽/CPU lane 限制；`lspci` 看 LnkSta |
| 寿命写穿 | 频繁 Checkpoint 写爆 TBW | 关注 TBW + `nvme smart-log` 的 Percentage Used |
| 装满掉速 | 用到 90%+ 变慢 | 预留 OP 空间，别长期接近写满 |
