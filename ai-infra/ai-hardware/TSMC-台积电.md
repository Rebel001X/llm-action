## 0. 一句话锚点

你在 vLLM 里调 batch、在 Megatron 里切 TP、在 NCCL 里调 All-Reduce——这些都是软件层。再往下，算力最终来自一块"硅片"上几百亿个晶体管的开关。**台积电（TSMC，Taiwan Semiconductor Manufacturing Company）就是把电路图变成真实硅片的那个工厂**。

理解它对 AI-Infra 工程师的价值在于：

1. **算力的物理上限来自制程**——同样面积，更先进的制程能塞下更多晶体管、跑更高频率、更省电。NVIDIA 每代 GPU（A100→H100→B200）的飞跃，一半归功于台积电换了更先进的节点。
2. **HBM 怎么贴到 GPU 上、为什么会缺货**——答案是台积电的 **CoWoS 先进封装**产能。2023–2024 年 H100 的瓶颈不是 GPU die，而是 CoWoS。
3. **出口管制、地缘、缺货**——这些影响你能不能买到卡、卡多贵，根子都在晶圆厂这一层。

```
   软件层   vLLM / Megatron / NCCL          ← 你平时调的
     │
   芯片层   H100 GPU（架构 Hopper）          ← NVIDIA 设计
     │
   制造层   TSMC N4 制程 + CoWoS 封装        ← 台积电"造"  ★本文★
     │
   材料层   硅晶圆 / EUV 光刻机 / HBM 颗粒    ← ASML / SK海力士
```

> ⚠️ 护栏：本文讲**稳定原理与机制**。具体某节点的精确晶体管密度、某光刻机的精确波长功率、某产品的良率数字会随时间和厂商保密而变，**精确数值以台积电/ASML 官方资料与权威拆解报告为准**。

## 1. 地基：晶体管、制程节点、Foundry 模式

把三个最底层的词拆成原子。

**① 晶体管（Transistor）**——芯片的最小开关。现代逻辑芯片用的是 **FET（场效应管）**：施加栅极电压，控制源极到漏极的电流通断，对应数字电路的 0/1。一颗 H100 级别的 GPU 上有**数百亿个**这样的开关。晶体管越小，单位面积能塞越多、开关越快越省电——这就是为什么人类一直追求"更小的制程"。

晶体管结构的演进（理解 N7→N3 的关键）：

```
平面 FinFET 演进：

  Planar（28nm 之前）        FinFET（22nm~N5/N4）        GAA/纳米片（N2 一代起）
  ┌──────────┐              ┌──┐ ┌──┐ ┌──┐            ═══════  ← 栅极环绕
  │  栅极     │              │鳍│ │鳍│ │鳍│            ▭▭▭▭▭   ← 沟道(片)
  ──────────── 沟道           └──┘ └──┘ └──┘            ═══════
  栅极只从"上面"控           栅极从"三面"包鳍          栅极从"四面"全包
  → 漏电严重                 → 控制力强、漏电少         → 进一步抑制漏电
```

**② 制程节点（Process Node，如 N7/N5/N4/N3）**——"代号"。历史上数字约等于晶体管关键尺寸（如栅极长度，单位纳米 nm）。**但今天的"7nm/5nm"已经是营销名，不再对应任何一个真实物理尺寸**（见第 4 节）。你只需记住：**数字越小 = 越先进 = 密度更高/更省电**。

**③ Foundry（纯代工）模式**——这是台积电模式的精髓。半导体公司分三类：

| 模式 | 谁设计芯片 | 谁造芯片 | 例子 |
|------|-----------|----------|------|
| IDM（垂直整合） | 自己 | 自己建厂造 | Intel（传统）、三星 |
| Fabless（无晶圆厂） | 自己 | 外包 | NVIDIA、AMD、苹果、华为海思 |
| **Foundry（代工）** | **不设计** | **只帮别人造** | **台积电（TSMC）** |

台积电的商业模式是"**我不和客户竞争，只帮所有人造芯片**"——这让 NVIDIA、苹果、AMD 这些 Fabless 公司放心把图纸给它。它的核心资产是**制程工艺 + 产能 + 良率**。

## 2. 光刻是核心：DUV vs EUV 的本质区别

要在硅片上"画"出几十亿个晶体管，靠的是**光刻（Photolithography）**：用光把电路图案投影到涂了光刻胶的晶圆上，曝光后显影、刻蚀，留下电路。**能画多细的线，取决于光的波长**。

物理原理（瑞利判据，分辨率公式）：

$$\text{最小可分辨线宽} \quad CD = k_1 \cdot \frac{\lambda}{NA}$$

- $\lambda$ 是光的波长——**波长越短，能画越细**。
- $NA$ 是镜头数值孔径——越大越好。
- $k_1$ 是工艺常数（多重曝光、相位掩膜等手段能压低它）。

这就引出 DUV 和 EUV 的根本差异——**就是 $\lambda$ 不同**：

```
   DUV（深紫外）                         EUV（极紫外）
   λ ≈ 193 nm （ArF 准分子激光）         λ ≈ 13.5 nm
   ↓ 波长大，画粗线                      ↓ 波长小近 14 倍，天然画细线
   想画 N7/N5 的细线 → 必须"多重曝光"     一次曝光就能搞定更细的图案
   工序多、对位难、成本高                 工序少，但 EUV 光刻机本身极贵极复杂
```

**EUV 为什么这么难/这么贵**（理解供应链卡脖子的关键）：
- 13.5nm 的 EUV 光被几乎所有材料吸收（包括空气、玻璃），所以**整个光路必须在真空中、用反射镜而非透镜**。
- EUV 光源是用大功率激光轰击锡（Sn）液滴产生等离子体得到的，能量转换效率极低、工程难度极大。
- 全球能造商用 EUV 光刻机的只有荷兰 **ASML** 一家。这也是为什么对 EUV 的出口限制能直接卡住一个国家的最先进制程。

> 对照你文件里写的两行：**N7 用 DUV（193nm）+ 多重曝光**；**N4 用 EUV（13.5nm）**。这正是 N7 与 N4/N5 代际的核心工艺分水岭之一。

## 3. 多重曝光：N7 没用 EUV 也能做到很细

既然 DUV 波长那么大（193nm），怎么画出 7nm 级别的细线？答案是**多重曝光（Multi-Patterning）**：用多次曝光+刻蚀，把一道"画不出来的细密图案"拆成几道"画得出来的稀疏图案"叠加完成。

```
想要的密集线条（一次 DUV 画不出来）：
   │ │ │ │ │ │ │ │

拆成两次（双重曝光 LELE / 或自对准 SADP）：
   第1次:  │   │   │   │     ← 间距大，DUV 能画
   第2次:    │   │   │   │   ← 补上中间的线
   叠加 →  │ │ │ │ │ │ │ │   ← 得到密集图案
```

代价：**每多一次曝光，就多一整套掩膜+曝光+刻蚀+对位工序**，成本和出错概率都上升，对位精度（套刻 overlay）要求极高。

所以工艺路线的权衡是：
- **N7（DUV 多重曝光）**：不依赖 EUV，但关键层要做 3~4 重甚至更多曝光，工序多、周期长。
- **N7+/N6/N5/N4（引入 EUV）**：用 EUV 把原来需要多重 DUV 的关键层**一次曝光搞定**，反而减少工序、提升良率。这就是 EUV 真正的价值——不只是更细，还**省工序**。

## 4. 制程节点命名的"营销陷阱"

**极重要的认知纠偏**：今天的 "N7 / N5 / N4 / N3" **数字不再等于任何真实物理尺寸**。N5 里没有任何一个结构是 5nm。这些只是台积电给"一代工艺"起的**商品代号**，用来表达"比上一代更密更省电"。

衡量制程"先进度"应看的真实物理量（讲类别，不背数）：

| 指标 | 含义 | 越好的方向 |
|------|------|-----------|
| 晶体管密度（MTr/mm²） | 每平方毫米能塞多少百万个晶体管 | 越高越好 |
| 性能（同功耗下频率） | 同样耗电跑多快 | 越高越好 |
| 功耗（同性能下耗电） | 同样速度多省电 | 越低越好 |
| SRAM 位单元面积 | 缓存能做多密（影响片上 cache） | 越小越好 |

业界把上面三件事合称 **PPA（Performance / Power / Area）**——每换一代节点，目标就是同时改善 PPA。台积电同一"代"里还有很多衍生工艺：

```
   N7 ──→ N7P（性能优化）──→ N6（与 N7 设计兼容，更密）
   N5 ──→ N4 ──→ N4P / N4X（高性能变体）
   N3 ──→ N3E / N3P / N3X ...
   （命名规则：字母后缀 P=Performance, E=Enhanced, X=极致性能；具体定义以台积电官方为准）
```

**对 AI 工程师的含义**：NVIDIA H100 用的是台积电 N4 的一个定制变体（常被称作 4N，注意 "4N" 是 NVIDIA 定制名，与通用 "N4" 写法相反），并非"任意 4nm"。看 GPU 规格时，"几纳米"只是粗略代际信号，真正决定算力/能效的是**架构 + 这一代具体工艺 + 封装**三者合力。

## 5. 良率与缺陷密度：为什么大 die 这么贵

晶圆是圆的（如直径 300mm），芯片是方的，要在圆晶圆上切出一个个方 die。制造中难免有微小缺陷（灰尘、工艺波动），**一颗 die 上只要落上一个致命缺陷，这颗就报废**。

```
   一张 300mm 晶圆切 die：

   小 die（如手机 SoC）          大 die（如 H100 GPU，~800mm²）
   ┌─┬─┬─┬─┬─┬─┬─┐              ┌───────┬───────┐
   ├─┼─╳─┼─┼─┼─┤              │       │   ╳   │  ← 一个缺陷
   ├─┼─┼─┼─╳─┼─┤              ├───────┼───────┤    报废一整颗大 die
   └─┴─┴─┴─┴─┴─┘              └───────┴───────┘
   缺陷只废掉一小颗             同样一个缺陷废掉一大颗 → 损失大
   → 良率高、单颗便宜           → 良率低、单颗极贵
```

经典模型（Murphy 良率近似，理解趋势即可）：

$$Y \approx \left(\frac{1 - e^{-A \cdot D_0}}{A \cdot D_0}\right)^2 \quad\text{或简化}\quad Y \approx e^{-A \cdot D_0}$$

- $A$ = die 面积，$D_0$ = 单位面积缺陷密度。
- **关键直觉**：die 面积 $A$ 越大，良率 $Y$ 指数级下降。AI GPU 的 die 都很大（逼近光刻机单次曝光的物理极限 **reticle limit，约 858mm²**），所以**又贵又难造**。这也是 B200/MI300 走"多个小 die 拼起来（Chiplet）"路线的根本原因——用小 die 提良率，再靠先进封装拼成一颗大芯片。

## 6. 先进封装 CoWoS：把 GPU 和 HBM 缝起来

这是 AI 时代台积电最被"卡产能"的环节，必须讲清。

现代 AI GPU 不是一块孤立的 die，而是**一颗逻辑 die（GPU 计算核心）+ 多颗 HBM 显存堆叠**，要让它们之间有**极宽、极短、极省电的连接**（HBM 带宽以 TB/s 计，靠普通 PCB 走线根本喂不动）。台积电的 **CoWoS（Chip on Wafer on Substrate）** 就是干这个的 **2.5D 先进封装**技术。

```
   CoWoS 2.5D 封装剖面（侧视）：

     [GPU die]        [HBM 堆叠]   [HBM 堆叠]
        │  │微凸点(μbump) │  │        │  │
   ═════╪══╪═════════════╪══╪════════╪══╪═══   ← Silicon Interposer（硅中介层）
        │  └── 上面布超密金属走线，连接 GPU↔HBM ──┘   这是 CoWoS 的核心
   ─────┴───────────────────────────────────── ← Substrate（封装基板）
                    │ │ │ │  焊球(C4 bump)
                  ━━━━━━━━━━  → 焊到 PCB 主板
```

- **CoW（Chip on Wafer）**：先把 GPU die 和 HBM 贴到**硅中介层（Interposer）**上。中介层是一小片硅，上面有超高密度走线，相当于"die 之间的高速公路"。
- **oS（on Substrate）**：再把这个组合贴到封装基板上，最后焊到 PCB。
- **为什么用硅做中介层**：硅上能做出比 PCB 细几个数量级的走线，才能容纳 HBM 那几千根数据线，实现 TB/s 级带宽且低功耗。

> 这就解释了 2023–2024 年的产业故事：**H100 缺货的真正瓶颈往往是 CoWoS 封装产能和 HBM 供应，而不是 GPU 逻辑 die 本身**。台积电扩 CoWoS 产能的速度，直接决定全球能交付多少张高端 AI 卡。相关变体还有 InFO、SoIC（3D 堆叠，把 die 直接叠在 die 上）等——具体能力与命名以台积电官方为准。

## 7. 一颗 H100 的"出生"全流程（调用链）

把前面所有概念串成一条从图纸到成品的链路：

```
 ① NVIDIA 设计       用 EDA 工具画出 Hopper 架构电路 → 生成版图(GDSII)
        │                                            （Fabless：只设计）
        ▼
 ② 制掩膜 Mask       按版图制作每一层的光罩（掩膜）
        │
        ▼
 ③ 晶圆制造 FAB      硅晶圆进厂，逐层重复：
        │              光刻(DUV/EUV) → 刻蚀 → 离子注入 → 沉积 → CMP抛光
        │              做出数百层结构 → FinFET 晶体管 + 多层金属互连
        │              （N4 制程，台积电核心环节）
        ▼
 ④ 晶圆测试 CP       探针逐 die 测试，标出好/坏 die（算良率）
        │
        ▼
 ⑤ 先进封装 CoWoS    好的 GPU die + HBM 堆叠 → 贴硅中介层 → 贴基板
        │              （台积电近年最紧的产能瓶颈）
        ▼
 ⑥ 成品测试 / 出货   最终测试、分级(binning) → 交给 NVIDIA → 上板成 H100 模组
        │
        ▼
   你在数据中心里 nvidia-smi 看到的那张卡
```

每一步都可能因良率、产能、材料（HBM、EUV 胶、光罩）而成为瓶颈。AI-Infra 缺卡，往往要往这条链的某一环去找原因。

## ★ 数值例子：手算晶圆产出与成本直觉

**例 1：一张晶圆能切几颗 die（Gross Die）**
300mm 晶圆有效面积约 $A_{wafer}\approx \pi r^2 = 3.14 \times 150^2 \approx 70{,}600\,\text{mm}^2$。
- 若是手机 SoC，die 约 $100\,\text{mm}^2$ → 理论上限约 $70600/100 \approx 700$ 颗（边缘浪费后实际更少）。
- 若是 AI GPU，die 约 $800\,\text{mm}^2$ → 仅约 $70600/800 \approx 88$ 颗。
**直觉**：大 die 本来就切得少。

**例 2：良率叠加成本**
设缺陷密度 $D_0=0.1/\text{cm}^2=0.001/\text{mm}^2$，用简化 $Y\approx e^{-A D_0}$：
- 小 die（100mm²）：$Y\approx e^{-0.1}\approx 0.90$ → 700×0.90 ≈ 630 颗好 die。
- 大 die（800mm²）：$Y\approx e^{-0.8}\approx 0.45$ → 88×0.45 ≈ 40 颗好 die。
**结论**：同一张晶圆，大 GPU die 好品只有几十颗，**单颗成本被良率再放大几倍**。这就是为什么 AI GPU 走 Chiplet（多小 die）+ CoWoS 封装来对冲大 die 的良率劣势。（$D_0$ 为示意值，真实数字保密。）

## 常见问题/坑（FAQ）

| 误区 / 问题 | 正解 |
|------------|------|
| "N5 里有 5nm 的结构" | ❌ 制程数字是营销代号，不对应任何真实尺寸。看 PPA/密度才准。 |
| "更小制程一定全面更好" | 不一定。更先进节点更贵、设计成本更高、不是所有芯片都需要——成熟制程在很多场景更划算。 |
| "GPU 缺货是 die 不够" | 常常是 **CoWoS 封装产能 + HBM 供应**不够，而非 GPU 逻辑 die 本身。 |
| "EUV 只是为了画更细" | 还为了**省工序**：把多重 DUV 曝光合成一次 EUV 曝光，提良率降成本。 |
| "DUV 做不了先进制程" | N7 就用 DUV+多重曝光做到了；EUV 是让 N5/N4 更高效，不是唯一出路。 |
| "台积电也设计芯片" | ❌ 纯 Foundry，只代工不与客户竞争——这正是它赢得信任的根本。 |
| "4N 和 N4 是一回事" | NVIDIA 的 "4N" 是其定制工艺名；通用写法是 "N4"。注意区分。 |
| "die 越大算力一定越强" | 受 reticle limit（约 858mm²）和良率限制；现代趋势是多 Chiplet 拼接而非单一巨 die。 |
