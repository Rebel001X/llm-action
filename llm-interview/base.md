## 0. 一句话锚点

> **Transformer 一层 = 多头自注意力（混 token，跨位置交互）+ 前馈网络（混维度，逐位置变换）+ 两条残差 + 两个归一化；位置编码补上"顺序"信息。** 注意力负责"看哪里"，FFN 负责"想什么"，残差和 Norm 负责"能训练得动"。

```
                 一个 Transformer Block (Pre-Norm)
   x ──┬─────────────────────────────────┐
       │                                 │ 残差①
   [LayerNorm] ──> [Multi-Head Attn] ──> (+) ──┬──────────────┐
                                               │              │ 残差②
                                          [LayerNorm] ─> [FFN] ─> (+) ──> 输出
   注意力: 跨位置混合(token之间)      FFN: 逐位置混合(维度之间)
```

## 1. 地基 / 前置：序列建模为什么难，张量长什么样

**输入张量**：一个 batch 的文本 token，经过 Embedding 后是
$$X \in \mathbb{R}^{B \times L \times d}$$
- $B$ = batch size（一次几条样本），$L$ = 序列长度（几个 token），$d$ = 隐藏维度（每个 token 用多少维向量表示）。
- 一个 token = 一个 $d$ 维向量（一行）。整句话 = $L$ 行堆起来的矩阵 $[L,d]$。

**为什么序列难建模**：语言里"它"指代谁、动词搭配哪个宾语，依赖**任意距离**的其他词。
- RNN：靠隐状态一步步传递，远距离信息要走很多步 → 梯度消失、无法并行。
- CNN：感受野受 kernel 限制，远距离要堆很多层。
- **Attention**：任意两个位置**一步直达**，且全部位置可并行计算 → 这是 Transformer 的核心动机。

```
RNN:   t1 → t2 → t3 → ... → tL      (远距离要走 L 步, 串行)
Attn:  t1 ── t2 ── t3 ── ... ── tL   (任意两点 1 步直达, 并行)
        \____\____\____/___/         (每个点都能看全部点)
```

## 2. Self-Attention：QKV、公式、为什么 scaling

### 2.1 三个角色 Q / K / V（这是高频考点）

把每个 token 的向量 $x$ 通过三个不同的线性投影变成三个角色：
$$Q = X W_Q,\quad K = X W_K,\quad V = X W_V$$
直觉类比"查字典 / 检索"：
- **Query（查询）**：我（当前 token）想找什么。
- **Key（键）**：每个 token 的"标签 / 索引"，用来被匹配。
- **Value（值）**：匹配上之后真正取走的"内容"。

> **追问：为什么要用三个不一样的 QKV，不能共用？**
> 为了增强网络容量和表达能力。如果完全不投影、直接用 $x$ 自己做（$Q=K=V=x$），表征能力太弱——每个 token 的"查询身份""被查身份""携带内容"被绑死成同一个向量，更新会非常拧巴。三套独立参数让"我想找什么"和"我能提供什么"解耦。

### 2.2 完整表达式

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

逐步拆（**a. Self-Attention 的表达式**就是这一串）：
1. **算相关性** $S = QK^\top$，形状 $[L,L]$：$S_{ij}=q_i\cdot k_j$，第 $i$ 个 token 对第 $j$ 个的"打分"。点积越大越相关。
2. **缩放** $S / \sqrt{d_k}$。见 2.3。
3. **softmax** 沿每一行归一化 → 注意力权重 $A$，每行和为 1（"我把注意力百分比分给谁"）。
4. **加权求和** $A V$，形状 $[L,d_v]$：每个 token 的输出 = 所有 value 按注意力权重的加权平均。

```
   Q[L,dk] · K^T[dk,L]  =  S[L,L]   ÷√dk   softmax(行)   A[L,L] · V[L,dv] = Out[L,dv]
   ┌──┐     ┌────┐         ┌────┐               ┌────┐      ┌──┐
   │q1│     │k1 k2 ..│  →   │s11 s12 ..│   →    │.6 .3│  →  │  │
   │q2│     │        │      │s21 s22 ..│        │.1 .8│     │  │
   └──┘     └────┘         └────┘               └────┘      └──┘
```

### 2.3 为什么要除以 $\sqrt{d_k}$（scaling，**b. 高频必考**）

假设 $q,k$ 各维独立、均值 0 方差 1，则点积
$$q\cdot k=\sum_{i=1}^{d_k} q_i k_i,\quad \text{Var}(q\cdot k)=d_k$$
即点积的方差随维度 $d_k$ 线性增大，标准差 $\sqrt{d_k}$。$d_k$ 大（如 64、128）时点积数值很大。
- **进入 softmax 后果**：softmax 对大数值会"赢者通吃"——某个分数极大时输出几乎是 one-hot。
- **梯度问题**：softmax 在饱和（接近 0/1）区域的梯度趋近 0 → 梯度消失，模型几乎学不动。
- **除以 $\sqrt{d_k}$**：把方差拉回 ≈1，让 logits 落在 softmax 的**敏感区间**，分布更平滑，梯度健康，更容易训练。

> 数值直觉：$d_k=64$ 时未缩放点积标准差约 8，softmax(8 vs 0) ≈ 0.9997 已饱和；除以 $\sqrt{64}=8$ 后标准差≈1，softmax 不再极端。

> **追问：self-attention 一定要这样表达吗（c.）？**
> 不一定。只要能建模 token 间相关性即可。但点积形式有几个好处：① 可写成矩阵乘法 → 高速并行；② 表达力强（query 主动关注相关 key、在 value 上强化、忽略无关部分）；③ 配合 $W_Q/W_K/W_V/W_O$ 和多头，模型容量足够大。

> **追问：Q 和 K 能否共享同一套权重？** 可以做（如某些变体），但会削弱表达力：会强制"我找你"和"你找我"的打分对称（$S$ 变对称矩阵），而语言中"A 关注 B"≠"B 关注 A"。

## 3. 多头注意力 Multi-Head（**j. 为什么要多头**）

把 $d$ 维拆成 $h$ 个头，每头独立做注意力，再拼接过输出投影：
$$\text{head}_i=\text{Attn}(XW_Q^i,XW_K^i,XW_V^i),\quad \text{MHA}=\text{Concat}(\text{head}_1..\text{head}_h)W_O$$
其中每头维度 $d_k=d/h$。

**为什么多头**：类比 CV 里不同卷积核关注不同特征——不同的头会学到关注**不同子空间的信息**（一个头看语法主谓、一个头看指代、一个头看局部短语）。单头只能学一种"注意力模式"，多头是"集成"，进一步增强容量和表达力。

```
        d=512, h=8, dk=64
   X ─┬─ head1(dk=64) ─┐
      ├─ head2(dk=64) ─┤  Concat → [L,512] → W_O → [L,512]
      │      ...        │
      └─ head8(dk=64) ─┘
   注意: 拆头后总计算量与单头≈相同(dk变小), 但表达更丰富
```

> **追问：头数越多越好吗？** 不是。$h$ 太大 → 每头 $d_k$ 太小，单头表达力下降；研究（如 "Are Sixteen Heads Really Better than One"）发现很多头可剪枝。是容量与冗余的权衡。
> **追问：MHA / MQA / GQA 区别？** MHA：每头独立 KV。MQA：所有头共享 1 套 KV（省 KV-Cache，略掉点）。GQA：分组共享 KV（折中，LLaMA-2 70B 用），是推理显存与质量的工程平衡。详见 [[llm-interview/llm-algo]]。

## 4. 位置编码：为什么需要、Sinusoidal vs RoPE

**为什么必须有**：注意力是**置换不变**的——打乱输入 token 顺序，输出只是同样打乱，注意力本身**看不到"谁在前谁在后"**。但语言有顺序（"狗咬人"≠"人咬狗"），所以必须额外注入位置信息。

### 4.1 Sinusoidal（原始 Transformer，加法式绝对位置）
$$PE_{(pos,2i)}=\sin\!\Big(\frac{pos}{10000^{2i/d}}\Big),\quad PE_{(pos,2i+1)}=\cos\!\Big(\frac{pos}{10000^{2i/d}}\Big)$$
- 不同维度用不同频率（低维高频、高维低频），像多位二进制 / 多刻度时钟。
- 直接加到 Embedding 上。优点：无参数、可外推到更长序列；缺点：是绝对位置，相对位置关系不直接。

### 4.2 RoPE（旋转位置编码，主流大模型用）
不加到向量上，而是**旋转** Q、K：把每两维看成一个复数 / 平面向量，对位置 $m$ 旋转角度 $m\theta$。关键性质：
$$\langle R_m q,\ R_n k\rangle = g(q,k,\ m-n)$$
内积只依赖**相对位置 $m-n$** → 天然编码相对位置，长度外推更友好。LLaMA、Qwen、DeepSeek 等均用 RoPE。

```
RoPE: 对位置 m 的 q 向量整体旋转 mθ
   m=0:  →        m=1:  ↗        m=2:  ↑      (角度随位置递增)
   两个 token 的"夹角差" = (m-n)θ 只跟相对距离有关
```

> **追问：RoPE 怎么做长度外推？** 直接外推会衰减；常用 NTK-aware 插值 / Position Interpolation（缩放 base 或位置）扩展上下文，详见 [[llm-interview/llm-algo]]。
> **追问：ALiBi 又是什么？** 不加位置向量，直接在注意力分数上按距离加线性偏置（越远扣分越多），外推性好。

## 5. 归一化：LN vs BN、Pre/Post-Norm、RMSNorm（**e/f. 高频**）

### 5.1 任何 Norm 的意义
把某一组数据重新标准化为均值 0、方差 1（再加可学习的缩放 $\gamma$ 和平移 $\beta$），让数值进入激活/softmax 的敏感区间，**减缓梯度消失/爆炸，稳定并加速训练**。

### 5.2 LayerNorm vs BatchNorm —— 沿哪个轴归一化（核心区别）

```
张量 [B, L, d]:
  BatchNorm: 对每个特征维, 跨 batch 统计 (沿 B 方向, ↓)
  LayerNorm: 对每个 token, 跨特征维统计 (沿 d 方向, →)

        d 维 →
      ┌───────────┐
  B   │ token向量  │  LN: 每行(一个token)自己归一化 →
  ↓   │           │  BN: 每列跨样本归一化 ↓
      └───────────┘
```

> **f. 为什么 Transformer/NLP 不用 BN，用 LN？**
> 1. **序列长度可变、padding 多**：BN 依赖 batch 统计量，NLP 里每条句子长度不同、有大量 padding，batch 内统计不稳定/有偏。
> 2. **小 batch 不稳**：BN 在小 batch 下统计噪声大；LN 只在单样本内部统计，与 batch 大小无关。
> 3. **训练/推理一致**：BN 推理要用滑动平均统计量（train/eval 行为不同，易出 bug）；LN 训练推理完全一致。
> 4. **语义动机（核心）**：在一个维度内归一化后，该维度内相对大小有意义、可比较；但**归一化后不同维度之间相对大小无意义**。BN 跨样本归一化某个特征，相当于假设"不同句子同一维度可比"，这在语言里不成立；LN 在单 token 内归一化，舍弃了"跨 token 的绝对尺度"信息，但**这个信息本可舍弃**，保留了 token 内部各维的相对结构。

> **追问：LN 舍弃了什么、为什么能舍弃？** LN 把每个 token 向量的整体均值和尺度归掉了，只保留方向/相对结构。能舍弃，是因为后续注意力关心的是 token 之间的相对相似度（点积），整体平移和缩放对建模相关性不是关键信息，反而归一化能稳定训练。

### 5.3 Pre-Norm vs Post-Norm（现代大模型几乎都 Pre-Norm）

```
Post-Norm(原始): x → Sublayer → Add → LN → 下一层   (LN 在残差之后)
Pre-Norm(现代):  x → LN → Sublayer → Add → 下一层   (LN 在残差之前)
```
- **Post-Norm**：表达力略强但深层难训，需要 warmup + 小心调参，梯度容易不稳。
- **Pre-Norm**：残差是"干净"的恒等通路，梯度可直达底层 → **深层网络更稳、好训**，代价是同等深度表达略弱。GPT、LLaMA 等都用 Pre-Norm。

### 5.4 RMSNorm（LLaMA 等用）
去掉减均值和 $\beta$，只用均方根缩放：
$$\text{RMSNorm}(x)=\frac{x}{\sqrt{\frac1d\sum x_i^2+\epsilon}}\cdot\gamma$$
- 比 LayerNorm 少算一次均值、少一组参数 → **更快**，效果基本持平。假设"重要的是缩放而非中心化"。

## 6. 激活函数：ReLU → GELU → SwiGLU（FFN 里的非线性）

FFN（前馈网络）逐位置做："升维 → 非线性 → 降维"，给模型"思考/变换"的能力：
$$\text{FFN}(x)=\sigma(xW_1+b_1)W_2+b_2,\quad d \to d_{ff}(\approx 4d) \to d$$

| 激活 | 公式要点 | 特点 |
|---|---|---|
| ReLU | $\max(0,x)$ | 简单快；负半区梯度 0（神经元死亡），不平滑 |
| GELU | $x\cdot\Phi(x)$（$\Phi$ 为标准正态 CDF） | 平滑、按输入大小"软门控"，BERT/GPT 用 |
| SwiGLU | $(\text{Swish}(xW)\odot xV)W_2$ | 门控线性单元，LLaMA 用，效果更好 |

> **为什么从 ReLU 走向 GELU/SwiGLU**：① 平滑（处处可导，优化更稳）；② **门控**思想——SwiGLU 用一路信号去"开关"另一路，表达力更强。代价是 SwiGLU 多一个投影矩阵，故常把 $d_{ff}$ 调小（如 $\frac{8}{3}d$）以保持参数量持平。

```
ReLU:  ___/    (拐角, 负区死)
GELU:  __╱     (平滑, 负区有微小梯度)
SwiGLU: 两路相乘做门控, 一路当"阀门"控制另一路通过多少
```

## 7. 残差连接：Transformer 为什么离不开它

$$y=x+\text{Sublayer}(\text{Norm}(x))$$
- **梯度高速路**：反向传播时 $\frac{\partial y}{\partial x}=1+\frac{\partial \text{Sublayer}}{\partial x}$，那个"$+1$"保证梯度至少能原样传回，**根治深层网络梯度消失**。
- **恒等先验**：初始时子层接近 0，网络≈恒等映射，从"什么都不做"出发学习增量，深层也能稳定训练。没有残差，几十层的 Transformer 基本训不动。

## 8. 整体结构：Encoder / Decoder / 掩码

```
Encoder (BERT类, 双向):  每个 token 能看全部 token (无掩码)  → 理解/分类
Decoder (GPT类, 单向):   因果掩码, 只能看自己及左边         → 生成
Enc-Dec (T5/翻译类):     Encoder 编码源 + Decoder 交叉注意力读源 → seq2seq
```

> **NLU vs NLG 任务差异（开篇第一问）**：
> - **NLU（理解：分类/抽取/相似度）**：需要**双向**上下文 → Encoder（BERT），看全句再判断。
> - **NLG（生成：续写/翻译/对话）**：自回归逐 token 生成，必须**单向**（不能偷看未来）→ Decoder（GPT），用因果掩码。
> - 现代大模型主流是 **Decoder-only**，因为生成范式 + 规模化下统一、简洁、易扩展。

**因果掩码（Causal Mask）**：在 $QK^\top$ 上把"未来位置"置为 $-\infty$，softmax 后权重为 0，保证位置 $i$ 只能注意到 $\le i$。
```
   能看↓  t1 t2 t3 t4
   t1     ✓  ✗  ✗  ✗     上三角(未来)被 mask 成 -inf
   t2     ✓  ✓  ✗  ✗
   t3     ✓  ✓  ✓  ✗
   t4     ✓  ✓  ✓  ✓
```

## 数值示例 / 逐数手算（面试常要求"算给我看"）

### 例1：单头注意力一行手算
设 $d_k=2$，某个 query $q=[1,0]$，三个 key $k_1=[1,0],k_2=[0,1],k_3=[1,1]$，对应 value $v_1=[2,0],v_2=[0,2],v_3=[1,1]$。
1. 点积：$q\!\cdot\!k_1=1,\ q\!\cdot\!k_2=0,\ q\!\cdot\!k_3=1$。
2. 缩放 $/\sqrt2$：$[0.707,\ 0,\ 0.707]$。
3. softmax：$e^{0.707}=2.028,\ e^{0}=1,\ e^{0.707}=2.028$，和 $=5.056$ → 权重 $[0.401,0.198,0.401]$。
4. 输出 $=0.401v_1+0.198v_2+0.401v_3=[0.401\cdot2+0.401\cdot1,\ 0.198\cdot2+0.401\cdot1]=[1.203,\ 0.797]$。
> 解读：query"像" $k_1,k_3$，注意力更多分给它们，输出向 $v_1,v_3$ 倾斜。

### 例2：注意力的参数量与显存（背公式）
单层 MHA 参数 $\approx 4d^2$（$W_Q,W_K,W_V,W_O$ 各 $d^2$）；FFN 参数 $\approx 2\cdot d\cdot d_{ff}=8d^2$（$d_{ff}=4d$）。
- 取 $d=4096$（LLaMA-7B 级别）：单层 ≈ $4d^2+8d^2=12d^2=12\times4096^2\approx2.01\times10^8$ ≈ **2.0 亿/层**。
- **注意力矩阵显存**：$S\in[B,h,L,L]$，随序列长度**平方增长** $O(L^2)$ —— 这就是长上下文显存爆炸的根源，也是 FlashAttention / KV-Cache 要解决的问题（见 [[llm-interview/llm-algo]]）。

### 例3：scaling 数值对比（解释为什么 $\sqrt{d_k}$）
$d_k=64$，假设两个 logit 未缩放为 $[8,0]$（标准差≈8 量级）：
- 未缩放 softmax$([8,0])=[0.99966,0.00034]$ → 几乎 one-hot，梯度≈0。
- 缩放 $/8$ 后 $[1,0]$：softmax$([1,0])=[0.731,0.269]$ → 平滑，梯度健康。

| 并行 | ✅ | ✅ | ❌ | ✅ |
| 复杂度 | $O(L^2 d)$ | $O(L d^2)$ | $O(L d^2)$ | $O(L k d^2)$ |
| 最长路径 | $O(1)$ | — | $O(L)$ | $O(\log_k L)$ |

| 选择 | 用什么 | 一句话理由 |
|---|---|---|
| 归一化 | LayerNorm / RMSNorm | batch 无关、train/eval 一致 |
| Norm 位置 | Pre-Norm | 深层好训、梯度直达 |
| 激活 | SwiGLU / GELU | 平滑 + 门控，表达更强 |
| 位置编码 | RoPE | 相对位置、外推友好 |
| 架构 | Decoder-only | 生成范式统一、易规模化 |

## 常见问题 / 高频追问

| 追问 | 踩点答案 |
|---|---|
| 为什么除 $\sqrt{d_k}$ 不是 $d_k$？ | 因为方差是 $d_k$，标准差是 $\sqrt{d_k}$；目的是把方差归一到≈1，不是把均值归一 |
| 不 scale 会怎样？ | 点积方差随 $d_k$ 增大→softmax 饱和→梯度消失→训不动 |
| QKV 能共享吗？ | 可共享但表达力降；尤其 Q=K 会强制注意力对称，不合理 |
| 多头计算量比单头大吗？ | 基本相同：拆头后单头 $d_k=d/h$ 变小，总量≈不变，但更丰富 |
| 注意力是 $O(L^2)$ 的瓶颈在哪？ | $QK^\top$ 和注意力矩阵存储都 $\propto L^2$，长序列显存/算力爆炸 |
| 为什么不用 BN？ | 序列变长/padding/小 batch 统计不稳，train/eval 不一致，跨样本归一无语义 |
| Pre-Norm 为什么好训？ | 残差是干净恒等路径，梯度可直达底层，深层稳定 |
| RMSNorm 比 LN 省在哪？ | 不减均值、无 $\beta$，少一次统计和一组参数，更快 |
| 位置编码不加会怎样？ | 注意力置换不变，模型分不清词序，"狗咬人=人咬狗" |
| RoPE 比 Sinusoidal 好在哪？ | 内积只依赖相对位置 $m-n$，长度外推更友好 |
| FFN 为什么升维 4 倍？ | 给非线性变换足够容量（经验值），SwiGLU 因多一矩阵常降到 $\frac83d$ |
| 残差去掉会怎样？ | 深层梯度消失，几十层 Transformer 基本训不动 |
| NLU 用 Encoder、NLG 用 Decoder 的本质？ | 理解需双向看全文，生成需单向不能偷看未来 |
| 因果掩码怎么实现？ | $QK^\top$ 上三角置 $-\infty$，softmax 后未来权重为 0 |
