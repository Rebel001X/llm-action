## 0. 一句话锚点

**RLHF = 用人类偏好训练一个"打分器"(奖励模型)，再用强化学习把语言模型的输出往高分方向推，同时用 KL 拴住别跑偏。**

一句话区分三大方法：
- **PPO**：在线采样 + 奖励模型 + 价值网络，最稳但最重（4 个模型）。
- **DPO**：用数学把"RL+RM"合并成一个分类损失，离线、轻、稳，但表达力弱于在线 RL。
- **GRPO**：保留在线 RL 与奖励，但用"组内多个采样的平均分"当基线，**砍掉价值网络**，省一半显存，R1 同款。

## 1. 地基：SFT 为什么不够

### 1.1 SFT 在做什么

监督微调（SFT）= 给定 prompt $x$ 和一个"标准答案" $y$，最大化 $\log \pi_\theta(y\mid x)$，逐 token 做交叉熵。它教模型**模仿**示范数据。

它的三个天花板：

1. **只能模仿，不能比较**。SFT 告诉模型"这样写"，但说不清"这样写比那样写好多少"。两个都通顺的回答，SFT 无法表达偏好强度。
2. **暴露偏差（exposure bias）**。训练时每步喂的都是真值前缀（teacher forcing），推理时喂的是自己生成的前缀，一步错步步错。
3. **目标错配**。我们真正想要的是"有用、诚实、无害"，但这些**没有逐 token 标签**——你没法给"无害"写交叉熵。

### 1.2 RLHF 的核心思想

既然"好"难以写成标签，那就**让人来比较**：给人看两个回答 $y_w$（win）和 $y_l$（lose），人选哪个更好。把这种**相对偏好**蒸馏进一个奖励模型 $r_\phi(x,y)$，再用 RL 最大化期望奖励。

```
        难以直接写标签的目标               可优化的代理目标
   ┌────────────────────────┐       ┌──────────────────────────┐
   │ "有用/诚实/无害"        │  ==>  │ 最大化 E[r_φ(x,y)]        │
   │ （没有 token 级 label） │       │ s.t.  KL(π_θ ‖ π_ref) 小  │
   └────────────────────────┘       └──────────────────────────┘
            人类偏好 (y_w ≻ y_l)  ──训练──>  奖励模型 r_φ
```

## 2. 三阶段全流程 + 涉及几个模型

> **高频开场题：RLHF 完整训练过程是什么？涉及几个模型？**

经典 InstructGPT 流程分三阶段：

```
 阶段1: SFT                阶段2: 训练奖励模型 RM        阶段3: PPO 强化学习
 ─────────                ────────────────────         ──────────────────
 人工示范 (x,y)            同一 x 采样多个 y            策略 π_θ 在线生成 y
      │                    人标排序 y_a ≻ y_b ≻ ...          │
      ▼                          │                           ▼
  最大化 logπ(y|x)         Bradley-Terry 损失           r = RM(x,y) - β·KL
      │                    训练 r_φ(x,y)                     │
      ▼                          │                           ▼
   π_SFT  ───初始化──────────────┴──────初始化────────►  PPO 更新 θ
```

### PPO 阶段涉及 **4 个模型**（最常被追问）

| 模型 | 角色 | 是否更新参数 | 显存 |
|------|------|-------------|------|
| **Actor（策略 π_θ）** | 生成回答，被优化的主角 | ✅ 训练 | 参数+梯度+优化器态 |
| **Critic（价值 V_ψ）** | 估计状态价值，算优势 GAE | ✅ 训练 | 参数+梯度+优化器态 |
| **Reward Model r_φ** | 给完整回答打分 | ❌ 冻结 | 仅前向 |
| **Reference π_ref** | 算 KL 的锚点（=SFT 模型） | ❌ 冻结 | 仅前向 |

> 记忆口诀：**两个要训（Actor/Critic），两个冻结（Reward/Reference）**。这也是 PPO 显存重、工程复杂的根因——**同时驻留 4 份 ~等大的模型**。
> DPO 只需 2 个（policy + reference），GRPO 需 3 个（policy + reward + reference，**无 critic**）。

## 3. 奖励模型 RM：为什么是 pairwise

### 3.1 为什么不直接打绝对分

让人给一个回答打 0–10 的绝对分，**方差极大、标注者间不一致**（你的 7 分=我的 5 分）。但让人在两个回答里**二选一**，一致性高得多。所以 RM 学的是**相对偏好**。

### 3.2 Bradley-Terry 模型

假设回答 $y$ 有一个潜在标量"质量" $r(x,y)$。人更偏好 $y_w$ 而非 $y_l$ 的概率：

$$
P(y_w \succ y_l \mid x) = \sigma\big(r(x,y_w) - r(x,y_l)\big) = \frac{1}{1+e^{-(r_w - r_l)}}
$$

RM 训练就是最大化这个概率的对数似然，即最小化：

$$
\mathcal{L}_{RM} = -\,\mathbb{E}_{(x,y_w,y_l)}\Big[\log \sigma\big(r_\phi(x,y_w) - r_\phi(x,y_l)\big)\Big]
$$

**结构**：RM 通常 = 去掉 LM head 的基座 + 一个标量回归头，取最后一个 token 的隐状态映射到 1 个标量。

**关键直觉**：损失只关心**两个回答的差值** $r_w-r_l$，不关心绝对值。所以 RM 的输出**没有绝对量纲**，只能比较，不能跨 prompt 直接比大小。

### 3.3 RM 的失效模式（陷阱）

- **奖励黑客（reward hacking）**：策略学会钻 RM 漏洞（如更长、更多套话、更多 markdown）拿高分，实际质量没提升。
- **分布漂移**：RM 只在 SFT 附近的回答上训过，策略一旦跑远，RM 给的分**不可信**（外推失效）——这正是要 KL 的原因。
- **过优化（over-optimization）**：RM 分越来越高，真实人评先升后降（详见第 5 节）。

## 4. PPO：目标函数逐项拆

### 4.1 强化学习的语言建模视角

把生成看成序列决策：状态 = 已生成前缀，动作 = 下一个 token，**奖励只在序列末尾给一次**（RM 打的句子级分），中间 token 奖励为 0。

### 4.2 完整目标

PPO 优化的是带 KL 惩罚的奖励：

$$
\max_\theta\; \mathbb{E}_{x\sim D,\, y\sim \pi_\theta}\Big[\, r_\phi(x,y) \;-\; \beta\,\mathrm{KL}\big(\pi_\theta(\cdot\mid x)\,\|\,\pi_{ref}(\cdot\mid x)\big)\Big]
$$

实现上 KL 被折进**每个 token 的奖励**：

$$
r_t = \underbrace{r_\phi(x,y)\cdot \mathbb{1}[t=T]}_{\text{末尾句子级奖励}} \;-\; \beta\big(\log\pi_\theta(y_t\mid \cdot) - \log\pi_{ref}(y_t\mid \cdot)\big)
$$

### 4.3 优势与 PPO-Clip

用 GAE 算优势 $\hat A_t$（需要 Critic $V_\psi$ 当基线降方差），令重要性比 $\rho_t = \dfrac{\pi_\theta(y_t)}{\pi_{\theta_{old}}(y_t)}$，PPO 的裁剪目标：

$$
\mathcal{L}^{CLIP} = \mathbb{E}_t\Big[\min\big(\rho_t \hat A_t,\; \mathrm{clip}(\rho_t,\,1-\epsilon,\,1+\epsilon)\,\hat A_t\big)\Big]
$$

**clip 在干什么**：限制单步更新幅度。若某 token 优势为正（好动作），策略想猛增其概率，但 $\rho_t$ 超过 $1+\epsilon$ 后被截断，**梯度归零**，防止一步走太远把策略搞崩。这就是 PPO 比早期策略梯度稳的核心。

```
   优势 A>0 (想增概率)              优势 A<0 (想减概率)
   ρ ─────►  到 1+ε 截平          ρ ─────►  到 1-ε 截平
   ╱│                              │╲
  ╱ │  超过就不再奖励               │ ╲  低于就不再惩罚
 ╱  └─ 1+ε ─────                ── 1-ε ─┘  ╲
```

### 4.4 PPO 的代价

- 4 模型驻留，显存≈ SFT 的 ~2–4 倍。
- 在线采样（generation）慢，是吞吐瓶颈。
- 超参敏感（$\beta$、$\epsilon$、学习率、GAE λ），训练不稳，调参成本高。

→ 正是这些痛点催生了 DPO（去掉 RL）和 GRPO（去掉 Critic）。

## 5. KL 惩罚：为什么必须有

> **高频题（即你文件里的种子题）：RLHF 中 RM 得分越来越高，效果就一定好吗？**

**不一定，往往相反。** 这叫**奖励过优化 / Goodhart 定律**："当一个度量成为目标，它就不再是好度量。"

机制：RM 只在参考策略附近训过。策略为了刷 RM 分会跑到 RM 没见过的分布，在那里 RM 的高分是**外推幻觉**，真实人评反而下降。

```
真实人评 ▲
        │        ╭─╮  ← 真实质量先升后降（驼峰）
        │      ╱     ╲
        │    ╱         ╲____
        └──┴────────────────►  RM 得分（持续上升）
           最优点         过优化区
```

**KL 惩罚 $\beta\,\mathrm{KL}(\pi_\theta\|\pi_{ref})$ 的作用**：像一根橡皮筋，把策略拴在 SFT（=RM 可信区）附近。$\beta$ 小→更自由更易刷分也更易崩；$\beta$ 大→更保守、几乎不动。

**面试加分点**：除了 KL，还可以靠 (a) 早停 / 看真实评测；(b) RM 集成或更大 RM；(c) 迭代式重训 RM（用新策略数据再标）来缓解过优化。

## 6. DPO：把 RL 干掉

### 6.1 核心洞察

第 4 节带 KL 的最大化问题有**闭式最优解**：

$$
\pi^*(y\mid x) = \frac{1}{Z(x)}\,\pi_{ref}(y\mid x)\,\exp\!\Big(\tfrac{1}{\beta} r(x,y)\Big)
$$

反解出奖励（关键一步）：

$$
r(x,y) = \beta\,\log\frac{\pi^*(y\mid x)}{\pi_{ref}(y\mid x)} + \beta\log Z(x)
$$

把它代回 Bradley-Terry 损失（第 3 节），**配分函数 $Z(x)$ 在差值里抵消**，得到 DPO 损失：

$$
\mathcal{L}_{DPO} = -\,\mathbb{E}\Big[\log\sigma\Big(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\Big)\Big]
$$

### 6.2 这意味着什么

**DPO 把"训 RM + PPO"两步合并成一个二分类损失，不需要采样、不需要 RM、不需要 Critic。** 隐式奖励就是 $\hat r(x,y)=\beta\log\frac{\pi_\theta}{\pi_{ref}}$。

```
 RLHF (PPO):  偏好 ─► 训RM ─► 在线采样 ─► PPO(4模型)  ──► π
 DPO:         偏好 ───────────────────► 一个分类损失(2模型) ──► π
```

### 6.3 DPO 的取舍

| 维度 | DPO 优 | DPO 劣 |
|------|--------|--------|
| 工程 | 简单、稳、省显存（无 RM/Critic） | — |
| 数据 | 直接用静态偏好对 | **离线**，不能像 PPO 在线探索新回答 |
| 表达 | — | 隐式 RM 表达力 < 显式 RM；易在 OOD 上偏 |
| 已知坑 | — | 可能同时**降低** $y_w,y_l$ 概率（只要相对差对）→ 概率坍塌；对噪声偏好敏感 |

> 衍生：IPO（去 BT 假设防过拟合）、KTO（用单条好/坏样本无需成对）、ORPO（无需 ref 模型）、SimPO（去 ref、长度归一）。

## 7. GRPO：扔掉 Critic

### 7.1 动机

PPO 里 Critic 几乎和 Actor 一样大，**训练它本身就难、显存翻倍**。GRPO（DeepSeek 提出）的洞察：**优势不一定要 Critic 给，可以用"同一 prompt 采一组回答的平均奖励"当基线。**

### 7.2 做法

对每个 prompt $x$ 采一组 $G$ 个回答 $\{y_1,\dots,y_G\}$，各自打分 $r_i$，**组内归一**得到优势：

$$
\hat A_i = \frac{r_i - \mathrm{mean}(r_1,\dots,r_G)}{\mathrm{std}(r_1,\dots,r_G)}
$$

同一回答内所有 token 共享这个 $\hat A_i$。再套 PPO 的 clip 目标，外加**直接的 KL 正则项**（GRPO 把 KL 放进损失而非塞进奖励）：

$$
\mathcal{L}_{GRPO} = -\mathbb{E}\Big[\tfrac{1}{G}\sum_i \min(\rho_i \hat A_i,\,\mathrm{clip}(\rho_i,1\pm\epsilon)\hat A_i) - \beta\,\mathrm{KL}(\pi_\theta\|\pi_{ref})\Big]
$$

```
 PPO:   优势 = r - V_ψ(s)        ← 需要训练 Critic（贵）
 GRPO:  优势 = (r_i - 组均值)/组标准差   ← 组内比较，免 Critic（省）

 prompt x ──► 采样 G 个回答
              y1:r=2 ┐
              y2:r=5 ├─► 均值3.0 ─► A1=-1.0, A2=+2.0, A3=-1.0(归一后)
              y3:r=2 ┘            高于均值的被拉高，低于的被压低
```

### 7.3 取舍

- **省**：去掉 Critic → 显存与工程大降，特别适合**可验证奖励**（数学/代码用规则判对错，不需训 RM）。
- **限**：组内基线方差比学出来的 Critic 大；对每个 prompt 要采 $G$ 个样本，采样开销上升；若组内回答得分全相同（std≈0）则该样本无梯度。

## 8. DeepSeek-R1：纯 RL 涌现推理

> 见 [[llm-algo/deepseek/DeepSeek-R1]]。这里只讲面试要点。

- **R1-Zero**：**完全不做 SFT**，直接在基座上用 GRPO + **规则奖励**（答案对不对、格式对不对）做 RL。结果：模型自发学会"长思维链、反思、自我验证"，出现 **aha moment**（顿悟时刻）。证明了**推理能力可由纯 RL 激发**，不必靠人标 CoT。
- **R1-Zero 的毛病**：可读性差、中英混杂。
- **R1（完整版）**：加**冷启动**——先用少量高质量长 CoT 数据 SFT，再 RL，再用拒绝采样 + SFT，再做覆盖全场景的 RL。流水线：冷启动SFT → 推理RL → 拒绝采样SFT → 全场景RL。
- **奖励设计**：数学/代码用**可验证规则奖励**（不易被 hack，故 R1 用 GRPO 而非训 RM）；通用任务才辅以偏好/格式奖励。

**面试要点**：R1 把"对齐推理"和"对齐偏好"分开看——**推理靠可验证奖励 + GRPO，偏好靠 RM**。这也是 GRPO 流行的直接推手。

## 9. 数值手算（把公式落到数字）

### 9.1 RM 损失（Bradley-Terry）

设某对样本 RM 打分 $r_w=2.0,\ r_l=0.5$，差值 $\Delta=1.5$：

$$
P(y_w\succ y_l)=\sigma(1.5)=\frac{1}{1+e^{-1.5}}=\frac{1}{1+0.2231}=0.818
$$
$$
\mathcal{L}=-\log 0.818 = 0.201
$$

若模型打反了 $r_w=0.5,r_l=2.0$，$\Delta=-1.5$：$P=\sigma(-1.5)=0.182$，损失 $-\log0.182=1.70$——**打反惩罚远大于打对**，符合直觉。

### 9.2 PPO 的 clip

设 $\epsilon=0.2$，某 token 优势 $\hat A=+3$，旧概率 0.4，新概率 0.6 → $\rho=0.6/0.4=1.5$。
- 未裁剪项：$1.5\times3=4.5$
- 裁剪项：$\mathrm{clip}(1.5,0.8,1.2)\times3=1.2\times3=3.6$
- 取 min → **3.6**。比 $1.5$ 截到 $1.2$，**多出的激励被砍掉**，防止一步把这个 token 概率推太高。

### 9.3 KL 惩罚对 token 奖励的影响

某 token：$\log\pi_\theta=-0.5,\ \log\pi_{ref}=-0.9$，$\beta=0.1$。
KL 项 $=\log\pi_\theta-\log\pi_{ref}=-0.5-(-0.9)=0.4$（策略在此 token 比参考更自信）。
该 token 奖励扣减 $=\beta\times0.4=0.04$。若整句 200 token 平均每个偏离 0.4，KL 罚 $\approx0.1\times0.4\times200=8.0$——**足以抵消一个 RM 高分**，这就是橡皮筋的力量。

### 9.4 GRPO 组内优势

一组 $G=4$，奖励 $r=[2,5,2,3]$：均值 $=3.0$，标准差 $=\sqrt{((2-3)^2+(5-3)^2+(2-3)^2+(3-3)^2)/4}=\sqrt{(1+4+1+0)/4}=\sqrt{1.5}=1.225$。
归一优势：
$$
\hat A=\Big[\tfrac{2-3}{1.225},\tfrac{5-3}{1.225},\tfrac{2-3}{1.225},\tfrac{3-3}{1.225}\Big]=[-0.82,\ +1.63,\ -0.82,\ 0]
$$
第二个回答（5 分）被显著拉高，两个 2 分被压低，3 分（=均值）不动——**无需 Critic 就得到了相对优势**。

### 9.5 DPO 隐式奖励

$\beta=0.1$，对 $y_w$：$\log\pi_\theta=-10,\log\pi_{ref}=-12$ → 隐式奖励 $0.1\times(-10-(-12))=0.1\times2=0.2$。
对 $y_l$：$\log\pi_\theta=-15,\log\pi_{ref}=-13$ → $0.1\times(-15-(-13))=0.1\times(-2)=-0.2$。
DPO logit $=0.2-(-0.2)=0.4$，损失 $=-\log\sigma(0.4)=-\log0.599=0.512$。梯度会**同时**抬高 $y_w$、压低 $y_l$ 的相对对数概率。

## 10. 对照表 + 高频追问 + 陷阱

### 方法对照

| 维度 | PPO | DPO | GRPO |
|------|-----|-----|------|
| 需要 RM | ✅ | ❌（隐式） | ✅/规则奖励 |
| 需要 Critic | ✅ | ❌ | ❌ |
| 模型数(训练时) | 4 | 2 | 3 |
| 在线采样 | ✅ | ❌（离线） | ✅（组采样） |
| 优势来源 | GAE + Critic | 无（直接分类） | 组内归一 |
| 显存 | 高 | 低 | 中 |
| 稳定性/调参 | 难 | 易 | 中 |
| 代表 | InstructGPT/ChatGPT | Zephyr/Llama-3后训部分 | DeepSeek-R1/Math |
| 适合 | 通用偏好、需在线探索 | 有静态偏好对、资源有限 | 可验证奖励、推理任务 |

| PPO 涉及几个模型？ | 4 个：Actor/Critic 训，Reward/Reference 冻 |
| 为什么要 KL？ | 拴住策略在 RM 可信区，防奖励过优化/Goodhart |
| RM 分越高越好吗？ | 否，先升后降（过优化），靠 KL+早停+重训 RM 缓解 |
| RM 为什么 pairwise？ | 绝对分方差大不一致；BT 模型学相对偏好 |
| DPO 怎么去掉 RL 的？ | KL 约束最大化有闭式解→反解奖励代回 BT→Z(x)抵消→分类损失 |
| DPO vs PPO？ | DPO 简单稳省但离线、表达弱；PPO 重但能在线探索、上限高 |
| GRPO 省在哪？ | 用组内均值当基线，砍掉 Critic |
| R1 为什么用 GRPO 不用 PPO？ | 推理用可验证规则奖励，无需 RM/Critic，GRPO 更省更稳 |
| R1-Zero 证明了什么？ | 纯 RL（无 SFT）可激发长 CoT 与反思（aha moment） |
| Reference 模型是谁？ | 通常就是 SFT 模型，冻结，用来算 KL 锚点 |

### 陷阱清单（容易答错的点）

- ❌ "RM 输出是绝对质量分" → ✅ BT 损失只约束差值，无绝对量纲，**跨 prompt 不可直接比**。
- ❌ "KL 惩罚是为了防过拟合" → ✅ 是防**分布漂移到 RM 不可信区**（奖励黑客/过优化）。
- ❌ "DPO 完全等价 PPO" → ✅ 只在理论假设下等价；DPO 离线、无探索、对 OOD 与噪声更敏感。
- ❌ "GRPO 不需要任何奖励" → ✅ 仍需奖励（RM 或规则），只是不需要 **Critic**。
- ❌ "PPO 中间每个 token 都有 RM 奖励" → ✅ RM 句子级只给末尾一次，中间 token 奖励主要是 KL 项。
- ❌ "R1 = 纯 RL 无 SFT" → ✅ 那是 **R1-Zero**；正式 R1 有冷启动 SFT + 多阶段。
- ❌ "DPO 的 $\beta$ 越大越接近最优" → ✅ $\beta$ 控制偏离 ref 的强度，过大几乎不更新，过小易坍塌。
