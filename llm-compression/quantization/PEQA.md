# PEQA (量化感知微调)

> 把"只微调量化 scale"做到极致的 PEFT：权重永久量化成低位整数后冻结，**只更新每个输出通道的量化步长**，一次微调同时拿到「省显存的训练 + 低位部署的推理」两份红利。📍 导航：[[00-知识地图]]
> 🔗 相关：[[00-知识地图]] [[llm-compression/quantization/量化基础]] [[llm-train/peft/PEFT-API]]

PEQA = **P**arameter-**E**fficient and **Q**uantization-aware **A**daptation（论文 *Memory-Efficient Fine-Tuning of Compressed LLMs via sub-4-bit Integer Quantization*，NeurIPS 2023，KAIST + NAVER）。

## 0. 一句话锚点

> **PEQA 把一层线性权重写成「冻结的整数矩阵 $\overline{W}$」乘上「可学习的逐通道步长 $s$」，微调时梯度只更新 $s$（参数量 ≈ 输出维度那么大），整数矩阵全程不动。** 训练完直接就是一个低位量化模型，无需再额外做量化。

两个红利一次拿到：
- **训练省显存**：可训练参数极少（只有 scale），优化器状态（Adam 的一阶/二阶动量）几乎为零。
- **部署天然低位**：微调结束权重本身就是 INT3/INT4，不像 LoRA 那样还要把高精度增量合并回去再量化。

---

## 1. 地基 / 前置

### 1.1 量化基础（一分钟复习）

把一个浮点权重张量 $W$ 用「低位整数 + 缩放因子」近似表示：

$$W \approx s \cdot \overline{W}, \qquad \overline{W} = \mathrm{round}\!\left(\frac{W}{s}\right) \in \{-2^{b-1},\dots,2^{b-1}-1\}$$

- $b$：位宽（PEQA 主打 **sub-4-bit**，即 3-bit、4-bit）。
- $s$：**scale / 量化步长**，控制每个整数格子代表多大的真实数值。
- $\overline{W}$：**整数（定点）矩阵**，存储只占 $b$ bit/元素。
- 量化粒度：PEQA 用 **per-output-channel（逐输出通道）**，即每一行（或每个输出神经元）一个独立的 $s$。

> 关键直觉：$s$ 决定了"量化网格的刻度"，$\overline{W}$ 决定了每个权重落在网格的哪一格。**改 $s$ 等于整体伸缩这一通道所有权重的幅度，但保持它们的相对整数格点不变。**

详见 [[llm-compression/quantization/量化基础]]。

### 1.2 PEFT 基础（一分钟复习）

PEFT（参数高效微调）= 冻结预训练大权重，只训练极少量新参数。代表：

- **LoRA**：冻结 $W$，加一个低秩增量 $\Delta W = BA$，只训练 $A,B$。
- **Adapter / Prefix / (IA)³** 等。

PEQA 属于 PEFT 家族，但它训练的"少量参数"不是新加的低秩矩阵，而是**量化本身就需要的 scale 向量**。详见 [[llm-train/peft/PEFT-API]]。

## 2. 为什么"先微调再量化"或"先量化再微调"都别扭

朴素地把"适配"和"压缩"拼起来，有三条路，全有坑：

```
路线A：全量微调(FP16) ──▶ 再做PTQ量化
   ✗ 微调阶段显存巨大(优化器状态=2×参数量FP32)
   ✗ 量化是事后近似，掉点不可控

路线B：先量化(INT4) ──▶ 冻结整数，加FP16 LoRA增量(=QLoRA)
   ✓ 训练省显存
   ✗ 部署时 LoRA 增量是高精度的：要么合并回去破坏量化、
     要么推理时保留一条FP16旁路 → 不是"纯低位模型"

路线C：PEQA ──▶ 量化 + 只学scale
   ✓ 训练省显存(可训参数≈输出维度)
   ✓ 结束即纯INT3/INT4模型，无高精度旁路
```

PEQA 的卖点正是补上路线 B 的最后一块：**让适配后的结果仍然是一个干净的低位整数模型**。

## 3. 核心分解：$W = s \odot \overline{W}$

对每一个全连接层（线性层）的权重矩阵 $W \in \mathbb{R}^{d_{out} \times d_{in}}$：

$$W \;\approx\; \mathrm{diag}(s)\,\overline{W} \;=\; s \odot \overline{W}$$

其中：
- $s \in \mathbb{R}^{d_{out}}$：逐输出通道步长向量（每个输出神经元一个标量）。
- $\overline{W} \in \mathbb{Z}^{d_{out}\times d_{in}}$：冻结的整数矩阵，每元素 $b$ bit。
- $\odot$：把 $s$ 沿 $d_{in}$ 方向广播后逐元素相乘（即 $s$ 的第 $i$ 个值乘到 $\overline{W}$ 的第 $i$ 行）。

```
       d_in 列
   ┌───────────────────┐      s (d_out,)
   │  ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ │ ×  s_0  ┐
   │  ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ │ ×  s_1  │ 每行(每个输出通道)
   │  ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ │ ×  s_2  │ 共享一个 scale
   │       整数 W̄       │  ...    │
   │  ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ │ × s_{d-1}┘
   └───────────────────┘
    ▢ = b-bit 整数，冻结不动      s = FP，可学习
```

> 初始化：先用一个 PTQ 量化器（如 OPTQ/GPTQ 或简单的 min-max round-to-nearest）把预训练 $W_0$ 拆成 $(s_0,\ \overline{W})$，使 $s_0\odot\overline{W}\approx W_0$。然后冻结 $\overline{W}$，把 $s$ 设为可训练。

---

## 4. 训练时更新谁、冻结谁

PEQA 在微调时**唯一可训练参数就是 $s$**。论文的更新形式可以理解为：在量化基底上对 scale 做梯度下降。

$$W = \big(s_0 + \Delta s\big)\odot \overline{W}, \qquad \text{只学 } \Delta s$$

- $\overline{W}$：**冻结**（整数，不接收梯度）。
- $s_0$：初始 scale（来自 PTQ）。
- $\Delta s$：**可训练**的 scale 调整量，形状 $(d_{out},)$。

```
┌──────────── 一个线性层的参数 ────────────┐
│  W̄  (d_out × d_in, INT3/4)   ❄ 冻结      │  ← 占绝大部分存储，但不更新
│  s   (d_out, FP)             🔥 可训练   │  ← 唯一梯度去向
└───────────────────────────────────────────┘
可训练参数比例 ≈ d_out / (d_out × d_in) = 1 / d_in
对 d_in=4096 → 约 0.024% 的参数被训练
```

直觉解释为什么"只调 scale"就够用：
1. 预训练已经把权重的**相对结构**（谁大谁小、符号）学好了，这部分锁在 $\overline{W}$ 里。
2. 下游任务往往只需要**各通道整体幅度的微调**——放大/缩小某些输出神经元的响应强度，这恰好由 $s$ 控制。
3. 这是一种强约束，把适配限制在一个极低维流形上，既省参数又起到隐式正则、抗过拟合的作用。

## 5. 前向 / 反向数据流（含 STE）

### 前向

$$y = (s \odot \overline{W})\,x = \mathrm{diag}(s)\,\overline{W}\,x$$

```
x ──▶ [ INT W̄ ] ──(整数/低位矩乘)──▶ z ──(× s 逐通道)──▶ y
        ❄冻结                                 🔥scale
```

实现上常等价写成：先用反量化得到 $\widehat{W}=s\odot\overline{W}$（FP），再做标准 $y=\widehat{W}x$；训练框架里这样最省事。

### 反向（梯度只回到 $s$）

对 scale 的梯度（第 $i$ 个输出通道）：

$$\frac{\partial \mathcal{L}}{\partial s_i} \;=\; \sum_{j} \frac{\partial \mathcal{L}}{\partial \widehat{W}_{ij}} \cdot \overline{W}_{ij}$$

即"上游对反量化权重的梯度"与"冻结整数行"逐元素相乘再求和——一个干净的逐行点积，**不需要对 $\overline{W}$ 求梯度**。

```
  ∂L/∂y
    │  (链式)
    ▼
  ∂L/∂Ŵ = (∂L/∂y) ⊗ xᵀ
    │
    ├──▶ 与 W̄ 逐行点积 ─▶ ∂L/∂s   🔥 更新这里
    │
    └──▶ (本可继续到 W̄，但 W̄ 冻结) ❄ 丢弃
```

> 注：若实现里把 round 也放进计算图（如训练中重量化），需要 **STE（直通估计器）** 让 $\mathrm{round}$ 的梯度近似为 1。但 PEQA 标准设定中 $\overline{W}$ 是固定整数、不重新 round，所以 scale 的梯度是**精确**的，不靠 STE 近似——这是它训练稳定的原因之一。

## 6. 显存账：为什么省得这么狠

微调时显存四大块：① 模型权重 ② 梯度 ③ 优化器状态 ④ 激活。PEFT 主攻 ②③。

以 Adam 为例，每个**可训练**参数需要：梯度 (1×) + 一阶动量 m (1×) + 二阶动量 v (1×)，通常 FP32，约 12 字节/参数。

```
全量微调(FP16权重, Adam-FP32):
  权重 2B + 梯度 2B(或4B) + m 4B + v 4B ≈ 12~16 B / 参数 × 全部参数

PEQA:
  权重 W̄: 3~4 bit / 参数 (冻结，无梯度/动量)
  可训练 s: 仅 d_out 个/层 → 优化器状态几乎可忽略
  ┌─────────────────────────────────────────┐
  │ 优化器状态 ∝ 可训练参数 ≈ 0.02%~0.1% 全参 │
  └─────────────────────────────────────────┘
```

对照（量级感受，**约值，以官方/具体配置为准**）：

```
 65B 模型微调峰值显存(示意)
 全量FP16     ████████████████████████  >780 GB(多卡)
 LoRA(FP16基)  ████████████              ~中等(基座仍FP16)
 QLoRA(4bit)   ██████                    单卡48GB级别可行
 PEQA(3~4bit)  ████                      与QLoRA同档，更低
```

PEQA 与 QLoRA 同属"4-bit 基座 + 极少可训练参数"，显存量级相近；PEQA 的可训练参数比 LoRA 还少（没有低秩 $A,B$，只有 scale 向量）。

## 7. PEQA vs QLoRA 逐项对比

二者都是"量化 + PEFT"的组合，核心差异在 **可训练对象** 与 **部署形态**。

```
                QLoRA                          PEQA
 基座权重     NF4 量化, 冻结                INT3/4 量化, 冻结
 可训练参数   低秩 A,B (FP16/BF16)          scale 向量 s (FP)
 增量形式     ΔW = BA  (高精度旁路)         直接调 s，无独立增量
 反量化       前向时 NF4→BF16 再算          s⊙W̄
 部署形态     基座低位 + LoRA高精度旁路      纯 INT3/4 模型 ✓
   ├ 合并     合并ΔW回权重→破坏4bit→需重量化  无需合并(本就低位)
   └ 不合并   推理留一条FP16 LoRA分支         无旁路，干净
 多任务切换   换一组小 A,B                   换一组小 s
 表达能力     秩 r 可调，较强                受限于"只缩放通道"，较弱
 极低位(<4bit) 不是主打                      主打 sub-4-bit ✓
```

一句话区分：
- **QLoRA**："量化是为了省训练显存"——训练完那条 LoRA 旁路通常仍是高精度，部署时面临"合并 vs 保留旁路"的两难。
- **PEQA**："量化就是最终部署形态"——微调直接发生在量化参数（scale）上，结束即得纯低位模型。

```
部署对比(数据流)
QLoRA:  x ─▶[INT4基座]─┐
              │         ▼
              └─▶[A·B FP16]─▶(+)─▶ y     ← 两条路，一条高精度
PEQA:   x ─▶[INT3/4 × s]──────────▶ y     ← 一条路，全低位
```

## 8. 何时用 / 不用 PEQA

```
                需要"微调后直接得低位部署模型"?
                          │
              ┌───── 是 ──┴── 否 ─────┐
              ▼                        ▼
     目标位宽 ≤4-bit?            训练完还要FP16推理/还会再训?
        │                            │
   ┌─ 是 ┴ 否 ─┐              ┌─ 是 ─┴─ 否 ─┐
   ▼           ▼              ▼             ▼
  PEQA 很合适  PEQA可用       用 LoRA      可用 QLoRA
  (sub-4bit    (但优势减弱,    (保留高精度  (训练省显存,
   是主场)      QLoRA也行)      灵活性)      部署再决定)
```

**适合 PEQA**：
- 端侧/受限显存部署，**必须**是纯 INT3/INT4 模型，不能带高精度旁路。
- 需要快速任务切换：每个任务只存一组很小的 scale 向量。
- 极低位（3-bit）场景，论文显示 PEQA 在 sub-4-bit 仍保持竞争力。

**不太适合 / 谨慎**：
- 任务与预训练分布差异极大，需要较强表达能力时——"只缩放通道"可能不够，LoRA 的低秩增量更灵活。
- 还要在微调后继续做大幅度训练或保留 FP16 推理路径。

## 9. 数值例子：手算一层的量化与微调

设某线性层取一行（一个输出通道）的 4 个权重，做 **4-bit 对称量化**（整数范围 $[-8,7]$）。

原始权重行：

$$W_{\text{row}} = [\,0.62,\ -0.20,\ 0.41,\ -0.83\,]$$

**步骤 1：定 scale。** 对称量化常用 $s = \dfrac{\max|W|}{2^{b-1}-1} = \dfrac{0.83}{7} \approx 0.1186$。

**步骤 2：round 到整数（冻结）。**

| 权重 | $W/s$ | round → $\overline{W}$ |
|------|-------|------------------------|
| 0.62 | 5.23 | **5** |
| -0.20 | -1.69 | **-2** |
| 0.41 | 3.46 | **3** |
| -0.83 | -7.00 | **-7** |

所以 $\overline{W}_{\text{row}}=[5,-2,3,-7]$（这组整数从此**冻结**）。

反量化重建：$s\cdot\overline{W} = 0.1186\times[5,-2,3,-7]=[0.593,-0.237,0.356,-0.830]$（对 $W_0$ 的近似）。

**步骤 3：微调——只动 $s$。** 设某 batch 反传得到对反量化权重的梯度
$g_{\widehat{W}} = [0.10,\ 0.05,\ -0.20,\ 0.08]$。

对该通道 scale 的梯度（第 5 节公式，逐元素乘整数行再求和）：

$$\frac{\partial \mathcal{L}}{\partial s}=\sum_j g_{\widehat{W},j}\,\overline{W}_j = 0.10(5)+0.05(-2)+(-0.20)(3)+0.08(-7)$$
$$= 0.50 - 0.10 - 0.60 - 0.56 = -0.76$$

取学习率 $\eta=0.01$，更新：

$$s \leftarrow s - \eta\cdot\frac{\partial\mathcal{L}}{\partial s} = 0.1186 - 0.01\times(-0.76) = 0.1186 + 0.0076 = 0.1262$$

**步骤 4：看效果。** 新的反量化权重（整数没变，只 scale 变大）：

$$s'\cdot\overline{W}=0.1262\times[5,-2,3,-7]=[0.631,-0.252,0.379,-0.883]$$

> 观察：**一个标量 $s$ 的更新，同时调整了整行 4 个权重的幅度**，且保持相对比例（5:-2:3:-7）不变。这就是"只学 scale"的杠杆——用 1 个参数撬动 $d_{in}$ 个权重的整体强度。对整层 $d_{out}$ 个通道，可训练参数就是 $d_{out}$ 个，而非 $d_{out}\times d_{in}$ 个。

**参数量对照（单层，$d_{out}=d_{in}=4096$）：**

```
 全量微调可训练参数   : 4096×4096 = 16,777,216
 LoRA(r=8)可训练参数  : 8×(4096+4096) = 65,536
 PEQA可训练参数(s)    : 4096                ← 比 LoRA 还少一个量级
```

## 10. 常见问题

| 问题 | 解答 |
|------|------|
| PEQA 训练的到底是什么？ | 只有量化 scale 向量 $s$（每个输出通道一个标量）。整数矩阵 $\overline{W}$ 全程冻结。 |
| 它和 QLoRA 最大区别？ | QLoRA 训练高精度低秩旁路 $BA$，部署留高精度分支；PEQA 训练量化 scale，结束即纯低位模型，无旁路。 |
| 只调 scale 表达力会不会太弱？ | 受限于"逐通道整体缩放"，比 LoRA 弱；但预训练已锁住相对结构，下游常只需调幅度，论文实测在 sub-4-bit 仍有竞争力。 |
| 为什么省显存？ | 可训练参数 ≈ $d_{out}$（占比约 $1/d_{in}$），Adam 优化器状态随之近乎为零；基座以 3~4bit 存储。 |
| 需要 STE 吗？ | 标准设定中 $\overline{W}$ 固定不重 round，对 $s$ 的梯度是精确的，不依赖 STE 近似，训练更稳。 |
| 支持多低的位宽？ | 主打 sub-4-bit（3-bit、4-bit），论文做到 65B 规模仍可扩展。 |
| 多任务怎么切换？ | 共享同一份冻结整数权重，每个任务只存一组很小的 $s$，切换即换 scale。 |
| 推理会更快吗？ | 是，权重本身是低位整数，结合低位 kernel 可降低带宽与延迟；无高精度旁路计算。 |
| 初始 scale 哪来？ | 先用一个 PTQ 量化器（如 GPTQ/OPTQ 或 min-max RTN）把 $W_0$ 拆成 $(s_0,\overline{W})$ 作为初始化。 |
| 能和 GPTQ 一起用吗？ | 可以。用 GPTQ 得到高质量整数初始化，再用 PEQA 微调 scale，是常见组合。 |
