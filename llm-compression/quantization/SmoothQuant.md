## 0. 一句话锚点

LLM 里**激活值有少数几个通道幅值奇大(离群值 outlier)**，把它们一起线性量化会让其余正常值被压成几乎全 0，精度崩塌。SmoothQuant 的观察是：**权重分布平坦、好量化；激活分布尖锐、难量化**。于是它用一个**逐通道(per-channel)的缩放向量 $s$**，把激活每个通道"按比例缩小"、同时把对应的权重通道"按比例放大"，乘积 $Y=XW$ 数学上**完全不变**，但量化难度被从激活"搬"了一部分到权重上。两边都变得"还行"，于是 **W8A8(权重 8bit、激活 8bit)整型 GEMM** 就能跑了。

它是**免训练 PTGQ(Post-Training Quantization)**：不需要反向传播、不需要数据集微调，只要一小批校准数据统计一下激活幅值即可。

## 1. 地基：量化与 GEMM(从最底层讲起)

**量化(线性对称量化)**：把浮点张量 $X$ 用一个标量 $\Delta$(scale，步长)映射到整数：

$$
X_{int}=\mathrm{round}\!\left(\frac{X}{\Delta}\right),\qquad \Delta=\frac{\max|X|}{2^{b-1}-1}
$$

8bit($b=8$)时整数范围 $[-127,127]$。反量化 $\hat X=\Delta\cdot X_{int}$。误差来自 round，最大约 $\Delta/2$。**关键直觉：$\Delta$ 由该张量的最大绝对值决定。一个超大离群值会把 $\Delta$ 撑大，于是所有小值的相对误差被放大。**

**粒度(granularity)——记牢这三个词**：

```
per-tensor    : 整个张量共用 1 个 scale Δ          ← 最省、硬件最爽
per-token     : 激活每一行(每个 token)1 个 scale    ← 行方向，硬件友好
per-channel   : 每一列(每个特征通道)1 个 scale       ← 列方向，激活上硬件不友好
```

**线性层就是一次矩阵乘 GEMM**：$Y = X\,W$，其中
- $X$：激活，形状 $[T,\,C_{in}]$($T$ 个 token，每个 $C_{in}$ 维)
- $W$：权重，形状 $[C_{in},\,C_{out}]$

```
        C_in                     C_out                 C_out
      ┌──────┐                ┌────────┐            ┌────────┐
  T   │  X   │   ×   C_in    │   W    │   =   T    │   Y    │
      └──────┘                └────────┘            └────────┘
      激活(动态,在线)          权重(静态,可离线)        输出
```

输出元素 $Y[t,j]=\sum_{i} X[t,i]\,W[i,j]$。注意求和沿 $C_{in}$(输入通道)方向 —— 这条"求和轴"是后面所有事情的关键。

---

## 2. 为什么激活难量化:outlier 现象

实测大模型(OPT/BLOOM/GLM…)在层数变深后，激活张量 $X$ 里会出现**系统性离群值**：

1. **幅值极端**：个别元素可达 ~100，而普通元素 ~0.1，相差约 **1000 倍**。
2. **固定在少数通道**：离群只发生在**特定的几列(channel)** 上，且这些列跨 token 一致出现 —— 不是随机噪声，是"结构"。
3. **越大模型越严重**：参数量到 6.7B 量级开始爆发，正是朴素 INT8 在大模型上崩掉的直接原因。

```
激活 X 的某一行(一个 token, 沿 C_in 看):
通道:  0    1     2      3    4     5 ...
值:   0.1  0.2  ⟨ 97.3 ⟩ 0.1  0.3  ⟨ 88.0 ⟩ ...
            正常          离群           离群
                         ↑           ↑
                  只有少数列爆炸, 但跨所有 token 都在这几列
```

**per-tensor 量化为什么崩**：$\Delta=\max|X|/127$ 被 97.3 撑到 $\approx 0.766$。于是 0.1 量化成 $\mathrm{round}(0.1/0.766)=0$，0.2→0，0.3→0 —— **所有正常值全归零**，信息全没了。

而**权重 $W$ 的分布平坦**(无明显离群)，直接 per-tensor INT8 几乎无损。这就是那句核心事实：**权重易量化、激活难量化**。

---

## 3. 为什么不直接对激活做 per-channel

既然离群"按列聚集"，那对激活每列单独给一个 $\Delta_i$ 不就好了?——**理论上对、工程上不行**。

回看 $Y[t,j]=\sum_i X[t,i]W[i,j]$。INT8 GEMM 要高效，必须把 scale 提到**累加之外**：

$$
Y[t,j]\approx \Delta_X\,\Delta_W\sum_i X_{int}[t,i]\,W_{int}[i,j]
$$

这要求 $\Delta_X$ 在求和轴 $i$ 上是**常数**(才能提出 $\sum$)。
- **per-token**：$\Delta_X$ 随 $t$ 变(行)，但对每个固定 $t$、沿 $i$ 是常数 → **可以提出来**，硬件友好。
- **per-channel(激活)**：$\Delta_X$ 随 $i$ 变(列)，正好卡在求和轴上 → **提不出来**，每次乘加都要带不同 scale，等于退化成浮点逐元素处理，Tensor Core 的整型 MAC 流水线用不上。

```
求和轴 = C_in (i 方向)
   per-token scale  : 沿 i 不变  ✔ 可提出 Σ 外
   per-channel scale: 沿 i 变化  ✘ 卡在 Σ 里, INT8 GEMM 失效
```

结论:**激活只能用 per-tensor / per-token 这种"沿求和轴恒定"的粗粒度**，可它又恰恰扛不住按列分布的 outlier。死结。

---

## 4. 核心数学:把缩放搬进权重(SmoothQuant 的灵魂)

SmoothQuant 的破局:**别在激活上做 per-channel 量化，而是在激活上做 per-channel 缩放，再把这个缩放搬给权重抵消掉。**

引入对角缩放矩阵 $\mathrm{diag}(s)$，$s\in\mathbb{R}^{C_{in}}$ 每个输入通道一个数。利用 $\mathrm{diag}(s)^{-1}\mathrm{diag}(s)=I$ 插一个"乘一除一":

$$
Y = XW = \big(X\,\mathrm{diag}(s)^{-1}\big)\big(\mathrm{diag}(s)\,W\big) = \hat X\,\hat W
$$

逐元素看(这一步要看懂):

$$
\hat X[t,i]=\frac{X[t,i]}{s_i},\qquad \hat W[i,j]=s_i\,W[i,j]
$$

- 对**第 $i$ 个输入通道**:激活整列**除以 $s_i$**(把离群通道缩小),权重整行**乘以 $s_i$**(把对应行放大)。
- 乘积 $\hat X[t,i]\hat W[i,j]=\frac{X[t,i]}{s_i}\cdot s_i W[i,j]=X[t,i]W[i,j]$ → **逐元素不变,输出 $Y$ 数学上完全相等**。这是"数学等价变换",不是近似。

```
迁移前:  X(激活,有离群,难量) × W(权重,平坦,易量)
                 │  乘 diag(s)^{-1}        │  乘 diag(s)
                 ▼                         ▼
迁移后:  X̂ = X / s (离群被压平,变好量)  ×  Ŵ = s·W (吸收了离群,略变难)
         └────────── 难度从激活"搬"了一部分到权重 ──────────┘
```

直觉一句话:**离群通道 $i$ 的 $s_i$ 取大**,激活那列被狠狠缩小、不再撑爆 $\Delta_X$;代价是权重那行被放大,但权重本来平坦、放大点仍好量。**把"难"摊薄到两边,各退一步,两边都能塞进 INT8。**

---

## 5. 平滑因子 $s$ 怎么定:迁移强度 $\alpha$

$s_i$ 要多大?太小压不平离群;太大又把权重那行撑出新离群。需要在**激活的难度**和**权重的难度**之间找平衡点。

记
- $\mathbf{a}_i=\max_t |X[t,i]|$ : 第 $i$ 个输入通道激活的最大绝对值(用校准数据统计)。
- $\mathbf{w}_i=\max_j |W[i,j]|$ : 第 $i$ 行权重的最大绝对值。

SmoothQuant 取**几何插值**:

$$
\boxed{\,s_i=\dfrac{\big(\max_t |X[\,:,i]|\big)^{\alpha}}{\big(\max_j |W[i,:]|\big)^{1-\alpha}}=\dfrac{\mathbf{a}_i^{\alpha}}{\mathbf{w}_i^{\,1-\alpha}}\,}
$$

$\alpha\in[0,1]$ 是**迁移强度(migration strength)** 旋钮:

```
α = 0   : s_i = 1 / w_i^1        全压权重那边, 等于没动激活 (不迁移)
α = 0.5 : s_i = sqrt(a_i / w_i)  激活与权重难度对半分 (常用默认)
α = 1   : s_i = a_i              把激活完全压成均匀, 全部难度甩给权重
```

迁移后,该通道激活幅值变为 $\mathbf{a}_i/s_i=\mathbf{a}_i^{1-\alpha}\mathbf{w}_i^{1-\alpha}$,权重幅值变为 $s_i\mathbf{w}_i=\mathbf{a}_i^{\alpha}\mathbf{w}_i^{\alpha}$。$\alpha$ 越大,激活越被压平、权重越被抬高。**默认 $\alpha=0.5$**;离群特别凶的模型(如 GLM-130B)可调到 ~0.75 让激活多让点。

## 6. W8A8 整条推理链

"W8A8" = **Weight 8bit, Activation 8bit**,矩阵乘真正跑在 INT8 上:

```
[1] 校准(离线,一次):跑少量样本 → 统计每通道 a_i, w_i → 算 s_i
[2] 平滑(离线):  X̂=X/diag(s),  Ŵ=diag(s)·W   ← s 吸进 LN/前层, 见 §7
[3] 量化:
      激活 X̂  → INT8  (per-token 或 per-tensor, 此时已无离群, 好量了)
      权重 Ŵ  → INT8  (per-channel/per-tensor)
[4] 推理:  Y_int = X̂_int  @  Ŵ_int    ← INT8 GEMM, Tensor Core 整型 MAC
[5] 反量化:  Y = Δ_X · Δ_W · Y_int          ← scale 提到累加外
```

收益:权重 FP16→INT8 **显存减半**;GEMM 走 INT8 Tensor Core **吞吐翻倍量级**(论文最高 ~1.56× 端到端加速、~2× 显存下降),精度损失可忽略,支持单节点服务 530B。

## 7. 离线融合:缩放为何"零开销"

担心 $\hat X=X/s$ 是不是每次推理都得额外做一次除法?**不用**。Transformer 里线性层前面通常是 **LayerNorm** 或上一层的输出。$\mathrm{diag}(s)^{-1}$ 是逐通道缩放,可以**预先乘进 LayerNorm 的 $\gamma,\beta$**(或前一层权重),离线一次性折叠:

```
原:   x → LayerNorm(γ, β) → Linear(W)
融合: x → LayerNorm(γ/s, β/s) → Linear(s·W)
              └ 缩放吸进归一化参数 ┘   └ 缩放吸进权重 ┘
推理时无任何额外算子, s 不出现在运行图里 → 真·零开销
```

权重侧 $\hat W=s\cdot W$ 更是**纯离线**改一次权重文件即可。所以 SmoothQuant 的"平滑"在推理时**不增加任何计算**,这也是它能"交钥匙"落地的原因。

## 8. 手算一个完整迁移例子(逐数)

取一个 mini 线性层。激活 $X$ 有 4 个输入通道,通道 2 是离群通道。权重 $W$ 形状 $[4,1]$(单输出,够说明问题)。

**给定数据**

```
X (2 个 token × 4 通道):
            ch0   ch1   ch2(离群)  ch3
 token0:    0.1   0.2     64.0     0.1
 token1:    0.2   0.1     48.0     0.3
W (4×1):    0.10  0.20    0.10    0.30
```

每通道激活最大绝对值 $a_i$、每行权重最大绝对值 $w_i$:

```
a = [0.2, 0.2, 64.0, 0.3]      (ch2 离群)
w = [0.10, 0.20, 0.10, 0.30]
```

**(A) 不迁移、直接 per-tensor INT8 量化激活——看它崩**

$\Delta_X=\max|X|/127=64.0/127\approx0.5039$。量化普通值:
- $0.1\to\mathrm{round}(0.1/0.5039)=\mathrm{round}(0.198)=0$
- $0.2\to\mathrm{round}(0.397)=0$,  $0.3\to\mathrm{round}(0.595)=1$
- $64.0\to\mathrm{round}(127.0)=127$

→ ch0/ch1 几乎全部归 0,信息丢光。**崩。**

**(B) SmoothQuant,$\alpha=0.5$,算缩放因子 $s_i=\sqrt{a_i/w_i}$**

```
s0 = sqrt(0.2 / 0.10)  = sqrt(2.0)   ≈ 1.414
s1 = sqrt(0.2 / 0.20)  = sqrt(1.0)   = 1.000
s2 = sqrt(64.0/ 0.10)  = sqrt(640)   ≈ 25.30   ← 离群通道, s 很大
s3 = sqrt(0.3 / 0.30)  = sqrt(1.0)   = 1.000
```

**(C) 平滑后的激活 $\hat X=X/s$**

```
            ch0    ch1    ch2          ch3
 token0:  0.1/1.414  0.2/1   64.0/25.30  0.1/1
          =0.0707   =0.20   =2.530      =0.10
 token1:  0.2/1.414  0.1/1   48.0/25.30  0.3/1
          =0.1414   =0.10   =1.897      =0.30
```

离群通道从 64.0 → **2.53**,降了约 **25 倍**!新激活最大值 $\approx2.53$(原 64.0)。

**(D) 平滑后的权重 $\hat W=s\cdot W$**

```
ŵ0 = 1.414 × 0.10 = 0.1414
ŵ1 = 1.000 × 0.20 = 0.2000
ŵ2 = 25.30 × 0.10 = 2.530     ← 权重这行被抬高(吸收了离群)
ŵ3 = 1.000 × 0.30 = 0.3000
```

权重最大值 0.30 → 2.53,变大了但**仍平坦无极端尖刺**(权重本来好量),完全可控。

**(E) 量化 $\hat X$——现在不崩了**

$\hat\Delta_X=2.530/127\approx0.01992$。量化普通值:
- $0.0707\to\mathrm{round}(0.0707/0.01992)=\mathrm{round}(3.55)=4$  ✔ 非 0
- $0.10\to\mathrm{round}(5.02)=5$,  $0.20\to\mathrm{round}(10.04)=10$
- $0.30\to\mathrm{round}(15.06)=15$,  $2.530\to127$

→ **所有正常通道都拿到了有效非零整数**,信息保住了。对比 (A) 的"全 0",天壤之别。

**(F) 验证输出不变(数学等价性)**

token0 原始输出 $Y_0=\sum_i X_{0i}W_{i}$:

```
Y0 = 0.1×0.10 + 0.2×0.20 + 64.0×0.10 + 0.1×0.30
   = 0.010 + 0.040 + 6.400 + 0.030 = 6.480
```

平滑后 $\hat Y_0=\sum_i \hat X_{0i}\hat W_i$:

```
Ŷ0 = 0.0707×0.1414 + 0.20×0.20 + 2.530×2.530 + 0.10×0.30
   = 0.0100 + 0.0400 + 6.4009 + 0.0300 ≈ 6.480   ✔ 与 Y0 相同
```

**逐元素乘积不变 ⇒ 输出不变。** 这正是 §4 那条 $\hat X\hat W=XW$ 的数值确认。SmoothQuant 没有改变这一层的浮点结果,只是**把同一个乘积重排成了"两边都好量化"的形式**。

## 复杂度 / 对照表

| 维度 | 朴素 INT8(per-tensor) | LLM.int8() | SmoothQuant |
|------|------------------------|------------|-------------|
| 思路 | 直接量化 | 离群走 FP16、其余 INT8 混合精度 | 缩放迁移后全 INT8 |
| 大模型精度 | 崩 | 保住 | 保住(≈无损) |
| GEMM 类型 | INT8 | 混合(拆两条路) | **纯 INT8 单条路** |
| 额外运行开销 | 无 | 有(离群分解+两次 GEMM 拼接) | **无**(缩放离线融合) |
| 硬件友好度 | 高但不可用 | 中(分支多) | 高 |
| 需训练 | 否 | 否 | 否(仅校准统计) |
| 关键超参 | — | 离群阈值 | 迁移强度 $\alpha$(默认 0.5) |

**计算开销**:校准是 $O(\text{少量样本} \times \text{层数})$ 的一次性统计;每层算 $s$ 是 $O(C_{in})$;融合是改权重,**推理期零额外算子**。

## 常见问题

| 疑问 | 真相 |
|------|------|
| 平滑变换会损失精度吗? | $\hat X\hat W=XW$ **数学严格相等**,零损失;精度损失只来自之后的 INT8 round,而那已被缓解。 |
| $s$ 是学出来的吗? | 不是。闭式公式 $a_i^\alpha/w_i^{1-\alpha}$,只需校准统计 $a_i,w_i$,免训练。 |
| $\alpha$ 怎么选? | 默认 0.5;激活离群越凶越往大调(0.6~0.8)让激活多让步;太大反把权重撑出新离群。 |
| 为啥不能直接对激活 per-channel 量化? | per-channel 的 scale 卡在 GEMM 求和轴上,提不出累加,INT8 GEMM 失效(§3)。 |
| 缩放每次推理都要算除法? | 否。$\mathrm{diag}(s)^{-1}$ 离线吸进 LayerNorm/前层,$s\cdot W$ 离线改权重,运行时不出现(§7)。 |
| 和 LLM.int8() 谁好? | 互补。LLM.int8() 靠混合精度保精度但 GEMM 有分支;SmoothQuant 走纯 INT8 单路、更快更省,精度相当。 |
| 权重被放大后会不会也出离群? | 权重本来分布平坦,$\alpha$ 适中时放大有限;且权重可用 per-channel 量化兜底,不受求和轴约束。 |
| 适用哪些层? | 所有线性 GEMM(QKV、O、FFN 上下投影),覆盖 OPT/BLOOM/GLM/LLaMA 等。具体集成以官方实现为准。 |
