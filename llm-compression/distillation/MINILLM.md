## 0. 一句话锚点

**知识蒸馏 = 让小模型去拟合大模型输出的"概率分布"(软标签)，而不是只拟合一个"正确答案"(硬标签)。MiniLLM = 在生成式 LLM 上做白盒蒸馏，用反向 KL($\mathrm{KL}[q\|p]$，q 是学生)代替前向 KL，强迫学生只学老师"高概率的主峰"，避免学生在老师概率近乎为零的地方乱编。**

---

## 1. 地基：它解决什么问题

### 1.1 痛点

一个 175B 的大模型推理一次要几十张卡、延迟高、成本贵。我们想要一个 1B~7B 的小模型，**能力尽量接近大模型**。

最朴素的办法：拿大模型生成的数据，让小模型做监督微调(SFT)。但 SFT 只给小模型看了一条"硬答案"(token = 5921，概率 1，其余全 0)，丢掉了大模型"犹豫"的信息——大模型可能觉得 token A 70%、token B 25%、token C 5%，这些**相对概率**才是它"懂得多"的体现。

### 1.2 蒸馏的核心直觉

```
   硬标签(SFT)            软标签(蒸馏)
   正确答案="cat"          老师分布:
                          cat  0.70  ← 主答案
   cat  → 1.0             dog  0.20  ← "也挺像"
   dog  → 0.0             car  0.02  ← "几乎不可能"
   car  → 0.0             ...
   ────────               ────────
   信息量: 1 bit          信息量: 整个分布(暗知识 dark knowledge)
```

"dog 0.20 而 car 0.02"这种**类间相似度结构**(老师认为猫和狗比猫和车更像)就是"暗知识"。小模型学到这个，泛化更好。

> 术语锚点：**teacher(教师)** = 大模型(已训好，冻结)；**student(学生)** = 小模型(待训)；**软标签 soft label** = 老师输出的完整概率分布(经过 softmax)。

## 2. 软标签与温度(Temperature)

### 2.1 softmax 与 logits

模型最后一层输出每个 token 的**原始分数 logits** $z_i$，经 softmax 变成概率：

$$p_i = \frac{\exp(z_i)}{\sum_j \exp(z_j)}$$

直接 softmax 后，最大概率往往逼近 1，其余被压到接近 0——暗知识又丢了。于是引入**温度 $T$**：

$$p_i(T) = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

```
 logits = [5.0, 3.0, 1.0]

 T=1 (尖锐)      T=4 (平滑)        T→∞ (均匀)
 ┌──┐                              所有都接近 1/V
 │  │            ┌──┐
 │  │ ┌─┐        │  │┌─┐┌─┐
 │  │ │ │┌┐      │  ││ ││ │
 0.84 0.11 0.02  0.50 0.30 0.20    0.33 0.33 0.33
   ↑ 几乎只剩一个   ↑ 暗知识被放大     ↑ 全糊了
```

$T>1$ 把分布"摊平"，放大小概率项之间的差异，让暗知识更明显。**经典 KD(Hinton 2015)** 在 $T$ 较大时蒸馏，损失要乘 $T^2$ 补偿梯度缩放。

### 2.2 但 MiniLLM 不靠温度

MiniLLM 处理的是**自回归生成**，逐 token 预测，本身分布就有结构；它的创新点不在温度，而在**用反向 KL 改了拟合方向**(见 §5)。温度只是经典分类蒸馏的工具，这里作为前置概念交代清楚。

## 3. 白盒 vs 黑盒蒸馏

判据：**你能不能拿到老师的内部 logits / 概率分布？**

```
┌───────────────────── 黑盒蒸馏 (Black-box) ─────────────────────┐
│  老师 = ChatGPT / GPT-4 这种 API，只吐文本                       │
│                                                                 │
│   prompt ──► [Teacher API] ──► "生成的文本答案"                  │
│                                      │                          │
│                                      ▼ (当成硬标签)              │
│                              学生做 SFT 拟合文本                  │
│                                                                 │
│  能拿到: 只有采样出来的 token 序列(可能含 logprobs，也可能没有) │
│  本质:   更像"用老师造数据再 SFT"  例: Alpaca, Vicuna           │
└─────────────────────────────────────────────────────────────────┘

┌───────────────────── 白盒蒸馏 (White-box) ─────────────────────┐
│  老师 = 你自己持有权重的开源大模型(LLaMA/GPT-2 等)              │
│                                                                 │
│   prompt ──► [Teacher 权重] ──► 每个位置完整概率分布 p(·|x)      │
│                                      │                          │
│                                      ▼ (软标签，逐 token)        │
│                       学生最小化与老师分布的散度(KL)             │
│                                                                 │
│  能拿到: 每步 vocab 上的完整概率向量、隐藏层、注意力            │
│  本质:   分布层面对齐，信息量远大于黑盒  例: MiniLLM, GKD        │
└─────────────────────────────────────────────────────────────────┘
```

| 维度 | 黑盒蒸馏 | 白盒蒸馏(MiniLLM 属此) |
|---|---|---|
| 拿到的信号 | 文本(可能带 logprob) | 完整概率分布 + 隐状态 |
| 信息量 | 低(1 个硬答案/位置) | 高(整个分布/位置) |
| 适用场景 | 老师只有 API | 老师权重在手 |
| 训练信号 | 文本级监督 | token 级分布级监督 |
| 典型代表 | Alpaca、Self-Instruct | **MiniLLM**、GKD、ImitKD |

MiniLLM 论文标题《Knowledge Distillation of LLMs》要解决的正是："白盒**生成式**大模型怎么蒸"——以前白盒方法多针对**分类**模型，照搬到生成会出问题(见 §5)。

## 4. KL 散度本质：前向 vs 反向

KL 散度衡量"用分布 q 去近似分布 p 时损失多少信息"，**不对称**：

$$\mathrm{KL}[p \,\|\, q] = \sum_x p(x)\log\frac{p(x)}{q(x)}$$

设 $p$ = 老师分布(固定)，$q$ = 学生分布(可训)：

- **前向 KL** $\mathrm{KL}[p\|q]$：经典 KD 用的。期望按 **$p$(老师)** 加权——哪里老师概率高，哪里就被严格要求拟合。
- **反向 KL** $\mathrm{KL}[q\|p]$：MiniLLM 用的。期望按 **$q$(学生)** 加权——学生自己"去过的地方"才被惩罚。

关键看 $\log(p/q)$ 这一项在两种情况下的"惩罚结构"：

```
  前向 KL[p‖q]:  权重是 p(x)                反向 KL[q‖p]:  权重是 q(x)
  ─ p>0 而 q→0  ⇒ p·log(p/q) → +∞ 巨罚      ─ q>0 而 p→0  ⇒ q·log(q/p) → +∞ 巨罚
    "老师有的，学生必须有"                      "学生有的，老师必须也有"
  ⇒ 逼学生覆盖老师所有模式 (mean-seeking)     ⇒ 逼学生只待在老师高概率区 (mode-seeking)
  ─ p→0 处:  几乎不罚 (权重 p≈0)             ─ p→0 而 q>0:  巨罚
    学生可以在老师"零概率区"乱放概率              学生不准在老师没有的地方放概率
```

**一句话：前向 KL 强迫学生"什么都要学到"(覆盖所有峰)，会在老师概率为零的地方也分一杯羹 → 生成时容易胡编；反向 KL 强迫学生"宁可漏，不可错"(只锁老师的主峰) → 生成更可靠。**

## 5. 为什么反向 KL 更适合生成(mode-seeking)

老师在某个位置的分布常是**多峰**的(一句话有很多合理续写)。小模型容量有限，**装不下所有峰**。

```
        老师真实分布 p (多峰)
        ▁▁▆█▆▁▁▁▆█▆▁▁▁▂▄▂▁
            峰A      峰B    噪声/低概率长尾

 ── 前向 KL (mean-seeking, 覆盖所有) ──
 学生被迫"摊开"去够每个峰，结果落在中间空白:
        ▁▃▄▅▆▆▅▄▄▄▄▅▆▆▅▄▃▁
           ↑ 概率质量糊在峰A、峰B之间的"无效区"
           ↑ 还可能把噪声长尾也学进来
   生成后果: 采样到"两个答案缝合的怪话"、幻觉、不连贯

 ── 反向 KL (mode-seeking, 锁主峰) ──
 学生集中火力对准一个高概率主峰:
        ▁▁▁██▁▁▁▁▁▁▁▁▁▁▁▁▁
           ↑ 只精确还原峰A，舍弃峰B 和长尾
   生成后果: 输出虽不如老师多样，但每句都"靠谱"、低幻觉
```

对**生成式 LLM**，我们要的是"每一步采样出来的 token 都合理"，而不是"把老师的每个犄角旮旯都复现"。所以：

- 反向 KL 让学生**集中在老师确信的高质量区域** → 更少胡说、**更低暴露偏差**、**更好校准**、**长文本更稳**(论文报告的几项收益)。
- 它惩罚"学生在老师近零概率处放概率"，正好压制**幻觉**。
- 代价：**多样性下降**(mode-covering 能力弱)，可能丢掉老师的部分合理答案——这是核心权衡。

> 直觉记法：**前向 = "求全"(mean-seeking，宁滥勿缺)；反向 = "求精"(mode-seeking，宁缺勿滥)。** 小模型容量不够时，"求精"更划算。

## 6. MiniLLM 的损失

目标：在策略(学生)自己生成的序列上，最小化序列级反向 KL。记 prompt 为 $x$，回复序列为 $y=(y_1,\dots,y_T)$，老师 $p$、学生 $q_\theta$：

$$\mathcal{L}(\theta) = \mathrm{KL}\!\left[q_\theta(y\mid x)\,\big\|\,p(y\mid x)\right] = \mathbb{E}_{x\sim p_x}\;\mathbb{E}_{y\sim q_\theta(\cdot\mid x)}\left[\log\frac{q_\theta(y\mid x)}{p(y\mid x)}\right]$$

注意三件事：

1. **期望对 $y\sim q_\theta$** 取——样本是**学生自己采样**出来的(on-policy)，不是老师给的固定文本。这正是反向 KL 的定义，也是它"自我纠偏、低暴露偏差"的来源。
2. 逐 token 展开：$\log\frac{q_\theta(y|x)}{p(y|x)} = \sum_t \log\frac{q_\theta(y_t|y_{<t},x)}{p(y_t|y_{<t},x)}$。
3. 把 $r_t = \log\frac{p}{q}$ 看成"奖励"，**最小化反向 KL ≈ 最大化一个由老师定义的奖励** → 天然变成**强化学习(策略梯度)问题**。

```
 ┌──────────── MiniLLM 一步训练数据流 ────────────┐
 │ prompt x                                        │
 │   │                                             │
 │   ├─► 学生 q_θ 采样回复 y=(y1..yT)  (on-policy)  │
 │   │                                             │
 │   ├─► 老师 p 对该 y 逐 token 打分 log p(yt|·)    │
 │   ├─► 学生 q 对该 y 逐 token 打分 log q(yt|·)    │
 │   │                                             │
 │   └─► 逐 token 反向 KL 项 = log q − log p        │
 │            │  当成"负奖励"                       │
 │            ▼                                     │
 │      策略梯度更新 θ  (见 §7)                     │
 └─────────────────────────────────────────────────┘
```

## 7. 怎么优化：策略梯度 + 三个稳定技巧

因为 $y$ 是学生采样的，$\theta$ 既在被求期望的分布里又在被积函数里，不能直接反传。用**策略梯度(REINFORCE 类)**：

$$\nabla_\theta \mathcal{L} = -\,\mathbb{E}_{y\sim q_\theta}\!\left[\sum_t \nabla_\theta \log q_\theta(y_t\mid y_{<t},x)\cdot R_t\right]$$

其中 $R_t$ 是从位置 $t$ 往后累积的"老师奖励"$\log\frac{p}{q}$。朴素 REINFORCE 方差极大、训练不稳，MiniLLM 用三招(论文的"有效优化方法"核心)：

```
 ① 单步分解 (single-step decomposition)
    把序列级梯度拆成每个 token 的即时项 + 长程项，
    即时项可直接精确求(老师/学生分布都在手) → 大幅降方差
    ▁▁▁ 直接精确 ▁▁▁  +  ▒▒ 采样估计长程 ▒▒

 ② 教师混合采样 (teacher-mixed sampling)
    纯学生采样早期质量差、易跑偏；按比例混入老师建议:
    y_t ~ α·p(·) + (1−α)·q_θ(·)
    像"老师扶着学生走路" → 缓解 reward hacking / 退化

 ③ 长度归一化 (length normalization)
    反向 KL 的累积奖励天然偏好短句(短句 KL 累积小),
    会让学生"惜字如金"→ 按长度归一化纠偏
```

再叠加标准 RL 工程：**baseline / 优势函数**降方差、**clip**、对 prompt 数据先做一轮普通 SFT 当 warm-up。

> 工程提示：实现细节(混合系数 $\alpha$、是否带 PPO-clip、归一化方式)请**以官方 LMOps/minillm 仓库与论文为准**，不同复现版本略有差异。

## 8. 与 SFT 的区别(高频考点)

```
            SFT (监督微调)                MiniLLM 蒸馏
 数据来源   固定的(x, y*)硬标签语料       学生 on-policy 采样的 y
 监督信号   one-hot 硬标签               老师的完整软分布 p(·|x)
 目标       最大化 log q(y*|x)           最小化 KL[q‖p] (反向)
            =前向KL对 one-hot            =mode-seeking
 老师角色   无(标签是人写/固定)          老师逐 token 在线打分
 暴露偏差   高(只见 teacher-forcing      低(训练时就用自己生成的
            的真值前缀)                    前缀,训练≈推理分布)
 多样性     取决于语料                   偏低(求精,锁主峰)
 像什么     "背标准答案"                 "老师在线点评你的即兴发挥"
```

要点：
- **黑盒蒸馏(用老师造数据再 SFT)本质≈SFT**，是对老师文本做前向 KL，仍有暴露偏差。
- **MiniLLM 的根本不同**：① 信号是分布不是硬标签(白盒)；② 拟合方向是反向 KL(mode-seeking)；③ 样本来自学生自身(on-policy，对齐训练/推理分布，降暴露偏差)。

## 9. 数值例子：前向 vs 反向 KL 谁更"宽容"

设某位置词表只有 3 个候选，老师分布 $p$ 是双峰：

| token | 老师 $p$ | 学生方案A(只学主峰) | 学生方案B(摊平覆盖) |
|---|---|---|---|
| A | 0.60 | 0.95 | 0.34 |
| B | 0.39 | 0.04 | 0.33 |
| C(老师近零) | 0.01 | 0.01 | 0.33 |

**前向 KL** $\sum p\log\frac{p}{q}$：

- 方案A：$0.6\ln\frac{0.6}{0.95}+0.39\ln\frac{0.39}{0.04}+0.01\ln\frac{0.01}{0.01}$
  $= 0.6(-0.459)+0.39(2.275)+0 = -0.275+0.887 = \mathbf{0.612}$
- 方案B：$0.6\ln\frac{0.6}{0.34}+0.39\ln\frac{0.39}{0.33}+0.01\ln\frac{0.01}{0.33}$
  $= 0.6(0.568)+0.39(0.167)+0.01(-3.50) = 0.341+0.065-0.035=\mathbf{0.371}$
- **前向 KL 偏爱方案B(0.371<0.612)** → 鼓励"摊平覆盖"，连 C 都分概率。

**反向 KL** $\sum q\log\frac{q}{p}$：

- 方案A：$0.95\ln\frac{0.95}{0.6}+0.04\ln\frac{0.04}{0.39}+0.01\ln\frac{0.01}{0.01}$
  $= 0.95(0.459)+0.04(-2.275)+0 = 0.436-0.091 = \mathbf{0.345}$
- 方案B：$0.34\ln\frac{0.34}{0.6}+0.33\ln\frac{0.33}{0.39}+0.33\ln\frac{0.33}{0.01}$
  $= 0.34(-0.568)+0.33(-0.167)+0.33(3.50) = -0.193-0.055+1.155=\mathbf{0.907}$
- **反向 KL 偏爱方案A(0.345<0.907)** → 鼓励"锁主峰、不碰 C(老师近零区)"。

**结论一眼看穿**：同样两个学生，前向 KL 选了"什么都沾点(方案B,会在 C 上放 0.33 概率→生成时可能采到 C 这种老师几乎否定的 token→幻觉)"；反向 KL 选了"咬定主峰、避开 C(方案A)"。这就是 MiniLLM 用反向 KL 抑制幻觉的算术证据。

## 10. 对照表(与同类方法)

| 方法 | 盒色 | 拟合方向 | 样本来源 | 一句话 |
|---|---|---|---|---|
| 经典 KD(Hinton) | 白盒 | 前向 KL(+温度) | 固定数据 | 分类蒸馏的祖师爷 |
| 黑盒/数据蒸馏(Alpaca 类) | 黑盒 | ≈前向(对文本) | 老师生成的固定文本 | 造数据再 SFT |
| Sequence-KD | 黑盒/白盒 | 前向 | 老师 beam 输出 | 用老师最优序列当硬标签 |
| **MiniLLM** | **白盒** | **反向 KL** | **学生 on-policy** | **mode-seeking，低幻觉** |
| [[llm-compression/distillation/GKD]] | 白盒 | 可调(含 JSD/反向) | **on-policy(学生自采)** | 主攻暴露偏差，散度可选、更通用 |

**何时选 MiniLLM**：你有**老师权重**(白盒)、做**生成任务**、在意**少幻觉/校准/长文本稳定**、能接受多样性略降、且愿意上**策略梯度式训练**(比纯 SFT 复杂)。若只追简单、老师只有 API → 走黑盒 SFT；若想要更灵活的散度与采样策略 → 看 GKD。

## 11. 常见问题

| 问题 | 答 |
|---|---|
| 反向 KL 一定比前向好？ | 不。生成任务+小模型容量受限时好;若要**高多样性/覆盖所有模式**(如开放创作),前向/JSD 可能更合适。这是 mode-seeking vs mean-seeking 的权衡。 |
| 反向 KL 为啥要策略梯度? | 因为期望对**学生分布 $q_\theta$** 取,采样分布带参数,无法直接反传 → 转成 RL 用 REINFORCE 类估计。 |
| 训练为啥不稳/会退化? | REINFORCE 方差大、易 reward hacking、偏好短句。靠单步分解+教师混合采样+长度归一化+baseline 稳住。 |
| 和 RLHF 像吗? | 形式像(都是策略梯度优化"奖励");但 MiniLLM 的"奖励"= 老师给的 $\log\frac{p}{q}$,是**蒸馏**而非人类偏好。 |
| 为啥说它暴露偏差低? | 训练时样本来自**学生自己生成**的前缀,与推理时分布一致,不像 teacher-forcing 只见真值前缀。 |
| 温度 $T$ 在 MiniLLM 里重要吗? | 不是核心。温度是经典分类蒸馏的暗知识放大器;MiniLLM 的创新在散度方向,不靠 $T$。 |
| 学生一定要和老师同架构吗? | 不必。白盒只要能拿到老师**逐 token 概率**即可对齐分布;架构/词表理想情况下兼容(词表不一致需额外对齐处理)。 |
