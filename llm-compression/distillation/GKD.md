# GKD (广义知识蒸馏)

> 让学生在**自己生成的序列**上跟教师学，用可调的**广义 JS 散度**做目标，从根上消除"训练时看老师的句子、推理时说自己的句子"这条曝光偏差鸿沟。📍 导航：[[00-知识地图]]
> 🔗 相关：[[00-知识地图]] [[llm-compression/distillation/MINILLM]] [[llm-compression/README]]

GKD = **G**eneralized **K**nowledge **D**istillation，DeepMind 2023 提出（Agarwal et al., *On-Policy Distillation of Language Models: Learning from Self-Generated Mistakes*）。它把"序列级 KD"在自回归生成上的两个老毛病——**分布不匹配（曝光偏差）** 与 **模型容量不足（student under-specification）**——一次性收编进一个统一框架。

## 0. 一句话锚点

标准 KD 在**固定数据**（真值句子或教师生成句子）上，用**前向 KL** $D_{KL}(p_{\text{teacher}}\|p_{\text{student}})$ 让学生逼近教师。GKD 动两个旋钮：

1. **换数据**：训练时让**学生自己采样**输出序列（on-policy），在这些序列上对齐教师 → 治曝光偏差。
2. **换散度**：用**广义 JS 散度 (JSD)**，靠一个权重 $\beta$ 在前向 KL 与反向 KL 之间平滑滑动 → 治容量不足。

$$\boxed{\text{GKD} = \underbrace{\text{on-policy 数据}}_{\lambda\ \text{控制混合}} \;+\; \underbrace{\text{广义 JSD}}_{\beta\ \text{控制方向}}}$$

---

## 1. 地基：自回归模型 + 知识蒸馏

**自回归语言模型**逐 token 预测，整句概率按链式法则展开：

$$p(y \mid x) = \prod_{t=1}^{T} p(y_t \mid x,\, y_{<t})$$

每一步在词表 $V$ 上输出一个分布（softmax 后的概率向量）。教师 $p_T$、学生 $p_S$ 各自给出这样的逐步分布。

**teacher-forcing（教师强制）**：训练时第 $t$ 步的"历史 $y_{<t}$"用**真值**前缀喂进去，而不是用模型自己上一步预测的 token。这让训练能并行、稳定，但埋下了第 2 节的雷。

**逐 token 蒸馏的基本损失**：在某条序列的每个位置 $t$，让学生分布逼近教师分布。最经典的是**前向 KL**：

$$D_{KL}(p_T \| p_S) = \sum_{v\in V} p_T(v)\,\log\frac{p_T(v)}{p_S(v)}$$

```
   教师 logits ──softmax──►  p_T(·|x,y<t)  ┐
                                            ├─► KL / JSD ─► 梯度回传到学生
   学生 logits ──softmax──►  p_S(·|x,y<t)  ┘
                              ▲
                  关键问题：y<t 这段"历史"从哪来？
                  ① 真值句子   ② 教师生成   ③ 学生自生成  ←── GKD 选这个
```

> **KL 的方向很重要**（后面反复用）：
> - **前向 KL** $D_{KL}(p_T\|p_S)$：期望对 $p_T$ 取。$p_T>0$ 而 $p_S\to0$ 处惩罚爆炸 → 逼学生**覆盖教师所有模式**（mass-covering，"摊大饼"）。
> - **反向 KL** $D_{KL}(p_S\|p_T)$：期望对 $p_S$ 取。逼学生**只压注教师高概率区**（mode-seeking，"抓主峰"）。

## 2. 病根一：曝光偏差 (Exposure Bias) / 分布不匹配

标准序列级 KD（如 word-level KD、SeqKD）在**真值序列**或**教师生成序列**上做 teacher-forcing 训练。但**推理时**，学生没有真值可喂，只能用**自己上一步的输出**当历史，一步步往下走（自由生成）。

```
训练时(teacher-forcing)：  历史 = 真值/教师句     —— 学生从没见过"自己的错误前缀"
推理时(free-running)：     历史 = 学生自己的输出  —— 一旦第 k 步走偏...

  正确轨道:  x → y1 → y2 → y3 → y4 ...   (训练时一直待在这条线上)
  学生实跑:  x → y1 → ŷ2(偏) → ??? → ??? (训练分布里没这点,模型不知所措)
                         └── 误差累积 (compounding errors) ──►
```

这就是**曝光偏差**：模型只在"完美前缀"分布上被训练过，从未"曝光"于自己的错误前缀，于是测试时一旦偏离就雪崩。这是**训练分布 ≠ 推理分布**的本质。

GKD 的第一招直接拔掉病根：**训练时就让学生在自己采样的序列上学**，把"自己的错误前缀"纳入训练分布（见第 4 节）。

---

## 3. 病根二：模型容量不足 (Under-specification) 与 KL 方向

学生通常比教师小很多（如 7B 蒸 1B），**装不下**教师的全部分布。此时散度方向决定学生"怎么牺牲"：

```
教师分布 p_T (两个峰):       ▁▁██▁▁▁██▁▁
                              峰A      峰B

前向KL D(p_T‖p_S)  逼学生覆盖两峰 → 容量不够就摊成宽平的"平均分布":
  学生:                       ▁▂▄▄▄▄▄▄▂▁   ← 在两峰之间的"无人区"也放概率
                                          ← 生成时可能采到峰间的劣质/不通顺样本

反向KL D(p_S‖p_T)  逼学生抓住一个峰 → 容量不够就专注主峰:
  学生:                       ▁▁██▁▁▁▁▁▁   ← 丢掉峰B,但生成质量高(只说有把握的)
```

经验上，对**生成质量**而言，反向 KL（mode-seeking）往往比前向 KL 更好——宁可少样性、要通顺。但反向 KL 也可能过度坍缩。于是 GKD 不写死方向，用**广义 JSD** 给一个连续旋钮（第 5 节）。

> 这正是 [[llm-compression/distillation/MINILLM]] 的核心主张：把目标从前向 KL 换成**反向 KL**。GKD 把它推广成"前向↔反向可调"，并叠加 on-policy 数据。

## 4. 药方一：on-policy 蒸馏（学生自生成序列上蒸馏）

**On-policy** 一词来自强化学习：数据由**当前正在被训练的策略**（这里就是学生）自己产生。GKD 的核心数据流：

```
            ┌─────────────────────────────────────────────┐
            │  GKD on-policy 一次迭代                       │
            └─────────────────────────────────────────────┘
   ① 学生采样:  y ~ p_S(·|x)          (学生自己生成整条序列,可能有错)
                       │
   ② 教师打分:  对 y 的每个位置 t,  教师给出 p_T(·|x,y<t)
                       │  (教师只前向,不更新; 它在"学生的句子"上当裁判)
   ③ 算散度:    在学生自生成的 y 上, 逐 token 算 JSD(p_T, p_S)
                       │
   ④ 反传更新:  ∇θ 更新学生  →  下一轮学生采样分布随之改变
```

关键点：

- 训练序列由**学生当前策略**生成，所以训练分布 = 推理分布 → **曝光偏差消失**。学生恰好在"它自己会犯错的地方"被教师纠正（论文副标题：*learning from self-generated mistakes*）。
- 教师**始终只做前向推理**当 oracle/裁判，给 token 级概率，**不需要真值标签**（无监督蒸馏也能做）。
- 注意 ② 里 $y$ 在 ① 已固定，所以教师与学生都对**同一条** $y$ 的前缀打分；这一步仍是 teacher-forcing 式的逐位置对齐，只不过"被对齐的句子"来自学生采样。
- 采样有成本（每步生成要前向），所以实践中按 **$\lambda$** 概率混合：以概率 $\lambda$ 用学生自生成序列，以概率 $1-\lambda$ 用固定数据集（真值）。$\lambda=1$ 纯 on-policy，$\lambda=0$ 退化为普通离线 KD。

> 对照（论文图 1 的命名）：
> - **on-policy** = 序列全来自学生采样；
> - **Mixed** = 真值与学生生成均匀采样（即 $\lambda=0.5$ 一类）；
> - **ImitKD** = "Mixed 采样 + 前向 KL"，是 GKD 的一个特例。

## 5. 药方二：广义 JS 散度 (Generalized JSD)

普通 JS 散度是"两分布各让一半、对中点取平均 KL"。**广义 JSD** 把"一半"换成可调权重 $\beta\in[0,1]$。先定义混合分布：

$$M_\beta = \beta\, p_T + (1-\beta)\, p_S$$

广义 JSD 定义为（对中点的加权 KL 之和）：

$$\mathcal{D}^{\beta}_{JS}(p_T \,\|\, p_S) = \beta\, D_{KL}\!\big(p_T \,\|\, M_\beta\big) \;+\; (1-\beta)\, D_{KL}\!\big(p_S \,\|\, M_\beta\big)$$

**两个端点正好是 KL 的极限**（这是 GKD 把所有方法统一起来的关键）：

```
 β → 0   ⇒  D^β_JS / 比例   →   前向 KL  D_KL(p_T ‖ p_S)   (mass-covering,摊大饼)
 β = 0.5 ⇒  标准 JS 散度(对称,有界,数值最稳)
 β → 1   ⇒  D^β_JS / 比例   →   反向 KL  D_KL(p_S ‖ p_T)   (mode-seeking,抓主峰)

        前向KL ────────●──────── 反向KL
        β≈0          β=.5        β≈1
        覆盖全模式   平衡/稳定    抓高质量主峰
```

> 直觉：$\beta$ 决定"以谁为中心算期望"。靠 0 端更看重教师覆盖了哪些 token（怕漏），靠 1 端更看重学生敢不敢只说有把握的（怕乱）。

广义 JSD 还有两个工程红利：

1. **有界且对称（在 $\beta=0.5$）**：不像纯 KL 可能因 $p_S\to0$ 而梯度爆炸，JSD 数值更稳，训练不易发散。
2. **一个超参覆盖一族目标**：调 $\beta$ 即可在"多样性 vs 质量"间扫，无需改算法。

## 6. GKD 总算法：两个旋钮 λ 与 β

GKD 的完整损失（一次迭代，对一个 prompt $x$）：

$$\mathcal{L}_{GKD} = \underbrace{(1-\lambda)\,\mathbb{E}_{y\sim \text{数据集}}}_{\text{离线/真值序列}} \big[\mathcal{D}^{\beta}_{JS}\big] \;+\; \underbrace{\lambda\,\mathbb{E}_{y\sim p_S(\cdot|x)}}_{\text{on-policy 学生序列}} \big[\mathcal{D}^{\beta}_{JS}\big]$$

其中每个 $\mathcal{D}^{\beta}_{JS}$ 是在序列 $y$ 上逐 token 求和/平均。

```
                     ┌──────── 数据旋钮 λ ────────┐
                     │  λ=0: 全离线(真值/教师句)   │  ← 治不了曝光偏差
                     │  λ=1: 全 on-policy(学生句)  │  ← 最强消曝光偏差
                     └────────────┬───────────────┘
                                  │
                     ┌──────── 散度旋钮 β ────────┐
                     │  β→0: 前向KL  β→1: 反向KL   │
                     │  β=.5: 标准JSD(最稳)        │
                     └────────────┬───────────────┘
                                  ▼
        许多已有方法 = GKD 在某个 (λ,β) 的特例:
        ┌───────────────────────┬──────────┬──────────────┐
        │ 方法                  │  λ       │  散度        │
        ├───────────────────────┼──────────┼──────────────┤
        │ 监督/离线 KD(word-KD) │  0       │ 前向KL(β→0)  │
        │ ImitKD                │  ~0.5    │ 前向KL(β→0)  │
        │ on-policy GKD         │  1       │ 反向KL/JSD   │
        │ MINILLM(近似)         │ on-policy│ 反向KL       │
        └───────────────────────┴──────────┴──────────────┘
```

实践默认：先 SFT 一个学生当初始化，再用 $\lambda=1$（纯 on-policy）+ $\beta\in[0.1,0.9]$ 扫一扫，任务相关地选最优。

## 7. 与序列级 KD（SeqKD / word-KD）对照

| 维度 | 序列级 KD (SeqKD/word-KD) | GKD |
|------|---------------------------|-----|
| 训练序列来源 | 真值 或 教师生成（**固定**） | **学生自生成**（on-policy，λ 可调） |
| 曝光偏差 | **存在**（训练≠推理分布） | **消除**（训练=推理分布） |
| 散度 | 前向 KL（写死） | **广义 JSD**（β 可调，含前/反向 KL） |
| 容量不足时的退化 | 学生"摊大饼"→生成劣化 | β 偏 1 时"抓主峰"→生成更通顺 |
| 教师角色 | 提供句子 + 概率 | 仅在学生句子上提供概率（当裁判） |
| 是否需真值标签 | SeqKD 需教师句；word-KD 需真值 | 不需要（也可混入） |
| 计算成本 | 低（离线一次生成） | 高（每步要学生在线采样） |
| 误差累积 | 雪崩（没见过错误前缀） | 被纠正（恰在错误前缀处学） |
| 可叠加 RL | 不自然 | **自然**（已是 on-policy，加序列级奖励即可） |

一句话：SeqKD 是"背老师写好的范文"；GKD 是"自己写作文、老师当场逐字批改"。后者正好练到你会犯错的地方。

## 8. 为什么 GKD 更好（直觉 + 证据 + 局限）

**为什么更好（直觉链）**：

1. on-policy → 训练分布对齐推理分布 → 没有曝光偏差 → 不会"测试时一偏就崩"。
2. 在学生**自己的错误前缀**上拿教师概率纠正 → 把监督信号精准投放到学生真正薄弱、真正会去的状态上（覆盖了 SFT/离线 KD 永远碰不到的状态空间）。
3. β 可调 → 容量不足时切到 mode-seeking，牺牲多样性换通顺度，生成质量更高。
4. 目标统一 → 同一框架横扫前向 KL / 反向 KL / JSD / ImitKD，便于公平调参取最优。

**证据**：论文在 **XSum 摘要、WMT 机器翻译、GSM8K 算术推理** 上，带反向 KL / JSD 的 GKD **一致优于** 监督 KD、ImitKD、SeqKD 等基线（图 1）；学生越小、与教师差距越大时，on-policy + mode-seeking 的收益越明显。

**与 RL 天然合体**：GKD 已经是"学生采样 + 打分"的 on-policy 循环，把"教师概率"换/加成"序列级奖励 $r(y)$"，就得到 RLHF 风格目标：

$$\max_\theta\; \mathbb{E}_{y\sim p_S}\big[\, r(y)\,\big] \;-\; \alpha\,\mathbb{E}_{y\sim p_S}\big[\mathcal{D}^{\beta}_{JS}(p_T\|p_S)\big]$$

即"既要奖励高、又要别偏离教师太远"，蒸馏与对齐共用一套管线（详见 [[llm-compression/distillation/MINILLM]] 的反向 KL 视角）。

**局限 / 权衡**：

- **贵**：每步在线采样，训练吞吐远低于离线 KD（要学生反复前向生成）。
- 教师必须能给 **token 级概率**（白盒蒸馏）；纯黑盒 API 教师做不了。
- β、λ 需逐任务调；纯反向 KL（β→1）可能过度坍缩、丢多样性。
- 学生初始太弱时自生成全是垃圾，纠偏效率低 → 通常先 SFT 暖启动。

## 数值例子：在一个 3-token 词表上把 KL / JSD 手算到底

设某位置教师与学生分布（词表 $\{A,B,C\}$）：

$$p_T = (0.7,\ 0.2,\ 0.1), \qquad p_S = (0.4,\ 0.4,\ 0.2)$$

**① 前向 KL** $D_{KL}(p_T\|p_S)=\sum p_T\log\frac{p_T}{p_S}$（用自然对数 nat）：

$$0.7\ln\tfrac{0.7}{0.4} + 0.2\ln\tfrac{0.2}{0.4} + 0.1\ln\tfrac{0.1}{0.2}$$
$$= 0.7(0.5596) + 0.2(-0.6931) + 0.1(-0.6931) = 0.3917 - 0.1386 - 0.0693 \approx \mathbf{0.184}$$

**② 反向 KL** $D_{KL}(p_S\|p_T)=\sum p_S\log\frac{p_S}{p_T}$：

$$0.4\ln\tfrac{0.4}{0.7} + 0.4\ln\tfrac{0.4}{0.2} + 0.2\ln\tfrac{0.2}{0.1}$$
$$= 0.4(-0.5596) + 0.4(0.6931) + 0.2(0.6931) = -0.2238 + 0.2773 + 0.1386 \approx \mathbf{0.192}$$

> 注意两者**不相等**（KL 非对称）！这就是"方向有意义"的实锤。

**③ 标准 JSD（β=0.5）**：先求中点 $M=\tfrac12(p_T+p_S)=(0.55,\ 0.30,\ 0.15)$，再

$$\mathcal{D}_{JS}=\tfrac12 D_{KL}(p_T\|M)+\tfrac12 D_{KL}(p_S\|M)$$

$D_{KL}(p_T\|M)=0.7\ln\tfrac{0.7}{0.55}+0.2\ln\tfrac{0.2}{0.3}+0.1\ln\tfrac{0.1}{0.15}=0.1686-0.0811-0.0405\approx0.0470$

$D_{KL}(p_S\|M)=0.4\ln\tfrac{0.4}{0.55}+0.4\ln\tfrac{0.4}{0.3}+0.2\ln\tfrac{0.2}{0.15}=-0.1274+0.1151+0.0575\approx0.0452$

$$\mathcal{D}_{JS}=\tfrac12(0.0470)+\tfrac12(0.0452)\approx \mathbf{0.046}$$

**结论**：JSD ($\approx0.046$) 远小于两个 KL ($\approx0.18\sim0.19$)，且**有界**（$\le\ln2\approx0.693$）、对称——所以训练时梯度更温和、不易爆炸。把 $\beta$ 从 0.5 调向 0/1，$\mathcal{D}^\beta_{JS}$ 就连续地偏向前向/反向 KL 的"性格"。

## 常见问题

| 问题 | 答案 |
|------|------|
| GKD 的 "on-policy" 和 RL 的 on-policy 一回事吗？ | 概念同源：数据由当前策略（学生）采样。GKD 把它用在蒸馏；加上序列级奖励就变成 RL。 |
| on-policy 一定要 λ=1 吗？ | 不。λ 是混合比；λ=1 纯 on-policy，0<λ<1 与真值混合（更稳、更省采样）。 |
| 为什么不直接全用反向 KL？ | 反向 KL 易过度 mode-seeking、丢多样性且可能不稳。JSD 有界对称，β 给了安全的中间档。 |
| 教师要不要被训练？ | 不。教师全程只前向，当 token 级裁判，给概率不给标签。 |
| 和 [[llm-compression/distillation/MINILLM]] 的区别？ | MINILLM 主打"换成反向 KL + on-policy 近似"；GKD 把方向推广为可调 JSD，并显式给出 λ 数据混合与 RL 接口，是更一般的框架。 |
| 比离线 KD 慢多少？ | 主要慢在每步学生在线采样（要自回归生成），吞吐通常显著低于一次性离线生成的 SeqKD。 |
| 黑盒 API 教师能用 GKD 吗？ | 不能。GKD 需要教师在每个 token 上的概率分布（白盒）。 |
| 学生太弱怎么办？ | 先 SFT 暖启动再 GKD，否则自生成序列质量太差，纠偏低效。 |
| β=0、β=1 严格等于 KL 吗？ | 极限意义上正比于前向/反向 KL；端点处数值上需注意 $\log$ 退化，实践常取 β∈[0.1,0.9]。 |
