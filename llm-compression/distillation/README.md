## 0. 一句话锚点

> **知识蒸馏 = 让小模型（学生）去模仿大模型（教师）的"输出分布"，而不仅仅是模仿数据集里的硬标签。**

核心洞察：一个训练好的大模型，在预测时给出的不是 0/1 硬标签，而是一整条概率分布（"这张图 80% 是猫、15% 是狗、5% 是狐狸"）。这条分布里"猫像狗、不像汽车"的相对关系，就是**暗知识（dark knowledge）**。学生模仿这条分布，比只看"标准答案是猫"学到的更多。

## 1. 地基 / 前置：蒸馏在压缩家族里的位置

> 原文锚点：近年来随着 Transformer、MoE 架构的提出，深度学习模型轻松突破上万亿规模参数，模型越来越大，因此需要大模型压缩技术来降低部署成本、提升推理性能。

大模型压缩主要分为四类（原文保留）：

| 技术 | 一句话 | 改变了什么 | 典型代表 |
| --- | --- | --- | --- |
| **剪枝 Pruning** | 删掉不重要的权重/神经元/层 | 网络结构变稀疏/变小 | Wanda、SparseGPT |
| **知识蒸馏 Distillation** | 小模型模仿大模型 | 换一个更小的网络重训 | Hinton KD、DistilBERT、MINILLM |
| **量化 Quantization** | 用低比特表示权重/激活 | 数值精度变低 | GPTQ、AWQ、FP8 |
| **低秩分解 Low-Rank Factorization** | 把大矩阵拆成两个小矩阵乘积 | $W \approx AB$ | LoRA 思想、ALBERT |

```
                          模型压缩四象限
        改"网络多大"                   改"数怎么存"
   ┌──────────────────────┐    ┌──────────────────────┐
   │  剪枝 Pruning          │    │  量化 Quantization     │
   │  低秩分解 Low-Rank     │    │  (FP16→INT8/INT4/FP8)  │
   └──────────────────────┘    └──────────────────────┘
        改"谁来教"
   ┌──────────────────────────────────────────────────┐
   │  知识蒸馏 Distillation：保留小网络，但换一个更好的"老师" │
   │  ★ 可与剪枝/量化叠加 → 又小又准的高效模型              │
   └──────────────────────────────────────────────────┘
```

**关键认知**：蒸馏不是"修改一个已有模型"，而是"重新训练一个小模型"，但训练时多了一个老师在旁边给提示。所以它天然能与剪枝、量化组合——原文结尾即指出："知识蒸馏是一种有效的帮助小网络优化的方法，能够进一步和剪枝、量化等其他压缩方法结合，训练得到精度高、计算量小的高效模型。"

## 2. 标准知识蒸馏（Hinton KD）

> 原文锚点：Hinton 等人（Distilling the Knowledge in a Neural Network）首先提出了教师神经网络-学生神经网络学习框架，通过最小化两个神经网络之间的差异来学习一个更窄更深的神经网络。

### 2.1 记号与目标

- 教师网络 $T$，参数 $\theta_T$（已预训练好，**冻结不动**）。
- 学生网络 $S$，参数 $\theta_S$（待训练，参数量远小于教师）。
- 一般而言，学生网络相较于教师网络具有更少的参数；通常把一个全新的、更深更窄结构的网络当作学生，把预训练好的模型当作教师。

目标：让学生的输出**同时**接近 (a) 真实标签、(b) 教师的输出分布。

### 2.2 经典损失函数（原文公式 10.3.5 的还原）

原文公式 (10.3.5) 表达的就是 KD 的双目标损失。完整写法为：

$$
\mathcal{L}_{KD} = \underbrace{(1-\alpha)\,H\big(S(x),\,y\big)}_{\text{① 硬标签：接近真实答案}} \;+\; \underbrace{\alpha\, T^2 \cdot H\big(\,\sigma(z_S/T),\ \sigma(z_T/T)\,\big)}_{\text{② 软标签：接近老师分布}}
$$

逐项对照原文：
- $H(\cdot)$ 是**交叉熵函数**（原文：交叉熵函数）。
- $S(x)$、$T(x)$ 分别是**学生网络和教师网络的输出**（原文：分别是学生网络和教师网络的输出）。
- $y$ 是**标签**（原文：是标签）。
- 第一项使学生分类结果接近真实标签；第二项的目的是**提取教师网络中的有用信息并传递给学生**（原文原意）。
- $\alpha$ 是**权值参数，用来平衡两个目标函数**（原文：是一个权值参数用来平衡两个目标函数）。
- $\sigma(\cdot/T)$ 即原文所说的**软化（soften）函数**，"将网络输出变得更加平滑"——这就是带温度 $T$ 的 softmax。

### 2.3 暗知识 + 温度 T：为什么软标签更值钱

带温度的 softmax：

$$
p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}
$$

- $T=1$：普通 softmax。
- $T>1$：分布被"拉平"，小概率项被放大，**类间相似关系**显现出来——这就是暗知识。
- $T\to\infty$：趋于均匀分布。

**数值手算**（3 类，logits $z=[3.0, 1.0, 0.2]$）：

```
T = 1   softmax → [0.836, 0.113, 0.051]   # 几乎一边倒，"猫"压倒一切
T = 3   softmax → [0.527, 0.270, 0.203]   # "狗"被抬起来，暴露"猫像狗不像第三类"
T = 8   softmax → [0.404, 0.314, 0.282]   # 更平滑，相对关系更清晰
```

→ 老师在 $T=3$ 时告诉学生"这更像狗(0.27)而不是第三类(0.20)"，这条信息在硬标签 `[1,0,0]` 里**完全丢失**。这就是软标签的价值。

**为什么损失里乘 $T^2$**：软标签项对 logits 的梯度量级约为 $1/T^2$，乘回 $T^2$ 让软/硬两项梯度量级匹配，避免温度一调高、软目标就"失声"。

### 2.4 训练数据流

```
                          ┌──────────────┐
            x (输入) ────► │  教师 T(冻结) │ ──► logits z_T ──┐
              │           └──────────────┘                 │ softmax(·/T)
              │                                             ▼
              │           ┌──────────────┐            软标签 p_T
              └─────────► │  学生 S(训练) │ ──► z_S ──┬─ softmax(·/T) ─► p_S
                          └──────────────┘          │        │
                                                    │   ②KL/CE(p_S, p_T)·αT²
                              y (真实标签) ──────────┴─ ①CE(softmax(z_S), y)·(1-α)
                                                             │
                                                    L = ① + ② ──► 反向传播只更新 S
```

## 3. 特征蒸馏与注意力蒸馏（不止学输出层）

> 原文锚点：公式 (10.3.5) 仅从教师分类器输出中提取信息，没有从中间层挖掘。因此 Romero 等人（**FitNet**）进一步开发了一种学习轻型学生网络的方法，可从教师网络任意一层传递有用信息给学生。

### 3.1 FitNet：中间层"提示"（Hint）

思想：让学生的某个中间层特征图去拟合教师对应层的特征图。因为两者通道数不同，要加一个轻量的"回归器"$r(\cdot)$ 做维度对齐：

$$
\mathcal{L}_{hint} = \big\|\, r(F_S) - F_T \,\big\|_2^2
$$

```
教师:  ...──[block_t]──► F_T (宽特征图) ──────────────┐
                                                      │  L2 对齐
学生:  ...──[block_s]──► F_S ──► r(·)对齐维度 ──► r(F_S)┘
```

直觉：输出层只有"最终答案"，中间层有"解题中间步骤"，让学生连解题过程一起学。

### 3.2 注意力蒸馏（Attention Transfer）

> 原文锚点：并不是所有输入数据对计算都有用（图像里重要的是动物所在区域而非背景）。Zagoruyko 和 Komodakis 提出基于感知（Attention）损失函数的学习方法，引入感知模块（Attention），选择性地将教师网络中的信息传递给学生。感知图用来表达输入图像不同位置对最终分类结果的重要性；感知模块从教师网络生成感知图并迁移到学生网络（原文图 10.3.3：一种基于感知 attention 的教师-学生学习算法）。

把每层特征图按通道聚合成一张"注意力图" $A=\sum_c |F_c|^p$，让学生的注意力图对齐教师的：

$$
\mathcal{L}_{AT} = \Big\|\, \frac{A_S}{\|A_S\|_2} - \frac{A_T}{\|A_T\|_2} \,\Big\|_2
$$

**三种蒸馏粒度对照**：

| 蒸馏对象 | 学的是 | 代表 | 对齐难点 |
| --- | --- | --- | --- |
| 输出 logits（响应蒸馏） | 最终概率分布 | Hinton KD | 几乎无，最易用 |
| 中间特征（特征蒸馏） | 隐层表示 | FitNet | 通道维度不一致，要回归器 |
| 注意力图（关系蒸馏） | "哪里重要" | Attention Transfer | 选哪些层配对 |

## 4. 大模型（LLM）蒸馏的新范式

传统蒸馏（图像分类）老师学生**同任务、同标签空间**。大模型时代，蒸馏被重新定义为两条主线（原文末尾分类）：

```
                   大模型蒸馏
        ┌──────────────────────────────┐
   ① 标准知识蒸馏            ② 基于涌现能力的知识蒸馏
   (logits/分布对齐)        - 上下文学习 (In-Context Learning)
                            - 思维链   (Chain-of-Thought)
                            - 指令遵循 (Instruction Following)
```

### 4.1 ① 标准知识蒸馏在 LLM 上的挑战

- **白盒 vs 黑盒**：能拿到教师 logits（白盒，如 MINILLM）才能做分布级蒸馏；只能调 API（黑盒，如 Lion/Alpaca 式）只能拿到生成的文本当伪标签。
- **分布失配（exposure bias）**：自回归生成时，前向 KL（学生学老师）会让学生在老师概率低的区域"过度自信"。**MINILLM 用反向 KL（Reverse KLD）**，让学生专注覆盖老师的主模态，避免幻觉式地编造老师不会说的内容。

### 4.2 ② 基于涌现能力的蒸馏

大模型的"涌现能力"（小模型本来没有）也能被蒸进小模型：

| 涌现能力 | 蒸馏做法 | 关键 |
| --- | --- | --- |
| 上下文学习 ICL | 老师生成"带示例的解答"，学生学会从少样本中归纳 | In-Context Learning distillation |
| 思维链 CoT | 老师生成"逐步推理过程"作为训练目标，不只给答案 | SCOTT / MT-COT / DISCO |
| 指令遵循 | 老师生成大量"指令→回答"对，蒸成学生的指令跟随能力 | Lion（对抗式：老师出难题→学生答→老师评判迭代）|

直觉：传统蒸馏蒸"概率分布"，LLM 蒸馏更多在蒸"**推理链条和行为模式**"——老师不仅给答案，还把"怎么想出来的"写出来给学生抄。

## 实操：一份最小可跑的标准 KD 训练循环（PyTorch 伪代码）

把上面的公式落到代码，方便对照 §2.2 各项：

```python
import torch
import torch.nn.functional as F

def kd_loss(student_logits, teacher_logits, labels, T=3.0, alpha=0.5):
    # ② 软标签项：两条带温度的分布做 KL，乘 T^2 平衡梯度量级
    p_t = F.log_softmax(teacher_logits / T, dim=-1)   # 老师 log 分布
    p_s = F.log_softmax(student_logits / T, dim=-1)   # 学生 log 分布
    soft = F.kl_div(p_s, p_t, reduction="batchmean",
                    log_target=True) * (T * T)

    # ① 硬标签项：学生 vs 真实标签的交叉熵
    hard = F.cross_entropy(student_logits, labels)

    return alpha * soft + (1.0 - alpha) * hard   # 对应 L = ② + ①

# 训练：教师 eval/no_grad 冻结，只更新学生
teacher.eval()
for x, y in loader:
    with torch.no_grad():
        zt = teacher(x)            # 老师 logits，不回传梯度
    zs = student(x)                # 学生 logits
    loss = kd_loss(zs, zt, y, T=3.0, alpha=0.5)
    loss.backward()                # 只更新 student 参数
    optimizer.step(); optimizer.zero_grad()
```

要点：
- `teacher.eval()` + `torch.no_grad()`：老师**只前向、不更新**，否则白白浪费显存且违背蒸馏假设。
- 教师与学生必须用**同一 tokenizer / 同一标签空间**，否则两条分布无法对齐。
- LLM 蒸馏中常把上式的硬标签项换成 SFT 损失，软标签项换成对生成 token 分布的 KL（白盒 MINILLM 用反向 KL）。

## 常见问题 / 坑

| 现象 / 坑 | 原因 | 处理 |
| --- | --- | --- |
| 软标签项几乎不起作用 | 忘了乘 $T^2$，软项梯度被 $1/T^2$ 压没了 | KL 项乘 $T^2$（见代码） |
| 温度太高，学生学崩 | $T$ 过大分布趋于均匀，暗知识被抹平 | 常用 $T\in[2,10]$，先试 $T=3{\sim}4$ |
| $\alpha$ 设成 1（只学老师） | 完全丢掉真实标签，老师的错误也照单全收 | 保留硬标签项，$\alpha\approx 0.5$ 起步 |
| 学生/老师 tokenizer 不一致 | 词表错位，分布按位置对齐变成噪声 | 蒸馏前统一词表，或做词表映射 |
| 中间层蒸馏维度不匹配 | 学生通道数 ≠ 教师通道数 | FitNet 加回归器 $r(\cdot)$ 对齐 |
| LLM 蒸馏学生爱"编造" | 前向 KL 让学生覆盖老师低概率区，幻觉 | 改用反向 KL（MINILLM 思路） |
| 黑盒蒸馏只有文本没有 logits | API 模型拿不到概率 | 退化为伪标签 SFT（Lion/Alpaca 式） |
| 蒸馏后精度仍不够 | 单靠蒸馏压缩比有限 | 叠加剪枝/量化（原文：可与剪枝、量化结合） |
