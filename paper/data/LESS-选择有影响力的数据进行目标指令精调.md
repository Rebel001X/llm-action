## 0. 一句话锚点

**LESS = 用候选训练样本的"低维梯度特征"和"少量目标验证样本的梯度特征"做余弦相似，相似度高的样本就是对目标任务最有影响力的训练数据，挑出 Top-5% 来精调。**

核心命题：指令精调不一定要"数据越多越好"，而是"数据越对路越好"。LESS 提供了一个**便宜、可迁移、可解释**的方式来量化"对路"——它把抽象的"影响力（influence）"落地成一个能在普通 GPU 上算完的梯度内积。

## 1. 地基：为什么要选数据

### 1.1 问题背景

指令精调（instruction tuning / SFT）通常把一大堆混合数据集（FLAN、Dolly、Open-Assistant、CoT 等几十上百万条）一股脑喂给模型。但实际部署时我们往往**只关心一个具体能力**——比如"做小学数学应用题（GSM8K）"或"多语种推理（MMLU 某领域）"。

矛盾点：

```
              全量数据 D (百万条, 多领域混杂)
                       |
            ┌──────────┴──────────┐
   传统做法: 全量 SFT            目标: 只想要 "数学" 这一项能力强
   - 贵(算力 x N)                 - 大量无关数据 = 噪声/干扰
   - 不针对                       - 甚至损害目标能力(负迁移)
```

我们想要的是：**给定一小撮"目标任务的示例"（few-shot validation examples），自动从大池子里选出最能提升该任务的训练子集**。这叫 **targeted instruction tuning（目标指令精调）**。

### 1.2 已有思路的不足

| 方法 | 思路 | 短板 |
| --- | --- | --- |
| 启发式过滤 | 按长度、困惑度、去重等规则 | 与"目标任务"无关，挑的是"普遍好数据"不是"对这个任务好的数据" |
| 表征相似（embedding 检索） | 用句向量找和目标相似的样本 | 表层语义相似 ≠ 训练时真的有帮助；忽略"模型学到什么" |
| 经典影响函数（Influence Function） | 用 Hessian 逆估计删掉某样本对验证 loss 的影响 | 需要 Hessian 逆，百亿参数下**完全算不动**；且对深网不稳定 |
| BM25 / TF-IDF | 词面匹配 | 同上，纯文本层面 |

LESS 的定位：**保留"影响函数"的目标导向思想，但把它简化到可在 LLM 上实际计算的程度**，关键是绕开 Hessian、绕开全参数梯度。

## 2. 影响力估计的核心直觉

### 2.1 "影响"到底指什么

> 一个训练样本 $z$ 对"在验证样本 $z'$ 上的损失"的影响 = 如果我用 $z$ 走一步梯度下降，$z'$ 的 loss 会下降多少。

用一阶泰勒展开看：参数 $\theta$ 用样本 $z$ 做一步学习率为 $\eta$ 的 SGD，$\theta \to \theta - \eta\nabla\ell(z;\theta)$。那么验证样本 $z'$ 的 loss 变化约为

$$\ell(z';\theta') - \ell(z';\theta) \approx -\eta\,\nabla\ell(z';\theta)^\top \nabla\ell(z;\theta)$$

**关键洞察**：loss 下降量正比于**两个梯度的内积**。

- 内积 > 0（方向一致）→ 训练 $z$ 会**降低** $z'$ 的 loss → $z$ 对 $z'$ **有帮助**。
- 内积 < 0（方向相反）→ 训练 $z$ 反而**抬高** $z'$ 的 loss → $z$ 对 $z'$ **有害**（负迁移）。

这就是 LESS 的灵魂：**把"有没有用"变成"训练梯度和目标梯度方向一致不一致"。**

```
   训练样本 z 的梯度  g_z  ──┐
                            ├── 内积 g_z·g_z'  > 0 ?  → z 对目标有用
   目标样本 z' 的梯度 g_z' ──┘                  < 0 ?  → z 对目标有害
```

### 2.2 为什么不能直接用 SGD 梯度内积

两个现实障碍，正是 LESS 要解决的：

1. **真实训练用的是 Adam，不是 SGD。** Adam 的更新方向不是 $\nabla\ell$，而是被一阶/二阶动量重整过的方向。直接用原始梯度内积，与真实训练动力学**对不上**。→ LESS 提出 **Adam 版影响公式**（见 §4.1）。
2. **梯度是百亿维，存不下、算不动。** 一条样本的全参数梯度和模型一样大。→ LESS 用 **LoRA 只训练少量参数 + 随机投影降维**，把梯度压成几千维的"梯度特征"（gradient datastore）。

## 3. LESS 四步管线拆解

整体流程：

```
┌─ Step 1: Warmup ────────────────────────────────────────────┐
│  用全量数据的一个小随机子集(如5%) LoRA 预热精调几步           │
│  得到若干 checkpoint  θ_1, θ_2, ... θ_T  (代表训练轨迹)       │
└──────────────────────────────────────────────────────────────┘
            │   (有了"模型在学习中"的快照)
            ▼
┌─ Step 2: 建梯度数据仓库 (gradient datastore) ────────────────┐
│  对【每条候选训练样本 z】:                                    │
│    在各 checkpoint 上算 LoRA 梯度 → 随机投影到 d 维           │
│    → 存一个低维向量 Γ(z)  (Adam 重整后)                       │
└──────────────────────────────────────────────────────────────┘
            │
            ▼
┌─ Step 3: 算目标验证集的梯度特征 ─────────────────────────────┐
│  对【少量目标任务 few-shot 验证样本 z'】:                     │
│    同样算 LoRA 梯度 → 同一随机投影 → 单位化 → ∇(z')           │
└──────────────────────────────────────────────────────────────┘
            │
            ▼
┌─ Step 4: 打分 & 选 Top-k ────────────────────────────────────┐
│  Influence(z) = 各 checkpoint 上 cos( Γ(z), ∇(z') ) 加权求和  │
│  按分数排序，取 Top 5% (或预算 k) 组成精调子集，正式 SFT     │
└──────────────────────────────────────────────────────────────┘
```

### 3.1 第一步：Warmup（为什么要预热）

直接用随机初始/未训练的模型算梯度没意义——此时模型还没进入"学指令"的状态，梯度方向不能代表真实训练动力学。所以先用**少量数据 LoRA 预热**，让模型进入"正在学指令"的轨迹上，再沿这条轨迹的几个 checkpoint 取梯度。多 checkpoint 是为了**对训练轨迹积分**，比单点更稳。

### 3.2 第二步：用 LoRA + 随机投影做廉价"梯度特征"

两层省钱：

- **LoRA**：只对低秩适配矩阵求梯度，可训练参数从百亿降到几百万，梯度维度随之暴跌（这是 LESS 能跑起来的第一前提）。
- **随机投影（Random Projection，Johnson–Lindenstrauss）**：再把 LoRA 梯度乘一个固定随机矩阵 $R\in\mathbb{R}^{d\times p}$，投到 $d$ 维（论文用 $d=8192$ 量级）。JL 引理保证投影后内积/距离近似保持，所以余弦相似度基本不失真。

```
全参数梯度 (≈10^10 维)  ──LoRA──▶  LoRA梯度(≈10^6维) ──随机投影──▶  Γ(z)∈R^d (d≈8192)
        存不下                        还是偏大               可放进 datastore，离线复用
```

一次建好的 datastore 可以**对多个不同目标任务复用**（换目标只需重算几个验证样本的梯度，候选侧不用重算），这是 LESS 可迁移性的工程来源。

### 3.3 第三/四步：匹配与选择

目标侧只需要**少量** few-shot 验证示例（论文里目标任务用其少量验证样本即可），算出目标梯度方向；候选侧逐条算余弦、跨 checkpoint 加权求和得到影响力分数；排序取 Top-k。选出来的子集再做一次正常 SFT，得到最终模型。

## 4. 关键公式、算法与数值示例

### 4.1 Adam 版影响公式（本文核心创新）

SGD 一步对验证 loss 的影响是梯度内积。但 Adam 的有效更新方向是

$$\Gamma(z;\theta) \;=\; \frac{\hat m}{\sqrt{\hat v}+\epsilon}$$

其中 $\hat m,\hat v$ 是该样本梯度经一阶/二阶动量校正后的量（即 Adam 真正"走"的方向）。于是 LESS 把影响重写为**Adam 重整梯度**与**目标梯度**的内积，并跨训练轨迹的多个 checkpoint $\{\theta_i\}$ 加权（权重含学习率 $\eta_i$）：

$$
\mathrm{Inf}_{\text{Adam}}(z, z') \;=\; \sum_{i=1}^{N} \bar\eta_i \,
\cos\!\Big(\Gamma(z;\theta_i),\; \nabla \ell(z';\theta_i)\Big)
$$

直觉解读：**"按 Adam 实际会走的方向" 和 "目标任务想要的下降方向" 越对齐、影响越大**。用余弦（而非裸内积）是为了消除样本梯度范数大小带来的偏置——否则长样本/大范数样本会无脑得分高。

> ⚠️ 公式中的动量项、$\bar\eta_i$ 加权细节以原文与官方实现为准；此处给出的是可理解的结构形式。

### 4.2 算法伪代码

```
输入: 候选训练集 D, 目标验证示例 V (少量), 预算比例 p (如5%)
# --- 离线，一次性 ---
1. θ ← LoRA-warmup(model, 随机子集 of D, T steps)，保存 checkpoints {θ_i}
2. for z in D:                       # 建 datastore (最贵但可复用)
3.     for θ_i in checkpoints:
4.         g ← Adam重整( ∇_LoRA ℓ(z; θ_i) )
5.         Γ_i(z) ← normalize( R · g )      # 随机投影到 d 维 + 单位化
6.     存 {Γ_i(z)} 到磁盘
# --- 针对某个目标任务 ---
7. for z' in V:  ∇_i(z') ← normalize( R · ∇_LoRA ℓ(z'; θ_i) )
8. for z in D:   score(z) ← Σ_i  η̄_i · ⟨ Γ_i(z), mean_{z'} ∇_i(z') ⟩
9. S ← Top-(p·|D|) by score
# --- 正式精调 ---
10. return SFT(model, S)
```

### 4.3 数值手算：影响内积怎么看

设某 checkpoint 上，候选样本 $z$ 投影后梯度（已单位化）与目标平均梯度方向的夹角余弦为：

- 样本 A：$\cos = +0.42$ → 强一致，**优先选**
- 样本 B：$\cos = +0.05$ → 几乎正交，无关，**可丢**
- 样本 C：$\cos = -0.30$ → 反方向，**有害（负迁移），必须排除**

若 4 个 checkpoint 的等权（$\bar\eta_i$ 视作相同）余弦分别为 A: 0.40/0.45/0.38/0.45 →
$$\mathrm{score}(A)\approx \tfrac14(0.40+0.45+0.38+0.45)=0.42$$
B 各点都在 0.05 附近 → score≈0.05。排序后 A 进 Top-k、B/C 出局。**这正是"挑出对目标有用、剔除有害"的量化体现。**

### 4.4 显存/算力账（直觉量级）

| 量 | 全参数影响函数 | LESS |
| --- | --- | --- |
| 单样本梯度维度 | $\sim10^{10}$（=模型大小） | LoRA 后 $\sim10^6$，再投到 $d\approx 8192$ |
| 是否需要 Hessian 逆 | 需要（$O(p^2)$ 存储不可行） | **不需要**（只做内积） |
| datastore 复用 | — | **一次建库，多目标任务复用** |
| 主要开销 | 不可行 | 遍历 D 各样本算一次 LoRA 梯度（一次前后向量级） |

一句话：LESS 把"理论上正确但算不动"的影响函数，工程化成"算一遍前后向 + 一个低维内积"。

## 5. 实验结论（定性）

> 数字均为定性概括，精确值见原文。

- **小数据追平/超越全量**：在多个目标任务（如 MMLU、TYDIQA、BBH 等）上，用 LESS 选出的**约 5%** 数据精调，效果**可媲美甚至超过用 100% 数据**的精调。说明大量数据是"陪跑"，少数是"主力"。
- **优于各类基线**：明显胜过随机选、表征相似（embedding 检索）、以及只看困惑度等启发式选择。
- **跨模型可迁移**：用**较小模型**（如 LLaMA-7B 量级）算出的影响力分数，挑出的数据**拿去训更大模型/不同模型也有效**——梯度特征捕获的"哪条数据对这类任务有用"具有跨规模一致性。这对工程极有价值：**用小模型选数据，给大模型用**。
- **可解释**：选出的样本在主题/能力上确实和目标任务对应（如数学目标会选出推理类样本），不是黑箱。

## 6. 对工程的启示

- **数据为中心（data-centric）的省钱杠杆**：与其堆数据/堆算力做全量 SFT，不如先花一次离线成本建梯度 datastore，之后每个目标任务只需轻量打分即可定制专属训练集，训练成本随 |子集| 线性下降。
- **"小模型选数据，大模型训"** 是落地黄金路径：选择阶段用 7B、训练阶段用 70B，选择成本可忽略。
- **可用于持续学习/领域适配**：上线新场景时，用该场景少量样本作为目标，从历史数据池里捞最相关子集做增量精调，避免全量重训和灾难性遗忘。
- **可作数据清洗器**：负影响（cos<0）的样本即"对目标任务有害"，可识别噪声/冲突数据。
- **与 [[llm-train/README]] 的 SFT 流程衔接**：LESS 是 SFT 前的"数据选择"前置模块，输出仍是普通指令数据，下游训练管线零改动。

## 7. 局限与后续

| 维度 | 局限 / 注意 |
| --- | --- |
| 一阶近似 | 影响基于一阶泰勒，忽略高阶与样本间交互；"选出的 Top-k 集合"未必是联合最优子集（贪心近似）。 |
| 目标验证集依赖 | 需要少量"代表目标任务"的示例；若目标定义模糊或验证样本不具代表性，选择会偏。 |
| 建库成本 | datastore 首次构建仍要遍历全部候选样本算梯度；池子极大时前期成本不低（但可复用摊薄）。 |
| 随机投影/LoRA 近似 | 用 LoRA 梯度+JL 投影近似全参数影响，存在系统性近似误差；维度 $d$ 太小会失真。 |
| 任务范围 | 论文聚焦指令精调/SFT 阶段的目标任务选择；偏好对齐（RLHF/[[llm-alignment/DPO]]）阶段的数据选择是自然延伸但非本文重点。 |
| 安全/分布 | 只优化"目标任务 loss"，未显式约束安全性/多样性，单纯追相似可能牺牲泛化。 |

**后续方向**：把梯度影响思想推广到偏好数据（DPO/RLHF）选择、与课程学习结合、把"选择"与"训练"联合优化、用更精细的轨迹积分替代少数 checkpoint。

## 一图总结

```
   海量混合指令数据 D ─────────────────────────────┐
                                                    │  ① LoRA warmup → checkpoints
   少量"目标任务"示例 V ──算梯度→投影→ ∇(z')         │  ② 每条 z 算 Adam重整梯度→投影→ Γ(z)  (建库,可复用)
                       │                            ▼
                       └──── cos(Γ(z),∇(z')) 跨checkpoint加权 = 影响力分数
                                          │
                                  排序取 Top-5%  →  正式 SFT  →  目标能力↑↑ (≈全量效果, 1/20 数据)
```
