# LLM 增强 LLMs：通过组合扩展能力（CALM）

> 用一个小的"增强模型"通过交叉注意力"挂"到一个大的"锚模型"上，不动任何一方的权重，就能组合出二者皆无的新能力。📍 导航：[[00-知识地图]]

## 0. 一句话锚点

**CALM（Composition to Augment Language Models）** 把一个**已经训练好的小模型 $m_A$**（懂某种专长，例如低资源语言、代码、特定逻辑）和一个**大基座模型 $m_B$**（通用能力强）**都冻结住**，在它们的中间层之间插入一组**可学习的交叉注意力层**。只训练这组"连接件"（外加一个线性投影），就能让组合模型 $m_{A\oplus B}$ 同时拥有两者的本事——而且在很多任务上**超过**任一单独模型，甚至超过把 $m_A$ 的数据直接拿去微调 $m_B$。

> 直觉：$m_B$ 像一个"全科大脑"，$m_A$ 像一个"专科顾问"。CALM 不重新培养任何一个，而是修一条**专用神经通路**，让大脑在思考时随时"咨询"顾问。

## 1. 地基/前置（问题背景）

### 1.1 为什么不直接微调或重训？

给基座模型加新能力，传统三条路各有代价：

| 路线 | 做法 | 代价/缺点 |
|---|---|---|
| 全量/继续预训练 | 用新数据再训大模型 | 算力极贵；易**灾难性遗忘**原能力；要拿到原始训练数据 |
| 参数高效微调（LoRA 等） | 在大模型上插低秩适配器 | 仍需大模型可训练梯度；新能力受限于大模型表征容量 |
| 模型合并 / 权重平均 | 直接平均/拼接权重 | 要求结构同源；能力叠加不可控，常互相干扰 |

CALM 的出发点：**很多专用能力其实已经被某个小模型学好了**（比如一个在低资源语言或私有代码库上训练过的小模型）。与其把这些数据/能力重新塞进大模型，不如**直接复用那个小模型的内部表征**。

### 1.2 关键假设

- **$m_A$ 和 $m_B$ 的中间层表征是"可被读取的知识载体"**：小模型某一层的隐状态里编码了它的专长信息。
- **冻结即保护**：不更新 $m_A$、$m_B$ 的权重，就**绝不会破坏**它们各自已有的能力（零遗忘）。
- **少量桥接参数足够**：只需学"如何把 $m_A$ 的表征注入 $m_B$"，不需要重学知识本身。

```
       传统微调                          CALM 组合
 ┌──────────────┐                ┌──────────┐   ┌──────────┐
 │  大模型 m_B   │ ← 反向传播      │ 小模型 m_A │   │ 大模型 m_B │
 │ (全部可训练)  │   更新所有权重   │  (冻结❄)  │   │  (冻结❄)  │
 └──────────────┘                └────┬─────┘   └────┬─────┘
   昂贵 + 可能遗忘                      └──交叉注意力──┘
                                       只训练这几层🔥
```

## 2. 核心方法拆解：把两个模型缝在一起

### 2.1 记号约定

- $m_A$：增强模型（augmenting，通常较小，含某专长），层数集合中选一组层 $\mathbb{L}_A$。
- $m_B$：锚模型（anchor，基座，通用），选一组层 $\mathbb{L}_B$。
- $H_A^{(i)}\in\mathbb{R}^{T\times d_A}$：$m_A$ 第 $i$ 层输出的隐状态序列（$T$ 个 token，维度 $d_A$）。
- $H_B^{(j)}\in\mathbb{R}^{T\times d_B}$：$m_B$ 第 $j$ 层的隐状态。
- 在选定的**层对** $(i,j)$ 之间，插入一个交叉注意力 + 投影模块，把 $H_A^{(i)}$ 的信息融进 $H_B^{(j)}$。

### 2.2 数据如何流动（核心图）

```
  输入 tokens x  ──┬───────────────► m_A（冻结）每层产出 H_A
                   │                    │  │  │
                   │                    ▼  ▼  ▼   选若干层 i∈L_A
                   │                 ┌─────────────┐
                   └──────► m_B ────►│  交叉注意力   │  Q 来自 m_B
                          (冻结)      │  + 线性投影f │  K,V 来自 m_A
                          每层 H_B    └──────┬──────┘
                            j∈L_B           │ 把"咨询结果"加回
                            ▲               │ m_B 的第 j 层残差流
                            └───────────────┘
                                            │
                                            ▼
                                     m_B 继续向上 → 输出
```

要点：
1. **同一份输入** $x$ 同时喂给 $m_A$ 和 $m_B$（也可对 $m_A$ 用不同的提示/分词，论文里两者各用自己的 tokenizer）。
2. $m_A$ 先跑一遍，缓存它各选定层的隐状态 $H_A$。
3. $m_B$ 正常前向，但在选定的层 $j$，额外做一次**交叉注意力**：Query 来自 $m_B$ 当前隐状态，Key/Value 来自 $m_A$ 的隐状态。
4. 交叉注意力的输出经线性变换后，**加进 $m_B$ 第 $j$ 层的残差流**（像多加了一个 sub-layer）。

### 2.3 为什么用"交叉注意力"而不是简单拼接？

- **维度不同**：$d_A\neq d_B$ 很常见，拼接需要硬对齐；交叉注意力天然用投影矩阵 $W_K,W_V$ 把 $d_A$ 映到 $d_B$。
- **token 对齐自由**：两个模型 tokenizer/序列长度可不同，注意力机制按内容软对齐，不要求一一对应。
- **可学的"读取策略"**：注意力权重让 $m_B$ **按需**挑选 $m_A$ 表征中有用的部分，而非全盘吸收——这正是组合优于简单叠加的关键。

### 2.4 选哪些层来连？（层映射）

论文做法是建立一组**层对映射** $\{(i,j)\}$：从 $m_A$ 的某些层连到 $m_B$ 的某些层。实践中常用"均匀采样若干层"或"每隔 $k$ 层连一次"。连得太多→参数与算力上升；太少→信息注入不足。具体层数/步长**以原文与官方配置为准**。

```
 m_A 层:  L1   L4   L8   L12 ...   (每隔几层取一个)
           │    │    │    │
           ▼    ▼    ▼    ▼   交叉注意力桥
 m_B 层:  L2   L6   L10  L14 ...
```

## 3. 训练目标与数据

### 3.1 只训练"桥"

- **冻结**：$m_A$ 全部参数、$m_B$ 全部参数。
- **可训练**：每个桥接模块的交叉注意力投影 $\{W_Q^{B},W_K^{A},W_V^{A},W_O\}$ 与线性映射 $f$。
- 损失：标准的**语言建模交叉熵**（next-token prediction），在能体现"组合能力"的任务数据 $D_C$ 上训练。

$$
\mathcal{L} = -\sum_{t}\log p_{\,m_{A\oplus B}}\!\left(x_t \mid x_{<t}\right),\quad \text{只对桥参数 }\Theta_{\text{cross}}\text{ 求梯度}
$$

### 3.2 训练数据从哪来？

论文指出一个很实用的点：**不需要 $m_A$ 当初的训练数据**。只要有少量能"激发组合"的任务数据即可——甚至可以是 $m_A$ 与 $m_B$ 能力交集的合成/混合数据。这降低了数据可得性门槛（私有数据训出 $m_A$ 后，组合阶段无需再暴露它）。

## 关键公式 / 算法 / 数值示例

### A. 交叉注意力桥（单个模块）

设 $m_B$ 第 $j$ 层隐状态为 $H_B\in\mathbb{R}^{T_B\times d_B}$，$m_A$ 第 $i$ 层为 $H_A\in\mathbb{R}^{T_A\times d_A}$。桥的计算：

$$
Q = H_B W_Q,\quad K = H_A W_K,\quad V = H_A W_V
$$
$$
\text{CrossAttn}(H_B,H_A)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_h}}\right)V
$$
$$
H_B^{\text{new}} = H_B + W_O\,\big(\text{CrossAttn}(H_B,H_A)\big)
$$

- $W_Q\in\mathbb{R}^{d_B\times d_h}$，$W_K,W_V\in\mathbb{R}^{d_A\times d_h}$，$W_O\in\mathbb{R}^{d_h\times d_B}$。
- 最后一行的 **残差加法** 保证：若桥输出为 0，组合模型退化为原始 $m_B$（**不伤害基座**的安全后备）。

### B. 组合算子记号

把整个组合写成算子 $\oplus$：

$$
m_{A\oplus B} = \mathcal{C}\big(m_A,\; m_B;\; \Theta_{\text{cross}}\big)
$$

其中只有 $\Theta_{\text{cross}}$ 可学，$m_A,m_B$ 为常量。

### C. 参数量手算（看"桥有多便宜"）

假设 $d_A=d_B=d=4096$，注意力头维 $d_h=4096$，连 $L=8$ 个层对，每个桥含 $W_Q,W_K,W_V,W_O$ 四个 $d\times d_h$ 矩阵：

$$
\text{每桥参数} \approx 4 \times d \times d_h = 4\times4096\times4096 \approx 6.7\times10^7
$$
$$
\text{总桥参数} \approx 8 \times 6.7\times10^7 \approx 5.4\times10^8 \;(\sim0.5\text{B})
$$

对比一个 60B 的基座，桥参数约占 **<1%**。即"加一个小模型的全部知识，只多训不到 1% 的参数"。（实际数值依配置，**以原文为准**）。

### D. 推理显存/算力账（直觉）

组合推理要**同时跑 $m_A$ 和 $m_B$**两次前向：
- 显存 $\approx$ 权重($m_A$)+权重($m_B$)+两者 KV-Cache + 桥参数。
- 算力 $\approx$ FLOPs($m_A$)+FLOPs($m_B$)+交叉注意力开销。

若 $m_A$ 远小于 $m_B$（如 1B vs 60B），额外开销主要是 $m_A$ 的那 ~1.6% 算力 + 桥，**性价比高**。这也是为什么 $m_A$ 要"小而专"。详见 [[docs/transformer内存估算]] 与 [[llm-optimizer/kv-cache]]。

## 4. 实验结论（定性，数字标"约/见原文"）

> 以下为论文报告的**趋势**，精确数字与设置**以原文为准**。

1. **低资源语言 + 推理组合**：把一个掌握若干低资源语言的小 $m_A$，组合到通用大 $m_B$ 上，在这些语言的翻译/数学等任务上，组合模型显著优于单独的 $m_B$，也优于单独的 $m_A$。说明组合是"$m_A$ 的语言 + $m_B$ 的推理"的真正叠加，而非取平均。
2. **代码能力组合**：把一个代码专长的 $m_A$ 接到 $m_B$ 上，代码补全/解释类任务有明显提升。
3. **对比直接微调**：在若干设置下，CALM **不输甚至超过**"把 $m_A$ 的数据拿去微调 $m_B$"，但**省去了对大模型反向传播**，且**零遗忘**原能力。
4. **零样本/泛化**：桥学到的是"如何读取 $m_A$"的通用策略，对训练分布外的组合任务也有一定泛化。

## 5. 对工程的启示

```
   "模型乐高"工作流
 ┌──────────┐
 │ 基座 m_B  │  训练一次，长期复用
 └────┬─────┘
      │  按业务挂不同增强模型（都冻结）
 ┌────┴───────────────┬───────────────┐
 ▼                    ▼               ▼
法律 m_A1           医疗 m_A2        某语言 m_A3
(桥1🔥)             (桥2🔥)          (桥3🔥)
```

- **解耦训练**：领域团队各自训自己的小 $m_A$（甚至用私有数据），平台方维护 $m_B$，组合阶段只交换"桥"，**不交换原始数据**——利于隐私/合规。
- **零遗忘上新**：上一个新能力 = 训一组桥，不动线上基座，**回滚只需卸载桥**。
- **与现有栈互补**：桥本身是一组注意力层，可叠加量化（[[llm-compression/quantization/量化基础]]）、并入张量并行（[[B07:llm-inference/大模型推理张量并行]]）部署。
- **与 RAG 的区别**：RAG 注入的是"文本知识"，CALM 注入的是"模型内部表征/技能"。两者可叠加：检索喂上下文，CALM 提供推理/语言桥接能力。

## 评价 / 对照 / 局限

| 对比项 | CALM | LoRA/微调 | 模型合并 | RAG |
|---|---|---|---|---|
| 是否动基座权重 | 否（冻结）| 是（插适配器/全量）| 是 | 否 |
| 灾难性遗忘风险 | 几乎为 0 | 有 | 较高 | 0 |
| 需要原训练数据 | 否 | 视情况 | 否 | 否 |
| 推理成本 | 高（跑两模型）| 低 | 低 | 中（检索+长上下文）|
| 注入的是 | 模型内部表征/技能 | 适配后的权重 | 平均权重 | 外部文本知识 |
| 结构要求 | 两模型可异构 | 单模型 | 通常需同源 | 与模型解耦 |

**局限**：
- **推理要双前向**，延迟/显存上升（$m_A$ 越大越贵）；不适合极端低延迟场景。
- **能力上限受 $m_A$ 制约**：$m_A$ 不会的，桥也变不出来——它是"读取"而非"创造"知识。
- **层映射/桥位置是超参**，需要搜索；连错层可能注入无效。
- **需要组合任务数据** $D_C$，虽不需 $m_A$ 原数据，但要有能激发组合的样本。
- 多个增强模型同时挂载的相互干扰、桥的可解释性等，仍是开放问题（**以后续工作为准**）。
